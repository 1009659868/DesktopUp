DesktopUp Preview — Windows 11 x64 独立预览版

这是开发预览，不是稳定发布版。支持从桌面/资源管理器拖入文件、文件夹和快捷方式本体，同卷移动、跨卷逐项准备后收纳；拖出通过 Windows Shell 交给桌面/资源管理器，保留系统冲突提示。操作会移动真实对象，请先用自行创建的无价值文件验证。
内容采用单一归属；有效对象无需应用层额外确认，失效引用在松手后才询问是否移除卡片。普通/映射海报间直接拖放已有本机验收；任意第三方目标、多DPI/满盘与长时场景仍未完成全面验证。
真实内容收纳仍在开发，当前不代表完整文件管理能力；窗口拖动/收展拖影等已知限制及长时验证仍待后续处理。

安装
1. 将 DesktopUp-Preview-日期.序号-win-x64-Setup.exe 复制到 Windows 11 x64 电脑。
2. 核对随包 SHA256 后，双击安装，可选择其他本地磁盘上的可写目录；目录中可以已有其他文件。只为当前用户安装，无需另装 .NET。
3. 在“附加选项”页选择是否创建桌面快捷方式（默认勾选）。取消勾选仍可从开始菜单启动；勾选后也可从带版本号的桌面快捷方式启动。已有同名文件不会被覆盖。
4. 打开 DesktopUp Preview。新配置首次为零海报、无演示卡片；每次启动时，零海报打开控制中心，有海报则后台运行。点击“新增海报”，默认“基础收纳”，随后可拖入自建文件。
5. 双击托盘图标打开控制中心。关闭控制中心并不退出；退出请用托盘 → 退出。

独立边界
- 安装目录可自选；建议默认：%LOCALAPPDATA%\Programs\DesktopUp Preview\<版本>。
- 可以安装到非空目录，保留已有文件。若 DesktopUp.exe、Uninstall.exe、PREVIEW-README.txt、app 或 licenses 已存在，请改选目录；不会覆盖这些同名内容。不安装到磁盘根、Windows目录、用户配置目录、联接路径或过长路径。
- 根目录只放启动/卸载入口、此说明、app 和 licenses。app 集中存放程序、运行库、语言资源与模块；这些属于运行依赖，请勿单独删除。
- 预览配置/日志：%LOCALAPPDATA%\DesktopUp\Preview
- 默认收纳：%LOCALAPPDATA%\DesktopUp\Storage\preview\<配置身份>；通常位于C盘，遵循系统用户数据目录，不硬编码盘符。
- 安装与用户数据相互独立，避免目录权限、升级或卸载影响收纳原文件。可在“控制中心 → 全局 → 收纳位置”修改并迁移已有收纳；原有配置中已选的位置不会被重装改写。
- 不读取、迁移或覆盖日常版 %LOCALAPPDATA%\DesktopUp\V3。
- 不设置开机启动。各预览版本共享 Preview 配置和单实例，不应同时运行。
- 不包含本机测试数据库、个人配置或开发 SDK。
- 自带 .NET 与 Windows App SDK 运行库；Windows 系统组件仍由操作系统提供。
- 新建海报的默认模板/参数由此包的 app\config\preview-defaults.json 决定，具体值见 app\preview-build.json。
- 当前默认打包配置为“基础收纳”，不附加灯光或介绍文字区；构建时仍可显式选择其他已支持模板。
- 仅新增海报使用此默认值，首次启动不生成海报；重装、重启不覆盖已有配置，复制海报保留源配置。

卸载与重装
先从托盘正常退出，再通过 Windows 设置 → 应用 → 已安装的应用卸载。
可通过安装目录的 Uninstall.exe 或 Windows“已安装的应用”卸载，二者为同一入口。
交互卸载默认先归还收纳内容：返回收纳前的目录并保留当前名称，原目录不可用或来源未知时返回系统桌面。Windows 冲突处理照常；取消或失败会停止卸载，程序和剩余文件保留，已经归还的文件不搬回。
也可选择“保留在原收纳位置，仅卸载程序”。包含受管目录内没有可见卡片的内容；映射目录和外部引用不搬动，不扫描其他用户或日常版数据。预览版本共用 Preview 配置，卸载任一预览版本时的归还会影响此共用配置。
文件位置清单保存在 Preview\uninstall-reports，仅在本机生成；配置、归属记录和未知文件均保留。程序仅按安装清单删除，不递归清理用户数据。静默卸载 /S 默认保留内容；/CONTENT=keep 显式保留；需要归还时请使用交互卸载。静默 /CONTENT=return 有收纳内容时拒绝执行。
桌面快捷方式仅在由本次安装创建、且仍指向此安装目录时随卸载清理；已有同名文件或被改指向其他程序的快捷方式保留。
同一版本不会覆盖安装或另装一份；先卸载同版本再装。不要移动卸载器或手动搬动安装目录。
卸载保留配置意味着重装后会恢复上次的预览设置，不等于完全重置。

安全提示
这是未数字签名的开发包，Windows 可能提示未知发布者或阻止运行。
请仅在确认来源、核对哈希并信任该包后决定是否运行；不需要关闭 Defender 或系统防护。
不要导入来源不明的配置/模板，不用预览包管理重要文件。

另一台电脑的简要验收
启动/新增海报；拖动/收展；控制中心修改并重启；托盘退出；卸载后确认配置保留。
异常时请提供 Windows 版本、截图、操作顺序，以及 Preview\logs\desktopup.jsonl。
发送日志前检查其中的本机路径等信息。不要发送整个个人配置库。

构建来源及依赖版本：app\preview-build.json；文件哈希：app\payload-manifest.json。
第三方许可证与归属声明：licenses 目录。此预览包不自动更新，请按后续版本重新安装。
