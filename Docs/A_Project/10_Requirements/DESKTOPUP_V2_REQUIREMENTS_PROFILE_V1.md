## 3. 产品定义

DesktopUP 是一款面向 Windows 11 的低资源桌面海报启动器。它把游戏和常用应用入口组织为可折叠、可换肤、可自动排版的桌面海报，使用户不必先打开传统启动器主页，就能在桌面查看和启动内容，同时保留 Windows 原生桌面行为、撤销、恢复、升级和卸载安全。

产品不是传统的“启动后打开主页”应用。正常运行时海报是唯一持续可见的产品表面；主页/控制中心用于管理，托盘用于快捷入口和生命周期控制，二者都不能取代真实桌面上的海报。产品本质上更接近**壁纸引擎/桌面收纳工具引擎**：视觉、布局与主题的可塑性和自由度是第一等需求，后续能力扩展（模板、素材、布局风格、AI 草稿）要求高自由度，不能把实现绑定在单一渲染技术或单一主题表达上。

## 4. 用户问题与核心价值

### 4.1 用户问题

- 游戏快捷方式散落在桌面，缺乏分组、层次和统一视觉；
- 传统启动器需要打开普通窗口，不能低干扰地长期融入桌面；
- 桌面美化工具可能吞掉框选、右键和原生图标点击；
- 自动整理如果直接移动文件，容易造成覆盖、丢失或卸载后遗留；
- 游戏库变大后，常玩内容、新加入内容和长期未用内容很难同时保持可发现；
- 主题和 AI 增强容易越过文件、网络、执行和隐私边界；
- 重启、Win+D、Explorer 重启、分辨率或 DPI 改变后，桌面组件容易消失、错位或覆盖普通程序。

### 4.2 核心价值

1. **桌面即入口**：海报长期位于桌面层，启动内容不依赖主页常驻。
2. **Windows 桌面优先**：空白框选、右键、图标单击/双击和普通程序层级不可破坏。
3. **安全添加与收纳**：先只读发现、再预览、再由用户选择“仅添加”或“安全收纳”。
4. **失败可恢复**：状态、主题、托管快捷方式、升级和卸载失败时保留上一份有效材料。
5. **视觉可塑**：从一键预设、结构化参数、素材替换到受限代码覆盖逐级开放。
6. **活跃内容突出**：近期使用、真实启动次数和新鲜度共同影响排序，且始终允许人工控制。
7. **低资源低打扰**：静态时不持续重绘，控制中心和 AI 按需加载。

## 5. 目标用户

### 5.1 游戏桌面整理者

- 使用 Windows 11；
- 桌面存在 Steam、Epic、Xbox、独立游戏或应用快捷方式；
- 希望三分钟内完成初始设置；
- 不希望应用改变 Windows 桌面习惯；
- 重视“不要动我的文件”和卸载恢复。

核心任务：安装后看到默认海报、添加项目、从海报启动、移动和缩放海报、锁定、收起/展开、重启恢复、卸载恢复。

### 5.2 桌面美化用户

- 重视壁纸融合、透明度、圆角、留白、配色、字体和动效；
- 希望通过预设和滑块完成主要定制；
- 可能导入背景图、SVG、字体和主题包。

### 5.3 主题作者

- 能编辑结构化参数、受限样式、SVG 或受限结构模板；具体样式语言由后续技术选型决定；
- 需要明确的参数 schema、素材槽、版本、导入导出和错误回退契约；
- 接受安全扫描、权限预览和信任确认。

### 5.4 BYOK AI 用户

- 自行提供 OpenAI、DeepSeek 或兼容端点的 API Key；
- 希望用自然语言调整主题、间距、尺寸、排序和布局；
- 接受模型只能提出结构化变更，不能获得本机通用权限。

## 6. V2 不可破坏不变量

### RP-INV-01 真实桌面优先（`P0/FROZEN`）

海报视觉覆盖到的透明空白必须仍允许 Windows 桌面框选、空白右键、原生图标单击/双击。海报不得以整屏透明输入层、浏览器右键菜单或不可见命中矩形替代桌面行为。

### RP-INV-02 层级稳定（`P0/FROZEN`）

海报的目标层级顺序固定为：普通窗口、控制中心、系统对话框与全屏程序在海报之上；海报在 Windows 桌面图标与壁纸之上。海报不得覆盖前述普通/系统程序，也不得沉到图标或壁纸之下。

键盘 `Win+D`、任务栏“显示桌面”和触控板显示桌面手势执行期间，海报必须连续可见；不得先隐藏、最小化、cloak、掉层或脱离桌面锚点，再通过补救动作恢复。右键关闭、刷新、拖动、控制中心开关和 Shell 恢复同样不得产生任何一帧瞬时置顶、隐藏或重挂闪烁。

实现不得以临时 `TopMost`、激活窗口或覆盖普通程序来换取恢复速度。

### RP-INV-03 用户文件安全（`P0/FROZEN`）

未经过用户主动入口、逐项预览和逐批确认，不扫描、不移动、不删除桌面项目。永不移动或删除 `.exe`、游戏本体、游戏平台目录、普通文件夹或普通文件。

### RP-INV-04 失败保留（`P0/FROZEN`）

权威业务存储、迁移、主题安装、快捷方式托管、恢复或卸载失败时，必须保留上一份有效状态、原始输入、保险库副本或恢复账本，不得用空白默认值掩盖损坏。

### RP-INV-05 单一状态权威（`P0/FROZEN`）

业务持久状态只能有一个正式权威。海报、控制中心、托盘和 AI 都是快照消费者或命令入口，不能各自保存会互相覆盖、刷新回弹的第二份状态。

### RP-INV-06 控制中心不是产品主体（`P1/FROZEN`）

普通启动和自启后只显示已启用海报与托盘。主页、设置和 AI 由用户主动打开；关闭主页不隐藏海报，隐藏海报不强制打开主页。

### RP-INV-07 锁定是保护边界（`P0/FROZEN`）

锁定只冻结海报外部几何（移动、缩放、锚点）与 Item 人工重排；内部自动排名、布局计算和主题参数等内部逻辑不受锁定影响，继续正常运转。仍允许解锁、收起/展开和正常 Item 启动。AI 和自动化不得静默解锁后继续修改。

### RP-INV-08 渲染技术可替换（`P0/FROZEN`）

海报渲染技术不是最终用户需求。任何实现都必须遵守同一状态、输入、层级、暂停、恢复、主题和诊断契约；替换渲染器不能迫使权威状态仓库、托盘、生命周期或安全收纳重写为另一套语义。

### RP-INV-09 技术选型后置（`P0/FROZEN`）

需求冻结前不预选 Qt、WebView2、Direct2D、DirectComposition、layered window 或其他技术。后续选型必须形成独立阶段，并提供候选、原型、同一证据矩阵和淘汰理由。

### RP-INV-10 无 AI 完整可用（`P1/FROZEN`）

未配置 API Key 时不初始化 Provider、不联网，海报、Item、主题手动编辑、启动、恢复和卸载完整可用。

### RP-INV-11 呈现事实可验证（`P0/FROZEN`）

“窗口存在”或“内容已加载”不能替代“屏幕实际正确呈现”。实现必须提供可诊断的呈现健康状态；白条、灰框、缺帧、透明失效、裁切或内容缺席必须能够被测试发现。

### RP-INV-12 个人自用边界（`CURRENT`）

当前以个人自用为主，不要求公开分发的许可证页面、第三方 NOTICE 和商业账户体系。若未来公开分发，重新启用许可证、签名、依赖再分发和隐私材料审计。

## 7. 产品信息架构

```text
DesktopUp 常驻运行时
├─ Desktop Poster Surface    桌面海报；默认持续可见
├─ Control Center / Home     主页与管理中心；按需创建或显示
├─ Settings / AI             控制中心路由或按需表面
├─ Native Tray               常驻轻量入口
├─ Application Core          状态、命令、生命周期、安全操作
└─ State / Recovery Store    持久状态、迁移、账本、备份与恢复材料
```

四个用户可感知角色必须分离：

- 海报负责展示和启动；
- 控制中心负责管理、编辑、预览和诊断；
- 托盘负责快速入口、全局状态和退出；
- 设置/AI 负责高级配置，不是后台必需表面。

## 8. 主页、托盘与海报关系

### 8.1 海报

- 正常运行时唯一持续可见的 DesktopUP 界面；
- 无 Windows 原生标题栏、无任务栏按钮、默认不进入 Alt+Tab；
- 不抢前台焦点；
- 非交互透明区域穿透；
- 标题栏、按钮和 Item 只在登记命中区接收输入；
- 生命周期独立于控制中心；
- 桌面挂载失败时进入明确回退或错误状态，不能打开主页伪装成功。

### 8.2 控制中心/主页

- 是普通、可聚焦、可进入任务栏和 Alt+Tab 的窗口；
- 从托盘、开始菜单、快捷方式或普通第二实例主动打开；
- 页面至少覆盖海报与项目、主题参数、自动布局、性能与暂停、启动与系统集成、备份恢复、AI 和诊断；
- 内部海报画布是编辑投影，不是真实桌面宿主；
- 预览与真实海报读取同一快照，修改走同一命令；
- 关闭后不影响海报，且释放预览动画和非必要渲染资源；
- 反复打开关闭只能存在一个控制中心实例。

### 8.3 托盘

- 由原生/后台核心拥有，不依赖控制中心常驻；
- 单击无动作；
- 双击切换控制中心；
- 右键菜单提供主页、设置、海报显隐、编辑、全局锁定、暂停、快速主题、自启、桌面重连、AI 配置和退出；
- Windows 决定图标在主通知区域或折叠栏的位置，应用不修改系统排列。

### 8.4 生命周期矩阵

| 事件 | 海报 | 控制中心 | 托盘/进程 |
| --- | --- | --- | --- |
| 普通首实例启动 | 显示已启用海报 | 不创建或隐藏 | 唯一托盘、进程运行 |
| `--autostart` 首实例 | 显示静态海报 | 不创建、不聚焦 | 进程运行 |
| 托盘单击 | 不变 | 不变 | 不变 |
| 托盘双击 | 不变 | 显示时关闭/释放；不存在时创建并显示 | 不变 |
| “打开主页” | 不变 | 创建或显示并聚焦 | 不变 |
| “显示全部海报” | 显示/隐藏 | 不变 | 不变 |
| 关闭控制中心 | 不变 | 释放优先，失败才隐藏 | 继续运行 |
| 普通第二实例 | 不重复创建 | 唤回唯一控制中心 | 第二实例退出 |
| 第二实例 `--autostart` | 不变 | 不变 | 第二实例静默退出 |
| 显式退出 | 销毁 | 销毁 | 移除托盘后结束 |

## 9. 海报视觉与几何

### 9.1 默认快照

```text
monitor = primary
anchor = top-right
presentation = EXPANDED
interaction = USING
runtime = ACTIVE_STATIC
is_locked = false
auto_collapse_enabled = false
template = transparent-default（暂名）
```

首个可用范围为主屏单海报。数据关系可以为未来多海报保留，但 V2 初期不提供多海报创建 UI。

### 9.2 默认几何

| 属性 | 需求 |
| --- | --- |
| 默认显示器 | 主显示器 |
| 默认锚点 | `top-right` |
| 默认位置 | 主显示器工作区右侧，保留安全边距 |
| 默认宽度 | `max(工作区宽 × 0.22, 280px)` |
| 最小宽度 | 240px |
| 最大宽度 | 当前工作区宽度 45% |
| 默认展开高度 | 工作区高度减去安全边距 |
| 最小展开高度 | 240px；仍需在实现契约中验证内容可读性 |
| 最大展开高度 | 工作区高度减去上下安全边距 |
| 收起高度 | 约 60px 的标题条 |
| 恢复方式 | 显示器身份 + 归一化锚点优先，绝对坐标只作回退 |

### 9.3 几何不变量

- `FrameGeometry`、`ContentMetrics` 与 `ResponsiveLayout` 是三组独立状态：外框几何描述海报在桌面上的位置和可视窗口；内容参数描述标题、Item、图标、间距与密度；响应式布局只负责在当前视口中重排和裁剪；
- 同一 DPI 下拖动外框缩放，只改变视口和布局约束，不得隐式缩放或改写标题、Item、图标、间距和密度；DPI 变化只改变逻辑单位到设备像素的投影，不得反向覆盖用户内容参数；
- 收起/展开只改变高度；标题栏顶部、水平位置和宽度保持不变；
- 展开恢复收起前宽高；
- 右下角缩放固定左上角；
- 尺寸受动态工作区限制，不能只依赖窗口或样式默认值；
- 提交失败保留最近已接受状态和待处理意图，不能闪回；
- 分辨率或工作区变化后迁回可见区域；锁定不允许永久不可见；
- 多显示器和跨屏恢复属于后续认证，不得在单屏实现中伪造通过。

### 9.4 视觉完整性硬门

- 无原生标题栏、顶部白条、亮带、灰色透明包络和宿主未绘制背景；
- 圆角、边框、阴影和透明边界完整，无矩形裁切；
- 冷启动、首帧、拖动中、松开后、控制中心开关后、Win+D 后一致；
- 不通过临时置顶、整屏宿主或扩大输入区掩盖视觉问题；
- 壁纸明暗变化时，文字和 Item 仍具基本可读性。

## 10. 海报状态与权限

```text
海报状态 = 呈现模式 × 交互模式 × 运行时模式 + 锁定属性

呈现：EXPANDED / COLLAPSED
交互：USING / EDITING
运行时：ACTIVE_STATIC / ACTIVE_ANIMATED / PAUSED / STOPPED
锁定：is_locked boolean
```

交互模式和运行时模式不作为 Poster 业务持久状态；重新启动从 USING 开始，运行时模式由可见性和主题能力派生。

### 10.1 权限矩阵

| 状态 | 标题栏拖动 | 内容区拖动 | 缩放 | Item 单击 | 收起/展开 | 锁定 |
| --- | --- | --- | --- | --- | --- | --- |
| USING + EXPANDED + unlocked | 允许 | 禁止 | 禁止 | 启动 | 允许 | 允许 |
| USING + COLLAPSED + unlocked | 允许 | 不存在 | 禁止 | 不存在 | 允许 | 允许 |
| EDITING + EXPANDED + unlocked | 允许 | 允许移动海报或按规则拖 Item | 允许 | 选择 | 允许 | 允许 |
| EDITING + COLLAPSED + unlocked | 允许 | 不存在 | 禁止 | 不存在 | 允许 | 允许 |
| 任意 + locked | 禁止 | 禁止 | 禁止 | USING 时仍可启动 | 允许 | 允许解锁 |
| 手动暂停动态效果 | 保持普通权限 | 保持普通权限 | 保持普通权限 | 保持普通规则 | 允许 | 允许 |
| 锁屏/显示器关闭/退出/宿主未就绪 | 禁止 | 禁止 | 禁止 | 禁止 | 禁止 | 禁止 |

### 10.2 收起与自动收起

- 收起态只显示约 60px 标题条，不显示 Item；
- 标题文字或展开按钮可恢复；
- 快速连续点击按最后意图处理，建议去抖约 300ms；
- 自动收起默认关闭；启用后离开热区 1–300 秒进入收起，默认 3 秒；
- 编辑态暂停自动收起，退出编辑后重新计时。

### 10.3 暂停与停止

- “暂停动态效果”只停止动画和持续绘制，不冻结按钮；
- 锁屏、显示器关闭、系统不可见等系统暂停可同时禁用输入；
- PAUSED 保留最后一帧，不补播错过动画；
- STOPPED 释放可选画布、大图和代码主题资源；
- 恢复保持呈现模式，但交互回到 USING。

## 11. 标题栏、命中和桌面输入

标题栏是海报自制内容，不是 Windows 非客户区。同行至少包含标题、模板标识、Item 数量、收起/展开和锁定/解锁。

- 模板可改变外观，不能改变按钮语义和命中契约；
- 未锁定时，标题栏空白和允许的非交互文字可以拖动；
- 按钮、链接、输入、Item 和显式 `no-drag` 节点排除；
- 移动达到 5px 才判定拖动；
- USING 下卡片间隙和其他透明空白穿透；
- 空白左键拖动产生 Windows 桌面框选；
- 空白右键显示 Windows 桌面菜单，不显示浏览器菜单；
- 海报覆盖范围下的桌面快捷方式仍可点击；
- Item 卡片自身命中；编辑态单击选择，使用态单击产生一次启动意图；
- 右键菜单打开期间阻止冲突操作，关闭后恢复。

## 12. 控制中心编辑

### RP-EDIT-01 预览投影

控制中心将真实桌面坐标按比例投影到可变画布。控制中心窗口改变大小时，海报预览始终可见、比例正确，不使用桌面绝对坐标直接定位。

### RP-EDIT-02 单向提交

预览不拥有第二套几何或主题状态。所有修改通过版本化命令和 expected-revision/CAS 提交；冲突、拒绝或失败显示真实结果，不能先乐观保存再刷新回退。

### RP-EDIT-03 连续操作

- 连续拖动至少三次仍可继续；
- 编辑态可连续拖动和多次改变宽高；
- 关闭重开后投影正常；
- 编辑不能让真实海报覆盖控制中心；
- 编辑后真实海报仍能拖动、锁定和收起/展开。

### RP-EDIT-04 主题预览

参数调整即时作用于隔离预览；保存后才写入正式 ThemeInstance，并进入统一撤销栈。取消、冲突或预览失败恢复保存前状态。

## 13. 内容 Item 模型

正式产品必须以数据驱动 Item 替代 `NIGHT OPS` 六张演示卡片。演示卡片只用于构图、交互和渲染验证。

### 13.1 CollectionItem

至少表达：稳定 ID、类型、显示名、标签、来源类型与来源身份、启动目标、参数、工作目录、图标来源、有效性、托管关系、累计启动、最近启动、有限历史、加入时间和诊断状态。绝对路径不得作为唯一身份。

### 13.2 PosterItem

表达 Item 与海报的关系：`poster_id`、`item_id`、`order_key`、锚定状态、可选页码和局部位置。未来同一 Item 可以出现在多张海报，但初期产品只创建一张海报。

### 13.3 零、一、多、失效和重复

- 零 Item：标题显示 0，展开态展示非模态添加引导；
- 一个 Item：仍使用稳定布局，不为填满海报无限放大；
- 多 Item：由确定性布局快照驱动；
- 失效 Item：保留可见和诊断状态，不能静默丢弃；
- 重复 Item：按路径、目标、来源身份和内容指纹提示，由用户决定；
- 图标缺失：显示首字母占位，不让 Item 消失。

## 14. 发现、添加、启动和安全收纳

### 14.1 主动入口

首版只允许用户主动拖入 `.lnk/.url/.exe`，或点击“扫描桌面”后选择当前用户/公共桌面。冷启动不静默扫描。

### 14.2 仅添加

- `.lnk` 按 Shell 语义解析 target、arguments、working directory 和 icon；
- `.url` 校验协议白名单；
- `.exe` 只登记启动入口；
- 写入前逐项预览名称、类型、来源、目标、图标、冲突和错误；
- “仅添加”不改变源文件。

### 14.3 启动

- 保留完整快捷方式语义，不把带参数快捷方式简化为路径启动；
- USING 单击启动，EDITING 单击选择；编辑态启动方式在实施前冻结；
- 单击/双击检测只产生一次启动；
- 提供打开文件位置；
- 启动失败结构化提示，不导致海报崩溃。

### 14.4 安全收纳

```text
Discover → Parse → Preview → Confirm
→ PENDING 账本 → 复制到保险库临时位置 → 校验大小/指纹
→ 原子提交保险库副本 → 移走原快捷方式 → MANAGED
```

只允许托管 `.lnk/.url`。失败时不覆盖现有文件；移走前必须有可验证副本和账本；启动时恢复未完成事务；恢复同名冲突不覆盖；恢复失败保留保险库和重试入口。

## 15. Item 活跃度与动态排版

### 15.1 排名目标

活跃内容应更易发现，但不能让新项目或长期内容永久消失。排序必须可解释、确定、可撤销，并允许三层人工控制。

```text
rank_score = 0.40 × recency_norm
           + 0.35 × frequency_norm
           + 0.25 × newness_norm
```

- `recency_norm`：最近 7 天线性衰减；
- `frequency_norm`：有效启动次数经过对数归一化；
- `newness_norm`：新加入项目获得曝光，随年龄下降；
- 相同输入得到相同结果；同分使用稳定 ID/order key 作为确定性打破规则；
- 计算列不作为权威持久化值。

### 15.2 动态缩放

```text
ratio = log(1 + launches) / log(1 + max_launches_in_poster)
scale = min_scale + (max_scale - min_scale) × ratio
```

- 用户可调 50%–300%；
- 无历史的新 Item 使用约 150% 默认比例，不直接落到最小；
- 排名比尺寸更敏感，尺寸端增加压缩以减少视觉跳动；
- 缩放变化使用轻微弹性过渡，暂停时停止，恢复不补帧。

### 15.3 刷新节奏

- 冷启动后延迟计算，不阻塞首屏；
- 启动游戏后只标记待重排，不让刚点击的卡片立刻跳走；
- 下次展开或手动刷新时重排；
- 不设置后台高频定时器。

### 15.4 布局与控制

- 默认确定性网格；增强布局使用行式弹性流和小 Item 子列填充；
- 海报空间不足时分页或连续滚动，不无限缩小、删除或永久隐藏 Item；所有 Item 必须保持可达；
- Item 视口对上下边缘执行连续像素裁剪；不足整行高度时允许显示部分行，禁止按整行量化后让一整排突然消失并留下不可解释的大空白；
- 滚动偏移必须连续，不得按整行步长跳动；绘制和命中都不得越过 Item 视口侵入标题区或底栏；
- Item 视口自身必须提供独立滚动入口，即使当前没有完整 Item 可见，也不能因命中目标消失而形成“无法继续滚动”的死锁；
- 外框缩放跨越列数或行数阈值时必须保持当前指针捕获，一次按下可连续完成缩放，不能要求用户松开后重新按下；
- 第一层全自动；第二层锚定+自动；第三层全手动；
- 锚定项保持序号，非锚定项填充空位；冲突按稳定规则偏移；
- 所有自动调整可撤销；
- 拖动阈值为 5px，拖动过程显示占位和插入线。

### 15.5 跳变机制

只有“原排名在下半区 + 用户拖到上半区并锚定 + 5 分钟内真实启动”三项同时满足，才给予临时曝光提升。提升只改变排序分，不伪造启动次数或直接把图标放大到最大；约 3–5 天衰减，真实活跃追上后自动退出。

旧公式中“30 天存在保护”与低启动次数相乘的具体数学表达存在矛盾，V2 保留产品语义但将公式校正列为 `TBD`，实现前必须用样例和性质测试冻结。

## 16. 海报视觉体系

### 16.1 默认参考构图

`NIGHT OPS` 原型提供默认构图参考，而不是硬编码内容：右侧高纵向半透明海报、顶部 collection/index、标题与副信息、3×2 Item 卡片、底部状态栏、右上锁定与收起按钮。正式数据必须替换六张演示卡片，模板可以改变风格但不能删除受保护交互。

### 16.2 首发视觉角色

| 模板 | 角色 | 核心方向 |
| --- | --- | --- |
| `transparent-default`（暂名） | 默认 | 高透明、低装饰、低焦点、优先与壁纸融合 |
| `neon-hud` | 可替换 | 冷色霓虹、HUD 线条、扫描线、数据化排版 |

- 静态主题无持续动画；
- 收起/展开只改变高度，建议 250ms；

## 17. 主题平台

### 17.1 四级定制

| 深度 | 能力 | 必须满足 |
| --- | --- | --- |
| 0 | 预设与开关 | 一键、即时预览、可恢复默认 |
| 1 | 颜色、透明、模糊、间距、尺寸等结构化参数 | schema 自动生成面板、范围校验 |
| 2 | 图片、SVG、字体、Logo 等素材 | 类型/大小/路径校验、净化、应用自有副本 |
| 3 | 受限样式和结构插槽覆盖 | 隔离、安全扫描、受保护节点、错误回退 |

### 17.2 技术中立隔离

无论最终使用 Web、Qt 或原生渲染，必须提供等价能力：模板不能污染控制中心和其他海报；参数、素材和结构覆盖只作用于所属海报；模板不能直接调用通用文件、网络、进程、注册表或原生 IPC；宿主拥有命中、拖动、暂停和错误边界。

### 17.3 热切换

在离屏/临时实例中构建、校验后原子替换；快速连续切换只执行最后意图；失败恢复旧模板和参数；正常切换目标低于 200ms，不含完整布局重算。

### 17.4 导入导出

- 参数快照包：结构化参数，载荷上限 64KB；
- 参数与素材包：参数、素材及必要元数据，总上限 20MB；
- 完整模板包：清单、参数契约、模板结构、样式、预设、素材和可选覆盖，总上限 20MB；
- 三类包的序列化格式、容器和文件扩展名由后续架构阶段决定，不能在需求阶段预绑定 JSON 或 ZIP；
- 路径穿越、symlink/junction、压缩炸弹、文件数、单文件大小、类型、图片、SVG、字体、样式和结构都必须校验；
- 完整模板、索引和引用原子安装；失败不留下半安装；
- 卸载前迁移全部引用，失败则拒绝卸载。

## 19. 数据与状态

- 正式业务状态使用支持事务、修订/CAS、迁移、备份和故障恢复的单一权威存储；具体存储引擎、库和绑定在技术选型阶段确认；
- schema 独立版本化；contract version 不代替 schema version；
- 写入严格校验和事务；mutation 使用 revision/expected-revision/CAS；
- 冲突返回结构化结果，不用最后写入覆盖；
- 损坏、未知版本、I/O 失败和无数据必须区分；
- 只有明确无数据且迁移完成时才能创建默认值；
- JSON/localStorage 只作为只读迁移来源，原始数据完整备份，迁移幂等；
- 不持久化 HWND、物理像素、DPI、命中区域、USING/EDITING、运行暂停原因和性能采样。

Poster 持久字段至少包含：身份、标题/副标题、显示器身份、锚点、归一化矩形、宽高、收起状态、自动收起配置、锁定、布局类型/参数、模板键和 revision。

## 20. 错误、空状态与降级

- 当前模板样式或结构失败：优先保留或回滚到上一份已验证可用模板与参数；
- 不存在任何上一份有效模板时，才进入受保护的最小标题栏、Item 容器和安全样式；
- 参数 schema 失败：海报继续运行，控制中心标明参数不可编辑；
- 图标缺失：显示首字母占位；
- Item 目标失效：保留 Item 和诊断，可移除或修复；
- 数据损坏：尽量从合法字段恢复，无法恢复时显示安全空海报和恢复入口；
- 渲染崩溃：有限次自动重建，重复失败逐级通知并停止无限重试；
- fallback 不得写回覆盖用户模板选择；
- 零 Item 展开态显示非模态“拖入快捷方式/扫描桌面/打开控制中心”引导。

- 安装器目标名 `DesktopUpSetup.exe`；
- 当前用户免提权；
- 默认目录 `%LOCALAPPDATA%\Programs\DesktopUp`；
- 至少包含 `DesktopUp.exe`、独立 `uninstall.exe` 和资源目录；
- 禁止广告和捆绑；个人自用阶段不要求公开许可证载荷。

### 24.2 自启

- 默认关闭，只由用户显式开启；
- 使用 Windows 当前用户范围、可查询且可逆的自启机制；具体注册位置或系统 API 由生命周期架构决定；应用自启标识固定为 `DesktopUp`；
- 命令指向正式安装路径并携带精确 `--autostart`；
- 开发/便携路径拒绝写入；
- 写后读回再更新 UI；
- 禁用只删除应用自有值。

### 24.3 升级与卸载

- 升级前备份状态、schema 和恢复账本；迁移事务化且失败回滚；
- 卸载先请求安全退出，再恢复托管快捷方式、清自启和集成、清应用自有数据、删程序并自删除；
- 恢复失败时保留保险库和账本，输出部分成功和重试入口；
- 不删除游戏、平台目录、外部主题源或普通用户文件。

## 25. 可用性、无障碍与本地化

- 核心操作不依赖复杂设置，首次使用目标三分钟；
- 拖动阈值防误触，收起/展开按钮位置稳定；
- 失败提示简短、可行动并保留原状态；
- 高 DPI 下托盘和命中清晰；
- Tab/Enter/Escape/Delete 基础键盘行为预留；
- 颜色、透明和动效可调整，暂停动画可用；
- 屏幕阅读器、高对比、系统减少动态映射、多语言和完整键盘重排仍需在发布计划中冻结范围。

## 26. 认证范围

### 初始认证目标

- Windows 11 x64；
- 主屏单海报；
- 在单主显示器环境分别验证 100%、125%、150%、200% 缩放；这不等同于混合 DPI 或跨屏认证；
- 外框尺寸至少覆盖 240px、280px、360px、默认宽高、宽扁和窄高形态；验证内容参数不被外框缩放改写、跨列/跨行重排不丢失捕获、部分行连续裁剪、全部 Item 可达以及底栏不被内容覆盖；
- 桌面空白/图标、层级、锁定、收起、拖动、缩放、Win+D、Explorer 恢复、控制中心和托盘矩阵；
- 正式 Item 的零/一/多/失效/重复数据夹具；
- 状态恢复、CAS、主题失败回退和退出顺序。

### 明确延期

- 多海报创建 UI；
- 第二显示器、混合 DPI、负坐标、主屏切换、跨屏重启和热插拔；
- 在线主题市场、账户和云同步；
- AI 图片重绘、语音和多 Agent；
- 任意原生插件和无限权限脚本。
