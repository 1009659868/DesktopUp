## 5. 不继承为 V2 权威的旧决定

以下只存在于历史快照，不得用于实现立项：

- 单全局透明 WebView2 宿主；
- 每张海报 Shadow Root 作为唯一隔离实现；
- Rust 校验 + JavaScript 渲染的方案 C；
- `put_DefaultBackgroundColor` 被描述为顶部亮带根治；
- WebView2 窗口、PrintWindow 或特定 DWM 探针作为普适渲染真相；
- 不经实验就优先 Direct2D/DirectComposition、Qt 或任何候选；
- 旧 A0 演示状态被当作 V2 当前实现；
- 旧实现路径、模块文件名、Tauri 命令和 IPC 名称。

## 6. 已规范化的冲突

### 6.1 USING 双击

旧交互文档同时写“单击启动”和“双击启动+标记最近活跃”。游戏/启动器预设保留：USING 单击发出一个启动意图；双击序列仍只产生一次启动和一次统计，不增加第二种运行态语义。EDITING 双击保持单独待决。 通用文件格新增选择/打开手势问题由 V2-TBD-013 及 V3-05-06 裁决，不由上述历史游戏语义覆盖。

### 6.2 30 天衰减保护

旧衰减公式与“新 Item 完全免疫”样例矛盾。V2 保留产品性质，公式列为 `ACT-TBD-01`，不得照抄。

### 6.3 编辑态启动

旧状态机存在“编辑态单击不启动、双击可选启动”的摇摆。V2 固定单击选择；双击策略保持待决。

### 6.4 主题默认与 fallback

`transparent-default` 保留正常模板角色，通用 Box 和 NIGHT OPS 游戏海报按用途形成不同预设；`minimal-fallback` 只用于错误，不合并为正常选择且不写回用户选择。

### 6.5 锁定与自动布局

锁定保护海报外部几何和人工重排。已裁决（2026-08-18）：锁定不影响内部自动排名、布局计算和主题参数等内部逻辑；任何变化都不能移动海报框或绕过用户选择的全手动模式。
