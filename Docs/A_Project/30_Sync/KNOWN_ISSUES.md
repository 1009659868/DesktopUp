## 1. 使用说明

本台账在“仅文档迁移”阶段记录未来重构必须解决的历史风险、尚未冻结的产品决策和明确暂缓范围。当前 V2 尚无实现，因此历史故障不能被写成“V2 当前 Bug”，但必须保留为候选方案的淘汰条件。

## 2. 历史防回归风险

### V2-RISK-001：透明海报顶部出现白色或浅色条带

| 字段 | 内容 |
| --- | --- |
| 类型 | `ARCHITECTURE / RENDERING RISK` |
| 状态 | `OPEN — FUTURE SOLUTION MUST DISPROVE` |
| 历史表现 | 海报位于屏幕中部时，打开控制中心后拖动真实海报，顶部出现固定高度白条；后续尝试曾演化为灰色透明边框、整屏顶部白条或常驻条带。 |
| 已知教训 | 不能把屏幕边缘、壁纸、CSS 贴边、单纯坐标误差或一次截图当作根因；必须区分应用内容、宿主窗口非客户区、透明合成层和桌面父子层级。 |
| V2 要求 | 技术候选必须具备可观察的呈现边界，能区分宿主、客户区、透明表面和最终屏幕合成；拖动、缩放、显隐、控制中心开关、DPI/分辨率变化均不得产生条带。 |
| 关闭条件 | 未来选定方案在定义的实机矩阵中持续通过“零条带、零异常边框”，并有可重复诊断证据。 |

### V2-RISK-002：海报短暂或持续覆盖普通程序

| 字段 | 内容 |
| --- | --- |
| 类型 | `WINDOW OWNERSHIP / Z-ORDER RISK` |
| 状态 | `OPEN` |
| 历史表现 | 打开控制中心、编辑拖动、桌面右键、文件选择、刷新或系统焦点变化后，海报短暂置顶或持续覆盖普通程序。 |
| V2 要求 | 桌面海报必须处于桌面图标关系中定义的层级；控制中心、托盘、文件对话框和普通应用不得改变其长期层级。发生 Explorer 重建时允许受控恢复，不允许先顶层闪烁再回落。 |
| 关闭条件 | 窗口关系测试和系统事件矩阵通过，且失败时可记录当前 owner、parent、z-order 意图与实际值。 |

### V2-RISK-003：控制中心编辑后真实海报拖动、缩放或命中失效

| 字段 | 内容 |
| --- | --- |
| 类型 | `INTERACTION / STATE AUTHORITY RISK` |
| 状态 | `OPEN` |
| 历史表现 | 预览拖动一次后无法继续拖动；进入编辑模式也无法调整长宽；预览与真实海报可能重叠、分离或互相覆盖。 |
| V2 要求 | 预览是状态投影，真实海报是运行表面，两者经同一权威状态和带版本命令同步；任何操作不能静默更换输入命中所有权或留下悬空编辑会话。 |
| 关闭条件 | 连续拖动/缩放/取消/提交/关闭重开矩阵通过，且无重复实例或失效命中区。 |

### V2-RISK-004：参数和状态回弹

| 字段 | 内容 |
| --- | --- |
| 类型 | `STATE CONSISTENCY RISK` |
| 状态 | `OPEN` |
| 历史表现 | 风格预设或视觉滑杆修改后立即回到旧值；跨控制中心、托盘和海报可能出现状态不同步。 |
| V2 要求 | 单一权威状态、修订号/CAS、草稿与提交边界、失败保留和冲突反馈必须明确；UI 不得用旧快照覆盖刚提交的新状态。 |
| 关闭条件 | 并发、重开、失败、退出恢复和版本冲突测试全部通过。 |

## 3. 当前产品待定项

### V2-TBD-001：未来技术候选与选型顺序

状态：`RESOLVED — 路线甲`。用户裁决（2026-08-18）：Qt 6 Quick/QML 优先，原生 D2D/DirectComposition 保底，Web 主题路线按需并行；内存预算原型实测后放宽；渲染器为 C++ 侧车进程 + IPC。执行载体：B-RND/C-QTP（见 `TECH_SELECTION_CANDIDATES_V1.md` §8）。

### V2-TBD-002：活跃度衰减精确公式

状态：`OPEN`。产品属性已经冻结：新增或近期使用的 Item 具有保护期，长期不用逐步衰减，高频项目应更耐衰减，固定项目不受自动排序影响。V1 公式把频次阻力直接相乘，可能破坏“30 天免衰减”语义；V2 只保留性质，待用数据样例重新标定公式。

### V2-TBD-003：动态排版阈值与视觉密度默认值

状态：`OPEN`。分栏、弹性流和爆发模型已定义，但 `MAX_POSTER_VISIBLE_ITEMS`、最小卡片尺寸、动效持续时间和重排防抖值需在未来原型中标定。

### V2-TBD-004：V2 默认正式主题

状态：`OPEN`。Night Ops、Neon HUD 和 Cinema Lightbox 均已迁入设计语言；哪一套作为 V2 出厂默认，以及透明度、背景材质和卡片密度的默认值，等待视觉评审。

### V2-TBD-005：主题扩展的最终安全边界

状态：`OPEN`。已经冻结“不得执行不受限原生代码或主题脚本、必须声明能力并隔离失败”，但具体声明格式、签名策略、主题市场来源和兼容层级需在架构阶段决定。

### V2-TBD-006：AI 低风险动作是否允许自动执行

状态：`OPEN`。默认要求 AI 先生成可审查 ChangePlan；是否允许用户显式开启部分 R0/R1 操作自动执行，以及撤销窗口多长，待产品决策。

### V2-TBD-007：编辑态双击行为

状态：`OPEN`。运行态 Item 双击启动已确定；编辑态双击是启动、进入属性还是禁用，需避免与拖动/选中冲突后再冻结。
