# Desktop-Up 海报交互事件映射 V0.1

状态：`ACTIVE DESIGN BASELINE`

日期：2026-08-03

## 1. 目的

汇总用户在海报上可执行的所有交互操作，明确每种操作的触发条件、在不同状态下的行为差异，以及与排序控制层和模板系统的关系。本映射是前端事件绑定和 Rust 命令路由的参考来源。

### 3.4 右/下边缘（仅 EDITING + EXPANDED）

| 操作 | 行为 |
|------|------|
| **鼠标悬浮右边缘** | 光标变为 `ew-resize` |
| **左键拖动右边缘** | 调整海报宽度，实时吸附预览线 |

### 3.5 键盘操作

| 按键 | USING + EXPANDED | EDITING + EXPANDED |
|------|------------------|---------------------|
| **↑ ↓ ← →** | 无操作（由 Accessible 层处理，不做海报级导航） | 移动选中的图标到相邻位置（如排序层允许） |
| **Enter** | 启动选中的游戏（如有焦点） | 启动选中的游戏 |
| **Delete** | 无操作 | 从海报移除选中图标（弹出确认） |
| **Escape** | 无操作 | 退出 EDITING → USING |
| **Tab** | 焦点在图标间循环 | 焦点在图标间循环 + 手柄 |

## 5. 拖拽与排序控制层的关系

### 5.1 图标拖拽（EDITING 态）

```
用户左键按住图标卡片
  → 检测拖动阈值 (>5px)
  → 图标进入拖拽态：
      - 原位置保留半透明占位
      - 拖拽中的图标 z-index 提升
      - 经过有效插入位置时显示蓝色插入线
  → 用户释放

  结果取决于排序控制层：
    第 1 层（全自动）：
      → 拖拽不被允许。用户尝试拖拽时图标弹回原位，显示提示"右键图标固定到位置后可拖拽"
    第 2 层（锚定+自动）：
      → 拖拽创建新锚定记录（pinned_index = 释放位置序号）
      → 图标显示图钉标记
      → 非锚定项在锚定项空隙中自动排序
    第 3 层（全手动）：
      → 拖拽直接改变 order_key
      → 不创建锚定记录
      → 无自动排序
```

### 5.2 海报拖动（EDITING 态）

```
左键在海报任意区域按住（非图标卡片）
  → 检测拖动阈值 (>5px)
  → 海报进入拖动态：
      - 窗口跟随鼠标移动
      - 贴边时显示吸附预览线（8px 间距）
      - 移动事件合并 300ms 写盘
  → 用户释放
  → 持久化新位置 (PosterPlacement)
```

### 5.3 宽度调整（EDITING 态）

```
鼠标悬浮右边缘 → 光标变为 ew-resize
  → 左键拖动
  → 宽度实时变化，触发图标重排
  → 释放后 600ms 去抖写盘
  → 持久化新宽度 (Poster.width)
```

## 6. 拖拽触发跳变的交互时序

来自 `POSTER_LAYOUT_AND_SORT_V0.1` §5：

```
1. 用户拖拽底部 50% 的图标到上半区并释放
   → 锚定记录创建 (pinned_index = 新位置)

2. 在接下来 5 分钟内，用户点击启动该游戏
   → 系统检测：该图标满足跳变三条件
     a. 拖拽前 rank_score 在下半区 ✓
     b. 5 分钟内启动 ✓
     c. 用户手动拖拽并锚定 ✓
   → 触发跳变：burst_rank_score 计算，图标显示上升箭头动画 (600ms)

3. 此后每次正常启动：
   → burst_multiplier × 0.7
   → total_launches += 1

4. 每天自动衰减：
   → burst_multiplier × 0.5

5. 当 original_rank_score ≥ burst_rank_score：
   → burst_bonus = 0，跳变结束
   → 静默提示"已回归自然排序"
```

## 7. 事件冲突处理规则

| 冲突 | 规则 |
|------|------|
| 单击 vs 双击（图标） | 双击检测窗口 400ms。单击启动只执行一次，不因双击重复启动 |
| 拖动 vs 单击（图标） | 拖动阈值 5px。移动 < 5px 视为单击；≥ 5px 视为拖动 |
| 滚动 vs 穿透 | 图标区域拦截滚轮；空白区域不拦截（穿透到桌面） |
| 右键菜单打开时其他交互 | 菜单打开时阻止其他海报交互，菜单关闭后恢复 |
| EDITING 超时 vs 未保存 | 编辑即保存（位置/宽度/排序变更即时写盘）。只有锚定操作需要显式确认 |
| auto_collapse vs 编辑态 | 编辑态不触发自动收起；退出编辑后重新计时 |
| 全局 EDITING 模式 vs 锁定海报 | 锁定海报在全局 EDITING 中仍处于 USING 交互态 |
