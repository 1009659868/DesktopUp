# Desktop-Up 制作与交付计划 V0.1

状态：`PROPOSED`

日期：2026-08-02

## 1. 交付目标

完成一个可在 Windows 11 x64 安装、运行、升级和完整卸载的 `DesktopUpSetup.exe`。安装后的核心体验是：创建游戏海报、导入或收纳快捷方式、自动排版、启动游戏、折叠海报、自动暂停，并能安全恢复数据。

## 2. 里程碑与阶段门

### M0：工程与桌面宿主验证

交付：

- Rust/Tauri/Svelte 最小工程；
- 通知区域图标、原生右键菜单骨架和单实例；
- 透明桌面宿主原型；
- 一张可点击、可拖动的假数据海报；
- 全屏与锁屏暂停探针；
- 关闭主页隐藏到托盘、显式退出结束进程的生命周期探针；
- 性能采样脚本和兼容性记录。

阶段门：`C-DHF-01..08` 全部通过。任何硬门失败都必须先选择修正、回退模式或技术栈调整，不能直接进入完整主题开发。

参考工作量：5–8 个有效开发日。

### M1：本地收纳 MVP

交付：

- `.lnk`、`.url`、`.exe` 拖入，以及用户主动发起的桌面扫描；
- 写入前的解析、图标提取、去重、逐项预览与确认；
- “仅添加”和“收纳并移出桌面”两种明确模式；
- 海报创建、删除、拖动、缩放、锁定、展开和收起；
- 网格排版与局部重排；
- 快捷方式保险库、两阶段恢复账本、异常事务恢复和撤销；
- SQLite 数据与迁移；
- 3 个静态主题；
- 托盘主页/设置、显示/隐藏、编辑、暂停和快速主题切换。

实施切片：A1.0 数据/只读扫描 → A1.1 预览/仅添加 → A1.2 安全收纳/撤销 → A1.3 启动/异常与卸载恢复。详细契约见 [`快捷方式导入与安全收纳模型 V0.1`](SHORTCUT_IMPORT_AND_COLLECTION_MODEL_V0.1.md)。

阶段门：连续完成 100 次导入/收纳/恢复故障注入，不覆盖或丢失用户快捷方式；无主动操作不扫描或改变桌面；`.exe` 永不被移动或复制。

参考工作量：10–15 个有效开发日。

### M2：主题与控制中心

交付：

- 主题参数 schema 和自动设置面板；
- 素材主题导入、校验、预览、导出；
- 动画暂停、限帧和按应用规则；
- 控制中心、托盘操作、备份与恢复；
- 统一 DesktopCommand、ChangePlan、预览和撤销契约，为手动 UI 与 AI 共用。

阶段门：恶意路径包、超大包、外链 CSS 和损坏主题均无法突破应用数据边界；主题卡死不导致主进程无法退出。

参考工作量：8–12 个有效开发日。

### M3：可选本地 AI 助手

交付：

- OpenAI、DeepSeek 和 OpenAI-Compatible Provider 配置；
- Windows Credential Manager Key 存取与删除；
- 无 Key 不初始化、不联网的启动门；
- 测试连接、流式对话和取消；
- 海报参数、图标尺寸/间距、排序和主题预设 Tool Calls；
- ChangePlan 预览、确认、应用与撤销；
- JSON/DSL/CSS/SVG 主题草稿和隔离预览。

阶段门：无 Key 冷启动没有 AI 网络活动；Key 不进入前端、数据库或日志；无效工具调用无法越过本地校验；API 失败不影响桌面宿主。受限 JavaScript 主题不阻塞本阶段。

参考工作量：10–20 个有效开发日，取决于主题 DSL 和隔离预览完成度。

### M4：游戏平台发现

交付：

- Steam、Epic 本地安装发现；
- Xbox/Microsoft Store Shell 项目枚举；
- 去重、来源角标和手动修正；
- 扫描开关、隐私说明和取消能力。

阶段门：没有任何平台客户端时功能正常；扫描失败不影响手动导入。

参考工作量：5–8 个有效开发日。

### M5：发布与卸载封板

交付：

- Release 构建、签名入口和许可证清单；
- `DesktopUpSetup.exe`；
- 安装目录内 `uninstall.exe`；
- 升级迁移、卸载恢复和自清理；
- 用户快速入门、故障排查和隐私说明。

阶段门：净机安装/升级/卸载矩阵全部通过，没有残留启动项、运行进程和不应保留的应用文件。

参考工作量：5–8 个有效开发日。

## 3. 实施顺序

```text
桌面宿主硬门
  → 数据模型与只读扫描
  → 导入预览与“仅添加”
  → 恢复账本与安全收纳
  → 单海报完整闭环
  → 多海报和自动布局
  → 主题参数/素材
  → 统一命令/预览/撤销
  → 可选 AI Provider 与受控 Agent
  → 游戏来源扫描
  → 性能与兼容性封板
  → 安装、升级、卸载验收
```

代码主题在素材主题、统一命令和隔离预览稳定后开始。AI 参数控制可以进入首版；受限 JavaScript 主题不得阻塞最小可发布版本。

## 4. 能力模块顺序

| 顺序 | B 模块 | 主要结果 |
| --- | --- | --- |
| 1 | Desktop Runtime Foundation | 桌面宿主、暂停、托盘、自启、恢复 |
| 2 | Collection and Launch | 导入、收纳、恢复、启动和元数据 |
| 3 | Poster Layout and Interaction | 锚点、拖拽、折叠和排版 |
| 4 | Theme Runtime and Authoring | 主题包、参数、预览和沙箱 |
| 5 | Local AI Assistant | BYOK Provider、受控工具、预览和主题草稿 |
| 6 | Game Source Discovery | 平台发现、去重和来源适配 |
| 7 | Distribution and Lifecycle | 安装、升级、卸载和发布验证 |

## 7. 发布硬门

- 没有未解释的快捷方式丢失或覆盖；
- 未签名代码主题默认不能执行；
- 静态桌面不持续刷新；
- 全屏游戏暂停行为可重复；
- Explorer 重启后能恢复或明确进入回退模式；
- 通知区域右键菜单可打开主页/设置并切换当前海报主题；
- 无 Key 时 Agent 不启动、不联网；Key 不进入 WebView、数据库和日志；
- Agent 修改全部先预览、后确认、可撤销；
- `uninstall.exe` 可从安装目录独立启动；
- 卸载前恢复托管快捷方式，失败时保留保险库；
- 卸载后没有自启项、活动进程、开始菜单入口或应用拥有的缓存残留；
- 重新安装可识别并恢复上次异常中断状态。
