# Desktop-Up 制作与交付计划 V0.1

状态：`PROPOSED`

日期：2026-08-02

## 1. 交付目标

完成一个可在 Windows 11 x64 安装、运行、升级和完整卸载的 `DesktopUpSetup.exe`。安装后的核心体验是：创建游戏海报、导入或收纳快捷方式、自动排版、启动游戏、折叠海报、自动暂停，并能安全恢复数据。

## 2. 里程碑与阶段门

### M0：工程与桌面宿主验证

交付：

- Rust/Tauri/Svelte 最小工程；
- 托盘和单实例；
- 透明桌面宿主原型；
- 一张可点击、可拖动的假数据海报；
- 全屏与锁屏暂停探针；
- 性能采样脚本和兼容性记录。

阶段门：`C-DHF-01..07` 全部通过。任何硬门失败都必须先选择修正、回退模式或技术栈调整，不能直接进入完整主题开发。

参考工作量：5–8 个有效开发日。

### M1：本地收纳 MVP

交付：

- `.lnk`、`.url`、`.exe` 手动导入；
- 海报创建、删除、拖动、缩放、锁定、展开和收起；
- 网格排版与局部重排；
- 快捷方式保险库、恢复账本和撤销；
- SQLite 数据与迁移；
- 3 个静态主题。

阶段门：连续完成 100 次导入/收纳/恢复故障注入，不覆盖或丢失用户快捷方式。

参考工作量：10–15 个有效开发日。

### M2：主题与控制中心

交付：

- 主题参数 schema 和自动设置面板；
- 素材主题导入、校验、预览、导出；
- 动画暂停、限帧和按应用规则；
- 控制中心、托盘操作、备份与恢复。

阶段门：恶意路径包、超大包、外链 CSS 和损坏主题均无法突破应用数据边界；主题卡死不导致主进程无法退出。

参考工作量：8–12 个有效开发日。

### M3：游戏平台发现

交付：

- Steam、Epic 本地安装发现；
- Xbox/Microsoft Store Shell 项目枚举；
- 去重、来源角标和手动修正；
- 扫描开关、隐私说明和取消能力。

阶段门：没有任何平台客户端时功能正常；扫描失败不影响手动导入。

参考工作量：5–8 个有效开发日。

### M4：发布与卸载封板

交付：

- Release 构建、签名入口和许可证清单；
- `DesktopUpSetup.exe`；
- 安装目录内 `uninstall.exe`；
- 升级迁移、卸载恢复和自清理；
- 用户快速入门、故障排查和隐私说明。

阶段门：净机安装/升级/卸载矩阵全部通过，没有残留启动项、运行进程和不应保留的应用文件。

参考工作量：5–8 个有效开发日。

## 3. 实施顺序

```text
桌面宿主硬门
  → 数据与恢复账本
  → 单海报完整闭环
  → 多海报和自动布局
  → 主题参数/素材
  → 游戏来源扫描
  → 性能与兼容性封板
  → 安装、升级、卸载验收
```

代码主题在素材主题与暂停机制稳定后开始，不得阻塞最小可发布版本。若需要尽快交付，可将代码主题移入 `0.2.0`。

## 4. 能力模块顺序

| 顺序 | B 模块 | 主要结果 |
| --- | --- | --- |
| 1 | Desktop Runtime Foundation | 桌面宿主、暂停、托盘、自启、恢复 |
| 2 | Collection and Launch | 导入、收纳、恢复、启动和元数据 |
| 3 | Poster Layout and Interaction | 锚点、拖拽、折叠和排版 |
| 4 | Theme Runtime and Authoring | 主题包、参数、预览和沙箱 |
| 5 | Game Source Discovery | 平台发现、去重和来源适配 |
| 6 | Distribution and Lifecycle | 安装、升级、卸载和发布验证 |

## 5. 发布产物

唯一对外安装入口：

```text
dist/DesktopUpSetup.exe
```

构建内部同时保存：

```text
artifacts/<version>/
├─ DesktopUpSetup.exe
├─ SHA256SUMS.txt
├─ THIRD_PARTY_LICENSES.txt
├─ build-manifest.json
└─ test-report/
```

安装结果和卸载清理契约以 [`RELEASE_AND_UNINSTALL_POLICY.md`](../../Rules/RELEASE_AND_UNINSTALL_POLICY.md) 为准。

## 7. 发布硬门

- 没有未解释的快捷方式丢失或覆盖；
- 未签名代码主题默认不能执行；
- 静态桌面不持续刷新；
- 全屏游戏暂停行为可重复；
- Explorer 重启后能恢复或明确进入回退模式；
- `uninstall.exe` 可从安装目录独立启动；
- 卸载前恢复托管快捷方式，失败时保留保险库；
- 卸载后没有自启项、活动进程、开始菜单入口或应用拥有的缓存残留；
- 重新安装可识别并恢复上次异常中断状态。
