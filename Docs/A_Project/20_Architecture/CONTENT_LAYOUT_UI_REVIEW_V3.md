## 1. 本轮范围与决定

用户认可上一版的职责归并：外观和内容布局放在一起，行为单独分组；要求减少常驻解释、说明悬停显示，内容滚动条默认隐藏，并另做完全不同风格供比较。当前先确定 UI，再评审图钉与跨格拖动的入口、反馈和组合规则，**本轮不推进这些未决语义**。用户要求归 [DEC-012](../10_Requirements/REQUIREMENTS_RISKS_AND_OPEN_QUESTIONS.md)。

V2 保留不覆盖。新稿的深色、琥珀点缀、具体间距和控件排布只是候选，不把“做一版不同风格”写成用户已经选定该皮肤。既有热度/图钉/缩框规则沿 DEC-011；源码中尚未修复的问题不由原型关闭。

## 2. 与上一版的区别

| 维度 | 方案 A / V2 | 方案 B / V3 |
| --- | --- | --- |
| 视觉 | 浅色、青绿色点缀，解释型表单 | 石墨深色、琥珀点缀，紧凑工具面板 |
| 结构 | 按控件依次展开的评审片段 | 海报目录侧栏＋对象参数区；外观/行为可切换 |
| 宏观参数 | 带预设节点的短滑块 | 尺度与疏密并排；模板用小样卡，不堆满宽表单 |
| 信息密度 | 规则较多地常驻展示 | 操作名称、当前值留在画面；原理与影响范围按需提示 |
| 浏览指示 | 可见浏览器滚动条 | 覆盖式指示条，静止隐藏；不改变内容视口尺寸 |
| 海报演示 | 页面右侧独立 DEMO | 仍在控制中心之外，窄窗口时移至下方；不是恢复产品桌面预览 |

仍然不设独立“布局”顶层页；外观承载模板、尺度、疏密、浏览方向/循环偏好、一个“整理内容”入口。行为示范现有自动收展与离开延迟，不增设逐海报动效开关以混淆托盘全局职责。新增/删除/备份等未在本次片段完整重画，**未画不等于删除既有功能**；定稿后需核对完整中心的信息架构。

## 3. 说明与反馈

- 默认只显示能完成操作的标签和值；解释控件用途、作用范围、原型限制的文字移入提示。
- 鼠标停留约 400ms 显示；键盘聚焦也能显示；Esc 关闭。提示可移入阅读，位置限制在窗口内，避免遮挡触发控件本身。
- 操作名称、当前目标、选中状态、不可用/失败原因不应只靠悬停获知。生产保存失败仍需常驻可见反馈，本原型没有数据库，不伪造“已保存成功”。
- “?” 集中说明演示范围，右侧信息入口解释海报演示与产品窗口的区别。提示不是把原来整页文稿塞进每个气泡；工程规则仍归设计文档。
- 400ms 是本次原型的试用值，不是冻结生产计时合同；提示的触屏路径与系统高对比度仍需后续实际技术栈验证。

## 4. 默认隐藏滚动条

静止无操作时不显示内容滚动条，也不预留滚动条宽度。仍允许沿当前主轴滚轮、方向键、PageUp/PageDown、Home/End 浏览；横向原型允许垂直滚轮映射到横向。

滚动、键盘浏览、靠近主轴滚动边缘时短暂显示细指示条，可拖动；停止操作约 1 秒后隐去。键盘聚焦在滑块上时保持可见，内容不足一屏则不显示。这里“默认隐藏”不等于“禁用滚动”，也不是让用户永久找不到浏览位置。1 秒及边缘感应范围只是候选体验值，尚未冻结。

指示条覆盖绘制、不参与排布，因此显隐不应触发换行、改变最小宽高或造成跳动。右侧/底部另有**评审专用缩框把手**，不是滚动条；下方“缩框测试”默认折叠，不进入产品控制中心。两轴仍采用同一保序换行/列规则，不以隐藏交叉轴滚动条掩盖不可达内容。

## 5. 可操作范围与保留边界

可以体验：切换三张 DEMO 海报（内存参数隔离）；模板/尺度/疏密；外观与行为分组；两轴有限浏览；悬停/聚焦提示；定位描边；缩框；整理入口、选中项尺寸、撤销及双独立辅助显示。

整理工具条采用紧凑候选：两个小图标分别控制基线网格和左上跨度；只有选中 Item 才出现尺寸操作。相较 V2 的折叠辅助入口，这是**待选 UI 形态**，不更改两个开关的独立性或底层布局。尚未添加图钉和拖动换位控件，避免在入口评审前暗定组合规则。

原型保持上游给定的有效顺序；纵向最小内容宽度为最大 Item 宽度，横向为最大高度；到最小边界单列/单行。缩框不改尺寸、不按面积排序；手动改尺寸不改热度或排名。上游图钉求序器未实现，不把预置顺序当真实图钉效果验证。

循环与自动收展开关仅展示状态，**不运行循环滚动或自动收展调度**。没有真实 Item 打开、文件读写、数据库、CAS、原生捕获、R4 动画、热度计算或主题脚本；刷新会复位。演示模板的中文名只是展示名，不构成生产模板标识迁移。

原型由同目录 [HTML](Designs/content-layout-controls-v3.html)、[CSS](Designs/content-layout-controls-v3.css)、[JS](Designs/content-layout-controls-v3.js) 组成，需一起保留；没有网络依赖、不使用本地存储。该 JS 只用于评审，不能直接成为生产第二求解器。

## 6. 评审出口

先确认视觉方向、目录/参数分区、短滑块密度、提示和隐藏滚动条手感。可选择 V2、V3 或明确组合其中的部分，并不要求整版全收。确定这层 UI 后，再回到 [行为设计 V2](CONTENT_LAYOUT_REMEDIATION_DESIGN_V2.md)，细化图钉与跨格拖动入口、反馈、取消/失败和组合矩阵。
