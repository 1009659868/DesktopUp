### 唯一设计源

- 模板 = 视觉树＋资源／参数＋行为预制体快照＋事件绑定＋菜单声明＋状态样式。海报实例固定模板版本并保存自身覆盖；新增海报实例化默认模板，而不是创建另一套旧UI后等进入工作台再转换。
- 当前海报读取同一目标实例与版本，包含实际背景、标题、内容区、控件、绑定、条件／顺序及收展状态样式。预览／应用／保存／撤销传递同一份完整设计；没有修改时打开再关闭不改变效果或写入。后续库更新不覆盖用户删除的绑定。
- 既有legacy模板仅经版本明确的兼容读取转换为草稿，保存／应用才写新格式。字段缺失的旧格式与显式空列表不可混同；未知模板或能力拒绝有损转换并保留原数据。任何运行帧、重新加载、错误恢复都不得把已删除绑定重新填回。

### 控件、行为和菜单

| 部分 | 默认模板提供 | 作者可调整 | 宿主负责 |
| --- | --- | --- | --- |
| 标题 | 读取本海报名的文字与布局 | 字体／位置／显隐、改为自定义文字；无标题也有效 | 有界文本与同代测量，不暗中生成标题栏 |
| v | 独立可命中的UI节点，click绑定`poster.toggle();` | 换图形／位置、移除控件或绑定、替换预制体与顺序 | 原收展用例的空间、版本、交互及提交保护，不直接改状态 |
| … | 独立UI节点，click绑定“打开菜单”预制体；引用本模板的菜单快照 | 移除／替换入口与绑定，组合已注册菜单项、顺序与分组 | 白名单命令、弹层生命周期、点击时新鲜检查；不加收展救援项 |
| 内容槽 | 只读宿主内容集合的承载 | 合法几何与视觉参数 | 原生文件交互、唯一归属、内容保护，不把文件操作暴露给设计脚本 |

新控件是场景中的真实节点，不继续以`host.title@1`派生子矩形充当完整编辑能力。默认标题组只是一份可解组的普通组合；保留控件身份、角色和可读标签，事件以稳定节点ID绑定，不凭名称、v字形或`/toggle`后缀赋予默认动作。新声明版本应一次转换旧标题布局／绑定并重映射引用；当前3.3不得直接接受未实现的新格式。

拟增加受限方法`menu.open("poster-more");`（**设计示例，当前编译器尚不支持**），引用作品内菜单ID，只能从明确用户点击触发。菜单数据引用受信任能力目录中的命令ID，初批复用锁定、外框调整、控制中心、删除海报请求等现有菜单行为；显示／启用条件由当前宿主状态计算。脚本只能打开菜单，不能自动选择菜单项或绕过删除海报等既有流程。新增系统级命令必须通过软件注册，不允许脚本构造Shell／文件操作。原生Item菜单仍是内容用例，不与作品菜单混用。

事件分派须区分“属于legacy兼容入口”与“属于画板节点”；后者无论无绑定、全部停用、条件不满足或执行被拒绝，都不转回宿主默认操作。一个点击确定一个目标与明确的传播策略；默认控件消费自身click，不穿透底层／冒泡触发另一份收展。可组合多行为按显式顺序执行，错误或取消停止后续步骤，不将失败当未处理；不隐式复制第二条事件路线。

收展不是必备模板能力。作者没有声明入口／行为时不补按钮或菜单项，不因该选择判模板损坏或启动fallback；只有真正的版本、资源、语法或安全错误才能拒绝候选并保留上一有效设计。应用外的控制中心／托盘管理不自动改作品。自动收展、标题拖动临时状态等既有策略也要纳入显式能力与状态说明，不能成为“不支持收展”作品的旁路；不得默默丢弃旧用户设置。

### 状态、预览与性能

展开／收起由同一实例的状态投影描述：同一节点ID、样式来源和坐标系；默认模板提供兼容旧体验的紧凑布局／背景，也允许显式修改。不再在收起时硬换成旧宿主标题，再在展开中换回画板标题。动画按声明状态间的转换执行，渲染与命中跟随同代发布；保持原生准备／提交／恢复门，不以移除保护掩盖闪烁。

画板运行与桌面使用同一事件执行器、状态解析和菜单定义。画板运行的菜单展示同样结构／启用原因；只能影响沙盒的命令在本地运行，涉及真实管理或文件的命令明确标为预览不可执行，不能伪称已执行。原生预览走真实宿主保护。退出运行销毁瞬态，不写真实海报或文件。

设计数据包应报告全部控件、事件来源、预制体、菜单命令来源、状态及缺失能力；“无绑定”可直接读取，不能让AI从图形猜行为。新增字段／命令在实现后才注册能力版本，草稿工具与手工编辑共用校验、预算、期望版本和摘要，不新增AI权限。节点按稳定ID复用，绑定仅在设计修订时编译／索引；不增加每节点timer，不逐帧重新实例化模板、解析脚本或读库。

### 四阶段落地的协议增量（v4拟议，未注册）

不另造一套模板存储或脚本引擎：扩展现有声明、工作区及共享执行器。兼容旧版本的解析与新格式的发布分开，当前`canvas-j1-3.3`继续准确描述旧实现；实际可运行后才递增能力目录。拟议最小增量如下，具体序列化字段在T1测试夹具中冻结。

| 数据部分 | 最小增量与规则 |
| --- | --- |
| `nodes` | 复用文字／形状／图片／组；可选交互角色和可读标签，不以角色自动绑定动作。标题、v、…各有真实节点ID。标题的受限文字来源只允许目录注册的`poster.title`等公开只读值，不允许任意属性路径或表达式求值 |
| `behavior.prefabs / bindings` | 沿用代码快照及有序绑定；source改为实际节点ID或明确poster事件，不再依赖派生`/toggle`子矩形；空列表有效。目标、条件、顺序与脚本预算统一校验 |
| `menus` | 作品内菜单ID与有序条目；条目引用宿主白名单commandId，允许分组／分隔。未知命令拒绝，不接受脚本、Shell路径或“trusted”自授权。显示名可定制，实际权限与启用理由只由宿主计算 |
| `states` | 同一树的展开／收起属性覆盖、视口与外形；只覆盖允许的几何、可见性和视觉属性，不替换节点身份、成员、脚本权限或保存另一棵树。未声明收展的作品无需collapsed态 |
| 状态过渡 | 明确来源／目标状态、时长／缓动及可插值属性；到达状态由宿主成功回执确认，不以时间到了就视为收展提交。减少动画可直接到终态，仍执行原生准备与提交门 |
| 宿主策略引用 | 自动收展、标题拖动临时展开等既有能力若启用，需要显式列出来源、参数与权限，在行为层／说明中可读可关闭；复用旧用例，不提供任意回调或新增每节点轮询 |
| 实例与资源 | 保存模板固定版本、实例覆盖和完整设计摘要；明确删除／空覆盖可遮蔽模板默认。自建模板／组合保存菜单、状态和行为快照，引用统一重映射；不共享真实文件身份 |

**事件与能力**：先确定输入所属设计与节点，再按有序绑定执行；分派结果至少区分无匹配、条件未满足、已接纳、拒绝／失败，不再用一个bool决定是否启用默认行为。默认点击不冒泡；同源重入取消尚未接纳步骤，接纳后的宿主命令必须完整收尾。`menu.open`是窄能力，传入作品内menuId；菜单用户选择生成带目标版本／几何代次的宿主请求，设计脚本不能构造该权限见证或自动触发破坏性菜单项。

**兼容转换**：v1／v2／v3先完成完整验证，再产生新的本地草稿；v3标题组拆分时同时转换几何、样式、点击绑定、角色及状态。旧显式空绑定不注入v默认；旧直接…菜单行为需要在转换报告中明确成为显式菜单预制体。无法无损转换的能力拒绝转换，保留原字节。打开、取消不落库；保存／应用经原版本／摘要门才写新格式，之前设计继续可撤销。缺失字段只在明确旧版本中解释，绝不能在新运行帧补默认。

**发布与撤销**：整份设计及资源依赖一起准备，UI、绑定、菜单、状态不能分次发布；原生显示与数据库并非物理原子，继续保留发布失败恢复／重启重建。草稿撤销恢复节点与引用，已应用撤销不回滚文件和统计。复制组合只复制声明、重新分配身份，不复制运行中通道、菜单会话或本机句柄。

**成本与可读性门**：修订时一次建立事件／资源／状态索引；逐帧只推进活动动作及必要视觉属性。菜单按需建，活动通道结束即释放；画板与原生共享纯策略和执行器，仅宿主效果适配不同。不要求为每个字段新增接口、目录或窗口partial；每条替代路径附旧入口清理项，不能以新增代码数量作为完成标准。

## 2026-10-29 行为预制体修订（当前优先）

review05的事件属性表与标题过渡未获用户认可；改为工作台编写、保存和运行`desktopup.behavior/1`受限脚本。review06后续补脚本换行／保存及独立v控件，能力目录升至`canvas-j1-3.3`，场景包仍为兼容增加字段的v2；`Actions`保留属性名，新增`ScriptCommands`／`ScriptLanguage`和`hostControls`。本节覆盖下文旧“不是脚本／组合不携带规则”的限制；不意味着开放C#/JS、网络、文件或动态插件。

- `behavior.prefabs[]`：`id/name/language/script`。作品包含代码快照，库内改版不联动旧作品。最多33份（默认1＋自定义32），单份8KiB／128指令／8层条件。
- 两个默认样例：`poster.toggle();`直接调用；`if (collapsed) { poster.expand(); } else { poster.collapse(); }`显式重写状态决策。后者仍使用安全宿主原语，不等于任意编写底层窗口算法。模板复制才进入作品，不替换旧快照。LF／CRLF／CR等价解析；工作台新保存使用LF。
- 工作台脚本保存即持久化作品草稿，入库额外保存独立预制体；不会自动应用。库写入失败明确区分草稿已保存，未保存代码留在当前编辑会话，不能宣称已持久化。
- `behavior.bindings[]`：`id/source/event/prefab/target/condition/enabled`，最多64条。source为poster、装饰／组合ID或`标题ID/toggle`；target是self装饰叶ID或poster。事件为click/enter/leave及poster.expanded/collapsed；条件always/expanded/collapsed。UI可绑定多份，按列表顺序等待执行。
- 当前3.3实现：标题文字、v、更多菜单按宿主派生子控件分开，只有v独立绑定；布局由父操作区求得、继承父锁，`hostControls`目前只有toggle可绑定。这是待替换的实现限制，不是作者必须保留控件的产品规则；目标见顶部同源设计。
- 脚本支持`set`、`animate`、`wait`、`if (collapsed/expanded)`及`poster.toggle/collapse/expand`。不支持循环、递归、变量、文件、网络、系统命令、反射或动态求值。动作边界由编译器和宿主验证，不靠提示词。
- `animate`等待到终点后执行下一句；每源一条通道，新触发取消该源后续动作，最多8通道／256执行步／30秒活动时间。视觉属性仅在内存，停止或换设计复位；已接纳的宿主动作不能靠取消脚本回滚。
- 收展仅允许点击触发，等待原用例成功；保留CAS、空间、文件操作与编辑保护，拒绝则停止后续步骤。当前更多菜单仍为宿主硬接线，尚未转为显式预制体／菜单声明，不能算目标设计完成。普通内容和原生拖放优先，不将装饰行为当文件操作接口。
- 编辑器“运行画板”采用同一执行器，收展适配为画板内状态，不写实际海报。桌面运行通过宿主端口接线。命中使用静态声明几何，不追随瞬态偏移，避免hover反馈循环；本包geometry同样不是某个动画帧。
- `ICanvasWorkspace.Behaviors/SaveBehavior`存取经过编译验证的行为库；`CanvasCombination.Behavior`携带组合内部行为快照，插入时重映射ID，外部图层引用拒绝。编辑锁检查在手动编辑与草稿工具共用；AI只可写受校验的草稿数据，无自动执行／应用授权。

实现、验证及两个集中退出门见[行为预制体记录](../../40_Implementation/V3-07/CANVAS_BEHAVIOR_PREFABS.md)。AI面板／提供方网络仍未接通。

## 2026-10-29 当前海报、画面上下文与受控设计工具（当前切片）

“当前海报”不是空白作品。新增`CanvasPosterDraft.Read`从选中海报的已解析呈现读取普通背景色、实际8位alpha、标题文字／显隐／颜色、内容区及尺寸，生成可编辑底板及语义节点；原有Canvas设计不重复叠加旧宿主背景。新空白作品仍透明。读取不写库、不扫描文件；没有无损转换器的旧动态／带介绍区模板明确提示，不静默替换为空白“当前海报”。这不是宣称已支持任意旧模板转换。

| `content.status / observation` | current才带同代匿名位置；stale／unavailable不拼接旧画面；含目标版本、设计摘要、文档版本和布局代次 |

基本参数对照：`box`是相对父节点的0～1比例；`rotation`为角度；`fill/color/actions`为#RRGGBB底色／文字色／操作符颜色；`opacity`为0～1不透明度，0透明、1不透明；`fontSize/radius/padding/gap`为设计DIP，具体范围由注册能力提供。声明旋转、解析坐标和宿主实际布局仍须通过原生预览；包不是逐像素截图、文字测量认证或无障碍树。

### 本轮工具门与事件行为

`CanvasDraftBatch`字段：requestId、宿主随机scope、capabilityRevision、targetVersion、draftRevision、digest、operations。每批最多32步／64KiB，每工具会话保留最多128条回执，满后要求宿主新建，不驱逐旧回执后重放。操作为add（受控装饰）、replace（保持节点身份／类型／父级／锁）、remove（非原生语义子树）、behavior（规则）；不支持未知命令或多余字段。先在独立草稿完整验证再一次Revise；失败不取消有效预览；确切重复返回原回执，冲突／过期拒绝。预览仅RAM，用户Apply继续新鲜检查、原生准备及事务保存。素材资源读取和校验仍走原端口，模型不得提交本地路径或URL。

| 画板声明 | 区域、节点树、参数、资源引用、内容槽、操作锚点 | 用户路径、真实Item清单、密钥、任意代码 |

最小内核知道几何和布局结果，不识别“台灯模板”“游戏模板”。复杂可信组件提供测量／呈现适配，作者只声明类型和参数；新增适配能力是软件更新，不是加载生成代码。

### 几何与对象布局

- 坐标相对于容器局部空间，不使用屏幕像素或Explorer图标坐标。宿主确定可用尺寸后求区域与节点布局，DPI转换在呈现边界执行。
- 节点 `box` 相对于父节点；根下指定region的节点以该区域为参照。样例采用归一化矩形排版盒，但排版盒不规定最终绘制形状。
- `draw.panel`的fill／opacity只作用于本节点背景，不隐式让全部子Item跟着变透明；节点隐藏不允许隐藏唯一内容槽。命中优先级由宿主决定，Item／菜单优先于其下的整面拖动区。
- 内容槽交给现有布局链，得到实际Item边界后再检查最小尺寸。文本测量、操作命中尺寸与空间限幅不能只凭JSON判定通过。
- 画面、裁剪、Item命中及操作区来自同一代几何；失败不发布半套新画面／旧命中。按原生实际提交结果准入，保留现有失败恢复。
- 标题栏、菜单和收展入口均非必要结构；作者实际声明的交互需满足有效几何和命中规则，非法引用／越界不能发布。省略或移除交互本身有效，不触发自动补足或拒绝；锁定、文件及事务检查不依赖作品是否画出相应按钮。
- 雨夜样例表达两个分离区域。圆形／空洞的原生输入待J4确认；J1只在既有矩形输入承载上验证，不自动让透明区域穿透到桌面。
- 多内容槽须先设计不重叠的成员分配、溢出和跨槽移动语义；首批不重复显示同一有效对象，不恢复共享引用。

### 自由组合与场景复用

- 基础类型描述图像、文字、形状、分组、布局、内容承载和宿主入口，不描述“雨夜模板”或“灯盘开关”。同类节点可多次添加、复制、分组、重排与重挂父级；复用只靠数据关系，不靠实例名字。
- `transform`采用局部DIP位置、缩放、角度和枢轴；`layout`区分free、anchored、flow。flow子节点的位置由布局计算，不同时保存相互冲突的手工坐标；退出flow才编辑自由位置。装饰旋转可组合，J1内容承载仍保持轴对齐、无倾斜，不以图像旋转冒充原生命中支持。
- 重挂父级默认保持世界位置，无法逆变换时拒绝；复制产生新节点ID。删除唯一内容承载时仍需等价承载保证真实内容保护；操作UI可以删除，并清理相关绑定后统一撤销，不强制补齐收展或菜单。
- 选中装饰子树可另存为子场景；引用固定版本和摘要，实例覆盖通过公开参数键访问，不使用任意反射路径。实例展开身份是实例路径加源节点ID；父子循环、资源循环和展开后越预算全部拒绝。
- 编辑源场景生成新版本；现有实例只有显式升级才变，升级保留仍合法的覆盖，失效覆盖需修正后再发布。首批子场景不得嵌入真实内容绑定；整份模板可以要求一个由宿主注入的内容绑定。
- 发布模板包含资源和依赖，不携带用户文件、统计、路径、凭据或运行实例身份。模板实例化与文件收纳是两条不同用例。

### 参数与资源

直接值、`{"param":"key"}`及`{"resource":"id"}`为互斥值形态。没有表达式求值、可执行插值、反射路径或模板脚本。条件显示只用有限条件，不执行代码。

用户通过素材导入动作显式选取PNG／JPEG；宿主读取并复制到资源库，按实际文件头、大小、尺寸／像素总量和解码预算验证，成功后发放资源ID。生产首批不开放SVG脚本、视频、字体包、任意URL或原生插件。导入动作本身是授权，不逐文件增加确认框；选取不等于上传给AI。库内副本不依赖源路径，用户源文件永不因取消／卸载模板被删除。

草稿、模板版本、实例及撤销记录各持有明确资源引用；取消只释放本草稿租约，保存草稿转为持久引用，撤销历史仍需要的资源不回收。发布前验证完整依赖和摘要；导出拒绝路径穿越／绝对路径／重解析逃逸，缺资源不静默丢图。存储字节摘要与解码缓存分离；同内容资源共享不可变数据，实例覆盖不修改共享资源。具体解码上限先测量再固化，不能只限制文件字节而不限制解码内存。

优先级为配方默认值 → 预设 → 已保存实例覆盖 → 当前草稿覆盖。恢复默认是移除对应覆盖，不改共享配方。改变可复用配方产生新版本，实例不静默跟随；应用实例覆盖与发布新配方是不同命令。

## 3 能力目录

目录由宿主生成，模板与模型只读，不能上传目录自授权限。`capabilities.design.json` 是拟议目录，`status: proposed`；生产查询只能返回真实注册实现，不能直接将此文件当成可用功能。

每项能力给出稳定ID／主版本、种类、子节点支持、属性类型与约束、参数绑定、资源需求和失效范围。目录更新递增revision；预览与应用均绑定该revision，更新后旧预览失效。控制中心、AI工具描述和宿主验证同源，宿主另外执行语义和几何检查。

初始能力分为布局、基础绘制、内容槽、宿主入口和可信动效。`effect.rain@1`是未来复用已有Rain的适配目标，不说明当前Modules已支持通用协议。必需能力缺失返回 `unsupported-capability` 并保留旧版。可选装饰须先定义替代方案才能降级；未知字段／版本默认拒绝应用，保留原包供更新后再读，不用丢字段后的版本覆盖作品。

### 创作工作台与控制中心

1. 创作工作台：独立工作区，左侧场景树／素材／子场景库，中间可直接操作的画布，右侧类型驱动属性检查器；可从空白开始，不要求先选两份样例。树与画布双向选择，节点增删、变换、层级、素材和实例编辑均走草稿命令。
2. 控制中心：只显示作者主动开放的日常参数及实例覆盖，可折叠和恢复默认；不把所有节点属性堆成设置夹，也不把创作缩成勾选组件。
3. 场景管理：保存草稿、另存为模板／子场景、资源依赖、版本与导入／导出；保存不是应用到海报，发布新版本不是静默更新其他实例。

J1必须包含基础结构编辑、直接操作、图片导入、场景复用及用户此次新增要求的受限行为脚本。复杂路径、通用粒子编辑器、通用语言脚本仍不在本批。文字、背景等可绑定共享色板；作者选择开放字段，不能通过隐藏控件绕过校验。新基础能力仍需软件更新，但在已注册能力内制作新风格不改源码。

## 4 设计草稿与应用

`desktopup.canvas-draft.design / 0.2-draft` 的字段：

| 字段 | 来源与用途 |
| --- | --- |
| requestId / draftId / draftRevision | 宿主分配，草稿修订递增；修订命令带expectedDraftRevision，拒绝旧请求覆盖新草稿；请求ID用于取消、幂等和回执查询 |
| target.containerId / expectedDesignRevision | 准入时固定，切换选择不改变目标；创建实例走明确create命令，不以缺目标当创建 |
| capabilityRevision | 绑定准备时的能力集合 |
| candidate.recipeId / recipeVersion / sha256 | 不可变候选及字节摘要，不仅凭名称信任包 |
| candidate.overrides | 实例覆盖，类型及范围来自配方和目录 |
| requestedBy | human／ai仅描述来源，不是授权凭证 |

宿主另行生成准备结果：规范化diff、基准见证、资源代次、几何可操作性、预算、previewId、规范化候选摘要及应用令牌；模型不得填写或导入这些结论。令牌绑定目标、设计和草稿版本、候选、作用域及会话，修改任一参数后需重新准备。

命令面为读取能力、读取授权目标摘要、创建／修订草稿、校验／准备预览、应用、丢弃、撤销。AI只可调用读取和草稿工具；首版应用与撤销由用户面板动作驱动。内部IPC后续选择，不要求外部MCP客户端。

结构命令补充AddNode、RemoveNode、DuplicateSubtree、Reparent、Reorder、SetProperties、SetTransform、BindResource、CreateSceneResource、InstantiateScene及ExposeParameter；均带目标／草稿预期版本，组操作原子校验，拒绝部分成功。鼠标拖动只在草稿局部预览，松手记一个撤销步骤，不逐帧写库。草稿Undo／Redo与已应用设计Undo分开；节点属性变化失效旧预览令牌。AI以后复用这套有界命令，不获得资源库任意路径读写权。

已授权目标内读取与预览不逐工具弹确认，用户看候选后点击一次应用。导出、素材导入或更广上下文另行授权，不混入设计提交；不改变普通原生拖入／出无额外确认的体验。

### 生命周期与提交顺序

`editing → preparing → preview-ready → applying → applied`。修订回editing并使旧预览失效；校验错误返回结构化问题。取消前置阶段进入discarded，拒绝迟到结果。

应用时重查目标设计revision、目录revision、操作会话和资源／文件新鲜见证。内容布局使用当前成员快照，不回写模型见过的旧成员清单；目标设计冲突重新预览，不用全局旧快照覆盖无关海报。

准备全部成功后经唯一用例登记设计提交并协调原生发布。数据库与窗口并非同一物理事务，须有发布失败恢复与重启重建，不宣称DB／GPU原子事务。提交后取消不自动倒退；撤销是带预期版本的新提交，不恢复旧成员或热度统计。

J1必须验证提交前取消无写入、提交后回执丢失可查询且不重复提交、原生发布拒绝恢复、重启从已提交设计重建。静态核对不替代这些证据。

## 5 AI 与热度模型

AI面板独立于控制中心，只做海报创作。地址／模型／密钥由用户设置；凭据设施保管密钥并绑定选定端点，模型不能改端点或读密钥。默认只发送匿名目标、结构、参数与布局需求，不自动发文件名、路径、截图或其他海报；确需时先说明发送范围。

Skill指导组合、配色、可读性和修订；程序执行能力白名单、授权、版本、配额和生命周期。模板文本、素材元数据、模型输出均不能扩张权限。deepseek-harness仅参考组织并裁剪，默认spine中的Shell、任务、文件系统不纳入；先测安装体积、启动／空闲成本与取消退出再选技术栈，子进程不等于安全沙箱。

AI可提出内容槽空间与设计参数，但不算日常热度、不伪造统计、不生成可执行模型。现有模型继续提出排序／缩放／位置／过渡建议，宿主协调人工优先、限幅和同代提交。装饰动效不得给Item再乘一次尺度或覆盖受保护位置。

## 6 增量与成本边界

| 变化 | 失效范围 | 保留 |
| --- | --- | --- |
| 纯容器平移 | 原生位置及同代空间变换 | Item视图、暖位图、相对布局 |
| 颜色／透明度 | 相关节点绘制 | 身份、内容快照、布局 |
| 文字／间距／区域 | 受影响子树测量及依赖布局 | 无关图标和统计 |
| 装配／类型变化 | 差异节点与依赖资源 | 稳定ID节点、真实归属 |
| 内容／热度 | 内容槽及相邻布局依赖 | 装饰树，无需AI会话 |

经现有按需调度合并，不加每节点timer。静态模板不轮询AI，隐藏／暂停／减少动画时停止不必要动效。先建立身份与失效依赖，再谈缓存，不跨轮复用过期权威快照。

J0可调整预算：单声明256 KiB、128节点、深度16、8区域、64参数、16资源引用；不是修改生产v1的64 KiB上限。资源沿已有类型／大小规则，J1另测总解码内存；数量预算不是性能保证。配对样本为1/3/6容器、20/100对象，不据此承诺支持上限或帧率。AI轮次、上下文与超时由宿主限制，草稿不能提高。

## 7 两个设计样例与自由创作证明

| 场景 | 基础收纳 | 雨夜书桌 |
| --- | --- | --- |
| 区域 | 克制的浅色收纳面，无大标题／副标题／数量介绍 | 冷色雨窗背景、暖色装饰与暗色可读内容区，非同一模板换色 |
| 装配 | 普通背景形状、单内容承载、宿主操作锚点 | 导入图像、独立文字／形状、装饰子场景、单内容承载；不以灯盘ID或组件开关控制 |
| 控制中心 | 作者开放背景／留白等常用参数 | 作者开放色调／文字／装饰强度等常用参数；完整编辑在工作台 |
| 内容 | 一个宿主members绑定 | 同一绑定，不复制或移动文件 |
| AI修订 | 背景／间距 | 调弱灯光、减少雨效、隐藏文字，只生成草稿 |

两例必须由同一通用编辑器创作并保存为普通数据资源，不进入编译分支。另从空白制作第三种结构，证明不只适配两个样例；不得只换名称／颜色。视觉目标见[设计重审](../../40_Implementation/V3-07/CANVAS_J1_CREATION_REDESIGN.md)，当前待确认。

J1按free／anchored／flow明确测量与变换，文字长短、窄尺寸、移除节点均不能靠样例ID判断；布局算法是能力，不将比例盒或文字后接内容槽变成唯一结构。视觉异形与原生空洞仍分批验证。

历史0.1材料：[目录](capabilities.design.json)、[基础收纳](basic-storage.recipe.json)、[雨夜书桌](rainy-desk.recipe.json)、[换装草稿](rainy-desk.draft.json)、[继续修订](rainy-desk-refined.draft.json)。原verify-design.mjs仅核对这些历史设计数据，不证明0.2或产品运行能力；保留原样以便追溯。

## 8 退出标准与余项

J0退出：三份协议职责明确；两配方／草稿引用一致；无标题与非矩形表达不伪造文件身份；中心可据目录列参数组；代表性非法类型、越界、未知能力、重复内容、过期版本和候选摘要错误可识别；旧需求与计划一致；用户集中确认设计。

| 后续裁决 | 进入点 |
| --- | --- |
| 自由创作、素材导入、子场景复用、真实测量与安全闭环 | 视觉确认后的J1实现；新退出门以联合计划为准 |
| 非矩形间隙输入、无标题原生操作区 | J4前确认，当前行为不变 |
| 多槽分配、复杂路径编辑、任意数据源 | 不纳入首个运行切片 |
| AI技术栈、提供方能力、历史留存、总资源成本 | J2探针与隐私设置 |
| 用户代码、组件市场、通用Agent、在线更新器 | 不属于本轮联合闭环 |

现有接点：Domain/TemplateRecipes、Application/TemplateRecipeCommands、PosterContentSession、ContentInputGeometry、App模板参数与Bootstrap；本批不改。未来按用例替代旧路径并删除，不长期保留两套模板权威；文件移动与行为修改分开。
