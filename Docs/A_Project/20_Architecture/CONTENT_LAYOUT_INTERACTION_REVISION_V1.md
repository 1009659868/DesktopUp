## 1. 已定位事实

- [ContentLayoutSamples.Illustration](../../../src/DesktopUp.Domain/ContentLayout.cs)给右侧写入`ReservedSpaces=(8,0,4,8)`，它是硬障碍。主卡从(0,0)向左超界、向右与留白相交；缩小后的其他卡片也被同一障碍拒绝。留白目前没有对应的可编辑/解除入口，用户无法看出其禁入语义。
- [PushManualPeers](../../../src/DesktopUp.Domain/ContentLayoutEditing.cs)先将留白放入障碍集，再验证拖动项，冲突就拒绝；非固定邻项只向下避让。缩小卡片保留各项原坐标，所以空出的行不会自动收拢。
- [ContentLayoutSolver](../../../src/DesktopUp.Domain/ContentLayoutSolver.cs)允许手动坐标在两轴溢出；[内容视口](../../../src/DesktopUp.App/PosterVisualWindow.Content.cs)分别显示两个滚动指示，普通滚轮纵向、Shift滚轮横向。当前没有独立FlowAxis，也没有循环模型。
- 三个参考样例共用同一求解器；它们预设了坐标、区域和部分硬约束，并非三套独立引擎。当前Automatic/Anchored/Manual表示排布控制权，不表示横向/纵向。
- “在海报上编辑”是临时输入许可；“进入手动”会保存当前排布/尺寸为手动意图；“退出手动”会改变持久排布策略。把三者平铺为按钮让用户承担了内部状态机。

## 2. 用户已经明确的方向

1. 纵向与横向滚动不能同时出现，由布局方向决定。
2. 横向布局采用循环浏览，同一方向持续滚动能够回到起点。
3. 保留跨格能力和独立网格/跨度提示，同时降低操作压力，明确每种手势的意图。

## 3. 建议的用户入口

控制中心保留：**布局方向：纵向 / 横向循环**、宏观尺度/疏密、**整理内容**及**更多**。在海报“…”也提供整理内容，进入后只出现“完成整理”。

整理时，点击选卡片，拖卡片改位置，拖右下把手改占格大小；两辅助开关置于整理工具条。细跨度数值、顺序锚、区域/留白、恢复自动尺寸等进入所选卡片的更多/高级选项，不常驻占满中心页面。

“完成整理”只退出编辑，保留已完成的手动操作，不重新排版，不恢复自动，不增加一道应用按钮。一次手势完成保存一次；Esc取消当前未完成手势；撤销还原整次操作及其必要邻项让位。

“恢复自动”是独立明确操作，说明作用于所选卡片还是全部；不会与完成整理混用。全量恢复提供预览/明确提示和撤销，不能静默丢弃人工意图。

## 4. 操作意图矩阵（建议，未冻结）

| 意图 | 操作 | 行为及边界 |
| --- | --- | --- |
| 浏览 | 在内容区滚轮 | 只沿当前方向浏览；不改布局文档、不产生热度统计，不以Shift暴露另一轴 |
| 选择 | 整理态单击卡片 | 选中、显示把手与简洁工具；不打开内容、不改变位置 |
| 移动卡片 | 整理态在卡片主体按下并越过拖动阈值 | 立即跟手，显示吸附落点和必要邻项避让；未到阈值只算选择，不用二次长按 |
| 占用空地 | 把卡片拖到内容区空格 | 空地默认可用；普通装饰不形成隐形障碍。显式锁定/保留区若保留，编辑态必须标识并可管理 |
| 处理碰撞 | 拖入已有卡片位置 | 建议预览必要的邻项让位，固定项不被推动；不静默交换、重叠、缩小或改动远处卡片 |
| 改变卡片大小 | 拖选中卡片的右下把手 | 改占格跨度；图像/文字按卡内规则适配，不等同修改热度分数 |
| 移动整张海报 | 拖标题栏 | 继续使用既有标题仲裁/空间通道，不变成内容拖动 |
| 调整海报大小 | 拖海报外框边缘 | 改视口；按主轴布局重投影，不因窄化偷偷保存新的用户跨度 |
| 退出整理 | 点击完成整理 | 保留每次已提交操作，仅结束编辑保护，不改变布局控制权 |
| 取消/撤销 | Esc / 撤销 | Esc取消当前手势；撤销回退上一完整命令；都不将迟到操作转交另一海报 |
| 恢复自动排布 | 所选项/全部的明确菜单命令 | 解除指定人工覆盖，恢复自动/热度参与；效果可预览、可撤销 |
| 打开真实内容 | 日常态按后续Item启动合同操作 | 归V3-05；当前只有DEMO，不在本轮虚构文件启动能力；整理态禁止误启动 |

待讨论的关键规则：建议**手动移动只建立该卡片的位置覆盖，改大小只建立该卡片的尺寸覆盖；其余未调整卡片继续参与自动/热度排版**。整理期间冻结自动重排，完成后在安全点处理最新提案。全海报手动模式可保留为高级选项，但不作为每次拖动的必经步骤。

## 5. 单轴与横向循环的实现边界（建议）

- 将方向、临时编辑会话、每项人工覆盖分成三种状态。方向字段逐海报持久化；不复用Automatic/Manual枚举表达方向。
- 纵向：横向适配内容宽度，只向下延伸；横向：纵向适配可用内容高度，只向左右延伸。不能仅隐藏滚动条而保留不可达的副轴内容。
- 主轴/副轴约束同时作用于自动排布、手动落点、跨度调整、区域、滚动锚及编辑边缘滚动。正交方向放不下时提供合法落点/受限投影与明确原因，不静默丢项或缩字体。
- 横向循环采用有限布局周期的视口投影，首尾相接，不用“到头跳回零”冒充连续。跨接缝的大卡片允许部分显示；同一内容保持唯一ItemId和一份保存状态，显示投影不变成重复Item。
- 空内容/不足一屏不复制卡片凑循环，不显示无效滚动。持续多圈后不累计坐标漂移；保留可辨识的起始位置提示。
- 建议整理拖动期间暂停自动绕回/热度重排，避免抓取对象突然转移到另一端；保留当前视口和抓取点，结束后恢复循环浏览。跨接缝编辑、同项多处投影命中和短内容规则须纯模型验证后再接生产。
- 样例应提供初始构图，而非不可突破的空白模板。保留“显式保留区域”底层能力时，必须有用户能理解和解除的编辑入口；不可继续将本次右侧空地默认硬锁。
