## 1. 本轮目的

用户认可B的控制中心与缩框演示，要求模板区能承接较多模板及用户自定义收藏，并预留整体色调切换、自定义配色。本轮沿B做增量，不再重做已认可的分区；B原稿保留。需求授权归[DEC-013](../10_Requirements/REQUIREMENTS_RISKS_AND_OPEN_QUESTIONS.md)。

“整体色调”本稿先解释为**控制中心及其界面的全局配色**，与每张海报的模板独立。这是已向用户说明的设计假设，尚不等于批准全应用皮肤合同或批量修改全部海报；如用户指的是其他范围，先调整原型，不写进生产数据。

## 2. 两个入口、两个作用范围

| 入口 | UI组织 | 作用范围 |
| --- | --- | --- |
| 外观 → 海报模板 | 当前模板摘要＋模板库入口；最多3个最近样例；另存入口 | 当前选中海报，不改变其他海报 |
| 窗口顶栏 → 主题 | 墨色/纸白/深海预设；我的主题；自定义入口 | 控制中心与评审界面，不改变海报模板 |

主参数页不随模板数量增长而无限变长。海报模板是逐海报外观资源，“主题”入口调整控制中心的配色；用位置和说明区分作用范围，不因改名而混合两个状态。切换选中海报不改变控制中心主题。

## 3. 模板库候选

- 点击当前模板卡打开独立选择窗口；标题显示当前目标海报，点选模板即切换并关闭，无通用“应用”步骤。
- 搜索＋“全部/内置/我的/收藏”筛选；卡片显示缩略图、名字、来源、使用中状态与收藏星标。收藏模板不是Item图钉，不改变内容顺序。
- 默认示范8个内置、3个用户模板；更多模板在库内浏览，保持主页面紧凑。缩略图只表达样例配色与标题层次，不保证真实内容布局与图示一致。
- “另存为…”以当前外观为起点，展示名字、海报底色、卡片底色与副标题开关。原型创建新样例到“我的”，不覆盖内置；保存后由用户点选使用，不暗中替换当前外观。
- 自定义表单先在小样内预览；取消/Esc不改变当前模板。重名显示可见错误，不静默覆盖。模板命名与完整资源管理规则仍需生产合同评审。
- 原型保存只在本页内存，刷新复位；不伪称已持久化。输入名用文本节点显示，不解释为HTML或脚本。

本稿“模板切换”只演示背景、卡片色、标题层次；保留Item、有效顺序、跨度、尺度、疏密、浏览方向、外框位置等参数。正式模板是否包含度量、布局方案、素材槽或作者区域，需按既有主题计划细化；不能从这个样例推定模板只有颜色，也不能暗中覆盖用户排列。模板删除/更新/分享/导入导出/资源缺失等入口尚未设计，不通过原型预先承诺兼容策略。

## 4. 主题入口（配色能力保留）

顶栏入口始终可发现，不归属于某张海报的外观页。弹窗标明“控制中心”，提示“更换控制中心的颜色，不影响海报样式”。预设点击立即生效，提供“我的主题”与自定义表单；名称、底色、强调色可调整，小样预览后“保存并使用”。该保存是创建命名资源，不恢复此前已取消的普通参数逐项应用流程。

文字明暗和辅助表面随底色推导。明显低对比的强调色显示错误并阻止保存；原型暂用对比值4.5作为保护假设，不是生产无障碍认证，也未冻结最终色彩算法。自定义草稿取消不影响正在使用的主题；仅保存后的样例进入“我的主题”。

本次未实现自动跟随系统、高对比度适配、主题插件、在线素材、文件导入导出或跨机配色同步。可以先预留UI，实际生产实现按计划后置；不为演示扩展SQLite或便携配置schema。

## 5. 保留不变的部分

外观/内容布局仍归并，行为单独分组；说明悬停/聚焦显示；短滑块与节点保持；海报内容滚动条静止隐藏。右侧是独立演示环境，不是恢复控制中心桌面预览。

缩框的保序求解函数与B一致：外框交叉尺寸缩小只换行/列，不缩Item、不按面积重排；最小边界单列/单行；两轴对称。热度和图钉来源仍按DEC-011，不在此轮细化图钉/跨格拖动组合规则。

双辅助开关、单项尺寸/撤销、有限浏览保留。真实循环、自动收展调度、图钉求序、跨格拖动、生产事务与文件操作均未实现，不用UI原型关闭现有Bug。
