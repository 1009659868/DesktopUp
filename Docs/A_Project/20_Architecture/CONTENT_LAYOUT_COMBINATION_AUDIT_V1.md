## 1. 已确认的手势模型

持续保存的布局模式只有**纯手动、热度自动**。选中、按下待判、拖动、中心预览、保存中、受限只读是暂态，不是更多布局模式。中心不是桌面操作的许可开关。

| 输入/意图 | 行为与结果 | 保存边界 |
| --- | --- | --- |
| 单击Item | 选中，不打开、不切模式 | 选择是会话状态，不提交布局 |
| 双击Item或对有打开资格的Item按Enter | 一次激活最多一次打开；两次点击须属于同一有效身份/呈现代次，按键重复不再次启动 | 打开走能力/意图端口，不是布局命令；本轮仍DEMO，真实执行归V3-05 |
| 按住Item并移动过位移防抖阈值 | 立即成为拖动，不等长按时间、不先进入整理；抓取点跟手，松手不补一次打开 | 按下、预览、无变化、取消不写库；有效松手才提交 |
| 自动模式拖动 | 预览最终顺序位，成功后仅目标新增/更新顺序图钉，其他项继续自动 | 图钉不锁像素、不锁大小；争位向后找未固定序号，无后位则拒绝 |
| 手动模式拖动 | 预览网格位置、局部让位和留白，不全局补洞 | 源项及所有受影响项一次保存/撤销；无效处释放不保存上一个合法位置 |
| 改Item跨度 | 通过尺寸入口或中心细调，预览必要让位；不改图钉或热度 | 尺寸覆盖独立；超正常空间约束拒绝候选，不自动扩大外框 |
| 滚动 | 正常只沿所选主轴；循环只改变浏览投影；受限时两轴有限可达 | offset/循环副本不写作者位置，不复制成员 |
| Esc / 撤销 | Esc取消未提交内容编辑；撤销回退一次成功语义操作 | 已提交结果不因Esc消失；撤销重新校验当前版本/成员，不恢复旧版本号 |
| 切到手动 / 回自动 | 每次从当前完整逻辑画面进入手动；退出A保留原自动图钉/尺寸，不带入手动尺寸 | 模式及构图一起提交；包含屏外成员，不把循环副本重复保存 |
| 缩框 / 空间恢复 | 普通适配保尺寸和原图；有效几何编辑才承接整图；真实被动不足临时只读双轴 | 普通resize不保存Item构图；受限时不承接；恢复用最新状态 |
| 关闭中心 | 关闭中心拥有的未提交预览；已提交结果保留；桌面操作仍可继续 | 不切模式；不得全局取消另一个入口拥有的桌面手势，见§5 |

Enter须按焦点语义路由：中心数值框中的Enter完成该字段编辑，不同时打开背景选中Item。本文不扩张完整键盘导航/无障碍首发范围（TBD-009）。标题拖动、外框缩放仍归原空间所有者；透明装饰不命中，不把桌面空白变成隐藏编辑区。内部排列不代表外部拖放、跨海报移动或磁盘搬移。

内容输入链：`Idle → PressedPending → Drag/ResizePreview → CommitPending → Idle`；未越阈值的释放交点击仲裁。取消/失效走独立出口。首次按下保护身份和呈现基准，越阈值才预览修改；提交中禁止接着写同一布局，完成后重新取最新权威状态。松手先消费最后一次输入。

## 3. 第一组：循环接缝与受限恢复

### 3.1 可以直接否定的方案

设主轴extent=980、viewport=300、循环period=1000、offset=950；头项逻辑起点y=20。它的下一周期副本在`20+1000−950=70`，抓取偏移10时指针位于80。如果按下就关闭循环并将offset夹到有限上限680，原项将出现在`20−680=−660`，瞬间偏移730。要仍显示在70，有限offset必须是−50，违反普通有限offset≥0。

因此“按下后立即夹紧为普通有限视口，同时完全不跳”并非可满足的通用规则。只存ItemId再取canonical矩形，也不足以恢复用户实际抓住的副本。横向交换轴可得相同反例。

**工程候选**：按下保存同代次tile投影变换（或等价见证）、完整矩形、局部抓取点和周期相位，暂停惯性/结构提案；内容手势仍沿原capture。正常循环直接拖动期间保留有界的接缝投影坐标系，影子由指针和抓取偏移驱动，不强制立即有限化。落点映射回唯一逻辑布局：自动只有1..N最终顺序位，手动只有合法网格位置；缝隙不是新Item、额外图钉或无限画布。当前受影响布局预览和命中必须同代次发布，目标判定从手势基准计算，不追逐被自己推走的预览。

这是对旧“必须提前进入整理/立即有限化”候选的替代工程方案，不是新增产品模式。仍使用一个solver/浏览投影；tile不落库。DEC-025已定新建纵向/循环关，切方向不改Loop、旧值保持；空/短/恰一屏不运行循环且offset归零，偏好与运行资格分开。最终循环拖动算法、周期变化/边缘导航预算和原生命中仍需R3/R6证明。

**锚点承诺必须可实现**：令新布局中目标内部点为a，希望它位于视口位置v。有限浏览取`offset=clamp(a−v,0,max(0,extent−viewport))`。例a=30、v=200，所需offset=−170，只能取0，目标移到30；这170是边界约束导致的必要移动。循环仍有资格时可按新周期还原相位。故“恢复不跳”指不换错Item/不任意回开头/不累计漂移；边界处允许最小夹紧并保持目标可访问，不能要求不可能的同像素位置。

受限逻辑布局240×500、真实视口180×300时，两轴范围分别[0,60]、[0,200]，四个极值可访问全部逻辑边界；原尺寸/意图不写回。C≥M的旧约束冲突不适用此计算，见第二组。进入受限已取消编辑，因此无需为保旧拖动而保住原像素；不能在恢复后自动接着提交旧手势。

## 5. 第三组：桌面与控制中心的草稿所有权

### 5.1 不依赖产品选择的边界

同一海报布局是一份文档，一次手动编辑可能影响邻居/全图。因此所有权至少覆盖**该海报的整个内容布局**，不是按Item分别占锁。中心的尺度、模板metrics和外框几何与布局存在共同依赖，沿现有保护通道协调；别张无依赖海报的纯观察不应被全局取消。本文不承诺绕过原空间事务提供任意并行写入。

一个编辑会话需能核对：所有者入口、PosterId/ItemId、会话token、权威读集/成员版本、度量/环境代次、候选及提交阶段。控件只是投影/意图输入，不能各自拥有可独立保存的副本。丢失普通焦点不等于内容失效；失去capture、目标删除、锁定、真正环境失效按既有取消语义处理。

| 反例ID | 轨迹 | 核对结论/反馈 | 验证承接 |
| --- | --- | --- | --- |
| CC-01 | 中心将A从2×2预览为4×3，未保存→桌面按住A | 隐式保存、丢弃或合并都会改变用户意图；取消中心后几何还原还可能使首次抓取跳动，不能仅用last-writer-wins。交接按Q2决定 | PD-20，MC-11 |
