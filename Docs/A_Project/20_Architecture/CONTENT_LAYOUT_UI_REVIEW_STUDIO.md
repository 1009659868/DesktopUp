## 1. 本轮反馈与范围

最初用户认为B+偏商业化，希望更有趣；认可配色能力，要求入口改为“主题”并修改解释。决定归[DEC-014/015](../10_Requirements/REQUIREMENTS_RISKS_AND_OPEN_QUESTIONS.md)。后续认可样片夹迭代方向，不等于确认全部密度、默认配色或特效强度为正式产品默认。

保留B+作为紧凑对照，直接同步“主题”的按钮/弹窗/可访问名称/自定义表单/通知文案。新视觉另做文件，不覆盖B+的页面结构，不改变生产代码或布局合同。

## 2. 主题：命名简化，作用范围不混淆

- 顶栏入口和弹窗标题统一为“主题”；自定义表单用“主题名称”“我的主题”。
- 入口提示：**更换控制中心的颜色，不影响海报样式。**
- 弹窗用“控制中心”标明范围，避免“全局”被理解为同时替换所有海报模板。
- 保留现有预设切换、自定义底色/强调色、文字明暗适配和低对比提示；不新增主题算法。
- 普通预设即时切换；“保存并使用”只用于命名自定义资源。所有保存仍是页面内存样例，刷新复位，不是生产持久化。

## 3. 样片夹的不同

原来的模板摘要框改为摊开的样片：纸卡边缘、轻微错落、编号和明确的“使用中”；底部可以翻看下一组或直接打开完整模板册。桌面演示区用轻量点阵底板，仍在产品控制中心之外。默认以纸白主题展示，墨色/深海也可切换；纸白不是生产默认决定。

选择器趣味放在材质、构图和轻微反馈，不引入自动旋转轮播、付费商店式推荐或额外确认步骤。装饰胶带不表示Item图钉；新场景模板有独立可关闭动效，完整主题素材加载/结构协议尚未接入。

| 操作 | 结果 | 不发生的事 |
| --- | --- | --- |
| 前后翻看 | 换一组候选样片；宽窗口3张，窄窗口2张 | 不应用模板、不改海报状态 |
| 收起/展开样片 | 切换摘要与卡片；保留当前模板名 | 不切模板、不收起海报、不改浏览位置 |
| 点选样片 | 当前海报换到该演示外观；标出使用中 | 不改其他海报、Item跨度/顺序或浏览方向 |
| 打开模板册 | 搜索、内置/我的/收藏筛选与全部样例 | 不要求逐页翻完才可搜索 |
| 留一份自己的 | 复用“另存为我的模板”表单 | 不覆盖内置模板，不把内容/位置存入样例 |
| 键盘聚焦并确认 | 与鼠标点选相同，保留可见焦点 | 不依赖悬停才能发现主要动作 |

当前3张样片的显示顺序只是模板选择器顺序，不涉及海报内Item热度排名。完整模板册的收藏同样不是内容图钉。支持减少动效偏好；不靠倾斜角度或颜色单独表达选中状态。

## 4. 需要评审的代价

相较B+单行摘要，这版更直观、可探索，但模板区占用更多纵向空间。现按用户要求支持主动收起，折叠后只保留当前模板名/展开入口；大量模板仍进模板册。不在点选后强制自动折叠。

“留一份自己的”是趣味候选文案，同时提供明确的可访问名称与解释。若用户认为不够直接，可保留纸卡视觉但恢复“另存为…”。不因追求趣味而取消搜索、目标提示、失败信息、普通按钮与键盘操作。

## 5. 实现与后续边界

[HTML](Designs/content-layout-controls-studio.html)、[样片外观](Designs/content-layout-controls-studio.css)、[翻选呈现](Designs/content-layout-controls-studio.js)复用B+的[样式](Designs/content-layout-controls-bplus.css)、[模板/主题逻辑](Designs/content-layout-controls-bplus.js)与[原缩框演示](Designs/content-layout-controls-bplus-core.js)，并保留[B基础CSS](Designs/content-layout-controls-v3.css)。没有另建布局求解器或真实主题服务。

双轴缩框、有限滚动、隐藏滚动条、辅助显示、宏观参数与原图钉待决边界不变。新增场景脚本只研究独立呈现与被动鼠标响应，不进入内容图钉和跨格拖动的语义设计，也不修改SQLite、便携格式或启动候选。
