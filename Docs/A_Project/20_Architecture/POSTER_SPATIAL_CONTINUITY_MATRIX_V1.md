# 连续操作场景矩阵 V1

日期：2026-09-09。依据：[行为合同](POSTER_SPATIAL_CONTINUITY_CONTRACT_V1.md)。以下为验证义务，不是预先宣称通过。

记号：E(X)=展开、C(X)=收起；所有序列均在每一步检查不重叠、不越界、锁定不被推动、非源尺寸/姿态不变、整段路径安全和失败无副作用。

| ID | 场景 / 连续操作 | 关键断言 |
| --- | --- | --- |
| N01 | C/B/A 竖直链，E(C), C(C) | 基线全回原位，无尾段 |
| N02 | E(C), E(B), C(C) | B保留展开，A保留B要求的让位，不留C造成的额外空洞 |
| N03 | N02后C(B) | 回初始布局；B收起锚点已跟随系统平移而更新 |
| N04 | E(C), E(B), C(B), C(C) | 中间B收展不销毁上游关系；最后无漂移 |
| N05 | 三层各自展开，多种收起排列 | 链上每一层都是可能的源，不只叶节点 |
| N06 | 宽源推动左右两个分支，再分别展开分支 | 分支独立姿态、不因枚举顺序串位；关联不是刚性组 |
| N07 | 两个窄源共同影响一个宽下游 | 同时约束，不把位移相加；先收任一源均不破坏另一个源 |

| N09 | 屏幕下部向上展开及逆向链 | 保留自身上扩偏移；被其他操作平移后仍正确收起 |
| N10 | 同一源先下后上影响两侧 | 收起分别释放两侧空间，未释放一侧不提前动 |
| N11 | 链两端交替操作，反向压力 | 不交换上下顺序、不往返振荡、无无限循环 |
| N12 | 被推动B后用户拖动/缩放，再收起上游 | B保留新意图；其他仍合格者独立判定 |
| N13 | 拖出再拖回相同位置但代次增加 | 仍认作人工接管，不凭坐标相同复活旧归位 |
| N14 | B被推动后锁定/解锁 | 锁定期间固定；解锁不自动恢复旧锚点 |
| N15 | 回程新障碍 / 一个分支受阻 | 不能完整返回者原位不动，另一安全分支仍可完整返回 |
| N16 | 中间节点隐藏/删除、重新显示/新增 | 无悬挂记录、不立即带动全桌面；新节点为真实障碍 |
| N17 | 受限高度展开，邻居后来收起 | 保留有效高度，不自动扩回首选高度 |
| N18 | 标题/颜色变更与无关配置变化 | 不破坏几何兼容的锚点；CAS仍检查当前实体读集 |
| N19 | DPI/工作区/Shell/运行session变化 | 不复用旧连续关系，从合法当前布局重建 |
| N20 | 同一请求重放 / 过期读集 / 写入故障 | 一次revision、幂等、失败整体回滚，元数据与实体一致 |
| N21 | 反复20轮、固定种子长序列、随机枚举顺序 | 连续安全、同序列确定、闭环无漂移、有限工作量 |
| N22 | 零/单/3/6节点、超过预算、无效记录 | 边界和错误清晰，不把预算失败当空间不足 |
| N23 | 动画中新命令、环境变化、退出 | 保留busy/取消/权威恢复，不提交过期模型 |

测试分层：域层纯连续序列和扫掠性质 → SQLite迁移/读集/回执/回滚 → 三端投影 → 真实宿主批次与正常退出 → 用户鼠标与同步动画。未触及层不能由下层PASS代替。生产进入门与证据登记在M07交接，不重复整套DPI/安装验收。
