# 多海报连续空间行为合同 V1

日期：2026-09-09。阶段：M07 空间补强。状态：合同基线；实施/验证以配套记录为准。

用户授权依次完成行为合同、连续场景矩阵、纯模型验证、生产接入。本文补充[旧矩阵](POSTER_SPATIAL_STRATEGY_MATRIX_V1.md) C05～C08 的连续操作语义，不重写宿主或采用全桌面自动装箱。用户另明确：**归位目标或整段路径受阻时，不能只回收一部分；该海报保持原位。**

## 1. 三类状态和优先级

1. 用户意图：显式摆放/缩放、首选展开高度、收展状态、锁定/显隐、所属工作区。正常拖动仍不推邻居；锁定者不被别人移动，但可以自行收展。
2. 实际占位：当前屏幕物理矩形、当前有效高度、当前收展状态。临时高度不覆盖首选高度；空间释放后不自动长高。
3. 连续关系：同一运行/显示环境内，每张海报的归位锚点、其自身展开在标题锚点上方占用的高度、最近确认的空间实体快照，以及实际推动产生的关联范围。这不是永久刚性组，也不是第二个状态仓库。

优先级：合法占位和连续路径 → 最新显式用户意图/锁定 → 保持非源海报当前尺寸和姿态 → 保留仍有效的空间影响 → 安全完整归位。视觉动画不参与决定端点。

## 2. 锚点与影响关系

- 初次纳入模型时以当前合法位置为锚点，不猜测旧会话的历史。
- 系统推让/合法归位只改变实际位置，不把每次位移覆盖成新的用户锚点。自身展开的上扩部分改变本姿态的锚点偏移；收起撤销该上扩部分，后续被平移不丢失这一偏移。
- 显式拖动/缩放、锁定变化、隐藏/重新显示、跨工作区等不兼容变化为该实体重新立锚；即使拖动最后回到原坐标也按布局代次识别。其他节点不全盘清空，也不能继续移动被用户接管的节点。
- 标题/颜色等不改变空间实体的更新不破坏归位关系。改变尺寸度量后执行现有版本/几何校验，不暗中扩高邻居。
- 关联范围由已成功的收展/实际推动，以及新展开对已有归位通道形成的阻挡合并：后来的源即使没有新增位移，也可能接管已让出的空间。不因相邻接触自动绑定。范围内也非必须全体移动：各节点独立求目标、资格与路径；全部消除位移后可解散关联，元数据随实体数量有界。
- 合流不是位移相加：宽海报同时受多个上方海报约束时，必须满足所有仍有效约束；移除其中一个源不保证它能移动。新的阻挡也可能来自源推动的中间节点，因此接管归位通道的判定覆盖本次所有变更节点，不只展开源自身。

## 3. 单次操作合同

### 展开

沿用既有完整候选求解：先合法下方容量，再向上补足，完整高度不可能时才接受满足模板最小高度的临时高度。邻居只平移，不改变其当前宽高/姿态。失败候选不呈现、不提交、不建立新关系。成功后更新源自身上扩偏移、受影响范围及所有变更的预计快照。

### 收起与重新协调

1. 以源当前矩形与仍有效的自身上扩偏移求收起锚点；逆序释放上下两侧空间。未知/不兼容记录沿用安全的当前顶部收起。
   源自身也可能携带先前被其他源推动的位移；其完整标题锚点若位于本次原占位的收缩范围内且路径安全，应在本次收起中吸收该位移。不能只归位邻居而使最后收起的源永久漂移；不允许借此穿过外部障碍或任意平移收起源。
2. 在源最终收起占位下，计算其关联范围的完整归位目标。保持所有非源的当前尺寸、收展姿态和横向位置；满足横向投影相交者的现有竖直顺序、工作区边界及固定节点约束。只沿竖直方向趋近归位锚点，不交换上下顺序，不绕到别列或其他屏幕。
3. 完整目标不是历史快照。例如 C 收起而 B 仍展开，A 的完整目标可能仍在 B 展开后的下边，而非初始 A 坐标。
4. 使用全场景（包括关联范围外的海报）检查目标与整段回程，并求安全子集。目标被占、路径穿越固定/无关海报时，该节点原位保留；不部分归位，不为归位推动无关者。一个节点不能归位可能阻挡其他节点，这些依赖一并检查。过去受阻而保留的位移可能大于当前源缩短的高度，不能按“源缩1像素，邻居最多回1像素”永久拒绝完整归位；共享的是归一化进度，实际移动仍由每帧释放空间与路径限制。
5. 源和可完整归位者使用同一组批次、同一源释放空间进度；不追加源已收好后的单独归位动画。上下分段各自有实际释放空间后才允许邻居跟进。
6. 源/参与者新实际位置与连续元数据在同一 committed revision 提交；保留全目录实体读集/CAS、请求幂等、有效高度投影与物理失败恢复。

## 4. 失效与事件

| 事件 | 模型动作 | 不允许 |
| --- | --- | --- |
| 仅自身收展、再次被系统推动 | 更新姿态占位/有效关系，保留兼容锚点 | 仅因布局代次变化永久丢弃所有关系 |
| 显式拖缩/锁定/重新显示等 | 重新立该实体的锚点并解除旧自动归位资格；新位置成为障碍 | 把其他实体全部恢复旧坐标，或默认组拖动 |
| 删除/隐藏 | 当前不可见者不占位；清理其记录；不以此事件主动播放邻居归位 | 删除即重排整个桌面 |
| 新障碍 | 全场景校验挡住不能完整返回的节点 | 半途停下当作成功归位、穿透障碍 |
| 新 session / DPI / 工作区 / Shell generation | 旧连续记录不复用，从恢复后的合法布局重新建立 | 跨环境重放像素位移或旧动画 |
| 过期 CAS/原生提交失败 | 整轮停止，恢复当前权威状态；不发布预计连续关系 | 一半实体写入、一半旧元数据 |
| 快速重复收展 | 复用当前 busy 保护/幂等；最后意图队列仍是独立未完成项 | 将本轮完成宣称为已交付最后意图获胜 |

显示/重启仍保存实际已提交位置和首选高度；连续元数据即使落盘也绑定运行环境，不进入便携配置，不作为跨机布局偏好。

## 5. 确定性、终止性与无漂移

- 相同初始状态、环境、操作序列与实体身份得到相同结果；输入集合枚举顺序不影响结果。
- 不要求空间不足时不同操作顺序一律同终点；先后意图和受限高度可产生合理差异。
- 无人工重定位/障碍/环境变化的可逆收展循环，应恢复该循环起点布局；多轮不能累计像素漂移。
- 求解只做有界单调传播；明确节点、候选、帧数与工作预算。预算耗尽是失败而非无空间，不执行部分结果。
- 检查每个连续运动段的扫掠碰撞，不只检查离散帧终点。失败时输入状态不可变，重放不重复移动。
