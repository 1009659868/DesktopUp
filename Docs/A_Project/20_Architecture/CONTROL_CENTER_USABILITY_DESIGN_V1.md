# 控制中心首版可用性设计 V1

日期：2026-09-15。状态：设计基线；UX已实施，当前滑块修订见[独立证据](../40_Implementation/V3-04/CONTROL_CENTER_SLIDER_REFINEMENT.md)，未验范围不补PASS。
产品决定：[V2-DEC-005](../10_Requirements/REQUIREMENTS_RISKS_AND_OPEN_QUESTIONS.md)；表面需求：[运行表面§4～5](../10_Requirements/RUNTIME_SURFACES_AND_TRAY_V1.md)；执行：[04-04计划§4](../30_Plans/V3_04_04_CONTROL_CENTER_PLAN.md)。

## 1. 目标与取舍

先交付一版简洁、好用的管理界面，允许之后迭代，不以完整视觉封板阻塞内容主线。

- 海报负责直接操作内容、位置与外框；控制中心负责管理海报、调整外观和行为。
- 删除现有桌面缩略预览入口，不继续发展可拖拽预览画布；导入影响预览、未来复杂主题隔离预览不在删除范围。
- 保留目录/稳定目标、状态权威、实体CAS、空间服务、R4呈现和恢复；替换交互适配层，不重写底座。
- “整体调整”指当前选中海报内的整体尺度与疏密，不默认联动其他海报，也不等于把每个Item强制同尺寸。
- 当前仍是六张DEMO ITEMS；本轮不做真实收纳、热度公式、完整主题平台、AI或M08标题缺陷修复。

## 2. 信息布局

| 区域 | 首版内容 | 不放在主操作区 |
| --- | --- | --- |
| 左侧稳定目录 | 全部海报、清楚的选中态/状态、新增；零海报可继续管理 | 屏幕缩略画布、技术ID |
| 目标页头 | 名称、定位按钮、少量常用管理操作；复制/删除等收入更多菜单 | revision、HWND、四个大号几何输入框 |
| 外观 | 内置风格选择、整体内容大小与疏密；按所选模板能力展示 | 一屏铺满单元宽/高、图标、字号、间距、三色原始值 |
| 行为 | 自动收展开关、离开延迟等必要设置 | 每项一个“应用”按钮、独立重复草稿区 |
| 高级/诊断 | 精确几何、细参数、版本/显示环境和错误详情，按需展开 | 默认长页强制滚到最底才够到常用操作 |

这是信息分组，不冻结最终像素、栏目名称和所有未来路由。首版复用WinUI现成选择器、滑块、开关、数值与导航控件；主题/状态提示清楚、键盘可达、小窗口有正常局部滚动。避免为低风险控件另造自绘输入体系。无效值和失败在相关控件旁说明，不用常驻大块调试说明挤占空间。

2026-09-16入口微调：低频“配置与恢复”收入现有“更多”的二级菜单，不在顶栏另占一个按钮。子菜单明确标注“配置与恢复（全局）”，以分隔线与重命名/复制/删除单张操作区分。更多按钮及全局子菜单不依赖海报选择，零海报仍可导入、导出和恢复；只禁用需要目标的操作。此次仅改变入口布局，不改变配置作用范围、确认、事务或恢复生命周期。

## 3. 宏观偏好与热度排版的接口

| 层次 | 输入/输出职责 | 不得做的事 |
| --- | --- | --- |
| 用户偏好 | 每海报整体内容尺度、疏密；版本化映射到ContentMetrics | 写入打开次数/热度得分，改变其他海报或手动排序 |
| 热度/布局策略 | 每Item稳定ID、相对大小层级、排序/固定信息；沿用自动、锚定+自动、手动模式 | 用海报外框宽高代替热度或用户尺寸偏好 |
| 排版与呈现 | 偏好＋热度结果＋视口，产出卡片/图标/标签/命中占位与滚动范围 | 只放大图像而不调整占位/命中；容不下就偷偷缩小偏好 |

工程概念为“基准度量 × 用户整体尺度 × Item相对层级”；不是提前冻结最终热度公式。须定义中性值和唯一缩放入口，避免既有默认150%与宏观尺度重复相乘。热度50%～300%、无数据默认等既有语义及待决公式仍归[Item§8～13](../10_Requirements/CONTENT_ITEM_ACTIVITY_LAYOUT_V1.md)。

整体尺度调整内容的共同基准；图标、卡片、标签可按模板的可读性规则协调变化，不要求标题/页脚也一起放大。疏密主要映射间距、内边距和留白，不偷偷改尺度、热度排序或自动/手动模式。尺寸增大后通过换行和滚动容纳内容。

初版等尺寸DEMO可用中性相对层级；纯夹具必须能注入异尺寸/排序结果证明接口兼容，不能据此宣称热度业务已实现。Item交互期间热度驱动重排沿用原延后规则。外框拖缩只改变视口，不修改用户偏好。

持久化保存语义值、单位、作用域和映射/schema版本，不能只存滑块第几个节点。复用M05解析/SetPresentation及每海报资源作用域；是否需要新增参数版本/迁移由UX-01对现有schema核对后给出，禁止默改旧字段含义或丢弃未知版本原文。今后便携配置能携带相同语义，AI只能通过受控命令修改这些偏好。

## 4. 滑块与即时反馈

- 整体内容大小“小 / 标准 / 大”、疏密“紧凑 / 标准 / 宽松”直接作为轨道上的三个点位与文字提示，不另列按钮。按真实数值比例布点；点击取精确预设，拖动保持连续、不强制吸附。每项最大320 DIP，窄内容区跟随缩窄，预留后续参数空间。
- 节点之间允许细调，不限制只有三种值；键盘操作同样可达。数字可在提示/高级项辅助显示，不是主要填写方式。
- 拖动时在真实目标海报预览；释放或键盘调节停止后自动提交，不要求再点应用。离开延迟等输入在形成合法完整值并结束本次编辑后自动提交。
- 开关直接发出目标化命令。成功后才标已保存；失败恢复权威值并解释原因。无效/未完整数字不写库，保留可更正提示。
- 即时视觉反馈不等于每像素、每键盘事件一次SQLite写入；高频更新只保留最新意图，按语义编辑合并。一次宏观动作涉及多个底层参数时单命令、完整实体CAS、单revision，不能分字段部分成功。
- 删除海报、覆盖导入、未来高风险主题/AI变更的确认仍保留。“取消应用按钮”不等于取消安全确认或事务校验。

## 5. 编辑会话与提交协调（UX-01待纯验证）

下列是实现约束与待验证方案，不宣称已有适配器满足，也不把其毫秒参数当用户已裁决。

1. 清洁会话读最新投影；手势开始冻结原PosterId、实体版本、请求身份和会话代次。运行预览是有期限的临时覆盖，不是第二持久权威。
2. 指针按住的连续滑动不因短暂停顿被拆成多次提交；释放后提交。键盘/数字编辑用明确的结束事件或有界稳定窗口，阈值由UX-01测试冻结。
3. 一目标一条提交协调通道，串行处理已完成的有效意图、合并尚未提交的同参数更新，防开关/延迟/尺度互相覆盖。不无限重试旧basis；冲突取消过时覆盖、展示最新权威值和原因。
4. 已完成输入和已发请求始终绑定原目标；切目标/关窗不重定向、不假装撤销已提交结果。正在进行的未结束预览、无效文本可取消并恢复最新权威状态；迟到结果不能修改新目标控件或新会话。须验证A→B→A及关闭重开。
5. 隐藏/收起海报可按能力保存非几何偏好，但选择或调整外观不能自动显示/展开。没有可呈现内容时提示“已保存，显示/展开后可见”，不伪造即时画面。未知schema只读。
6. 复用现有交互保护，但浏览中心和一次定位不占长期编辑保护；操作完成/取消/失效释放。与标题手势、R4收展、环境恢复发生竞争时，由既有所有者协调、明确拒绝/延后，不抢占输入或直接SetWindowPos。
7. 恢复依据最新权威状态及有效代次，不把旧预览快照盖回更新后的实体；退出/删除/Explorer或显示环境变化取消旧回调。撤销以完整语义动作计，不把每一预览帧塞入记录。

M08专用“草稿＋应用/取消”只作为旧实现证据；新UI复用SetAutoPosture和验证/调度，不重建自动行为模型。通用会话是否合并实现与旧类型退役清单在UX-01确定，不让两套控件同时写同一参数。

## 6. 真实海报定位提示

- 切换左侧目标触发一次轻量短时描边；“定位”按钮可重复提示。名称可用“定位”，避免把focus误作Windows前台激活。
- 不移动、缩放、强制展开/显示、不抬层、不夺走控制中心的键盘焦点，不更改锁定/姿态/布局或业务revision。
- 提示是目标会话内的临时视觉状态，复用现有呈现/生命周期通道；不创建覆盖普通程序的定位窗、第二海报或每海报常驻计时循环。
- 不高频闪烁；减少动效时使用短时静态描边。这只约束新提示，不将延期的完整收展动效适配记为完成。
- 收起态只标示当前可见标题外框；隐藏、恢复中、目标被删除时不给虚假成功，给出状态提示。前台程序遮挡时不为可见性强制置顶/最小化他窗；可提示用户查看桌面，不能声称已判断遮挡而未实际检测。
- 切目标、重复触发、关窗/退出与恢复不会留下永久边框、旧代次回调或改变命中区域；提示不复用有问题的永久白边作为反馈。

## 7. 几何真实性与旧预览退役

[V3-BUG-002/003](../40_Implementation/V3-04/KNOWN_ISSUES.md)分别记录字段与实际位置错配、预览有效工作区不可辨；不能用隐藏几何字段冒充修复。

- 高级精确几何明确“当前工作区内位置”与“保存展开尺寸”；当前受限大小只作状态说明，不拿它覆盖保存高度。禁止把fallback坐标包装为实际当前位置。
- 编辑开始采用同一可信运行快照和坐标系，带目标/实体/显示环境/布局代次；运行不可用时禁用实际几何编辑并解释，不填0冒充实值。锚点/回退字段留给持久恢复和诊断。
- 请求携带用户实际修改的字段意图；只改宽度/高度不附带陈旧X/Y移动，只改位置不重写尺寸。部分字段表示输入意图，最终空间验证/多字段提交仍完整、原子；环境或读集失效拒绝，不静默覆盖。
- 旧预览删除仅移除UI、专用映射和死测试；用于真实布局查询、恢复、事务的共享读回不可一并删。先确认引用，再替换为定位/几何真实性门；旧包和历史证据保留。

## 8. 验证出口与实现基线

纯模型先验：当前坐标初始化、只改宽高不跳位、受限高度、DIP/物理像素、锚点恢复；宏观值/预设双向映射、异尺寸输入、单目标隔离、无热度写入；预览/提交/失败、快速调节/切目标/关闭/删除/版本竞争、单revision和有界回调。

同一候选实机验：0/1/3张管理、小窗口/键盘、无需应用的即时调整、重启保持、定位不激活不抬层、提示消失、原目录/输入/收展/R4无回归、退出资源释放。只按实际覆盖的显示环境登记，不把新UI通过扩称M08缺陷解决。

UX-01验证后的实现基线见[UX实施记录§2](../40_Implementation/V3-04/CONTROL_CENTER_USABILITY_DELIVERY.md#2-冻结的最小参数合同)：尺度0.8～1.5/疏密0.5～1.5线性倍率，标准1、连续步长0.01、键盘稳定350ms；v1中性兼容/v2偏好，定位1400ms静态提示。纯合同1265与构建已通过，UX-05六组真实控件/进程门已通过，人工U1～U7仍待验。高级精确几何和多字段基准保留一次明确成组确认，不将常用设置重新变成Apply表单。最终视觉皮肤、完整热度公式/主题编辑与AI留后续阶段。
