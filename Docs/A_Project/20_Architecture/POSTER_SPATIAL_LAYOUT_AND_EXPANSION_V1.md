工程设计基线（不是用户逐项指定，也不是已通过的实现）：

- 拖动以接触阻挡和沿边滑动为首版行为，不默认推动整片桌面；缩放遇障碍限制继续增长，不修改邻居尺寸。收展的明确推让与拖缩分开。

- 当前因果归位要求同session、环境及代次证明有效；新进程不重放旧证明，没有有效证明就保留邻居当前位置，不能推测用户未调整过。

## 4. 占位、坐标与操作边界

1. 占位取海报可见外框矩形；透明/半透明主题不免除碰撞，装饰阴影不计入占位，圆角空隙不作为另一张插入通道。边界接触可允许，正面积相交不允许；可选间距不是已冻结的像素常量。
2. 持久几何继续采用现有逻辑尺寸/锚点意图；计算快照统一到当前工作区的同一坐标系，DPI 转换后向外取整并复验像素占位。输入、视觉、求解必须引用同一版本，禁止混用屏幕像素与 DIP。
3. 首版工作区按所在显示器扣除任务栏；不把其他屏幕的空位作为推离当前屏幕的理由。主屏门不冒充多屏认证。
4. 普通程序、全屏程序、桌面图标不是需要推动的海报障碍；不修改 Windows 原生图标坐标。应用层级规则保持不变。
5. 显示中的收起海报只占标题条；隐藏者不占当前空间，但重新显示必须求解。拖动、四边/四角缩放、收展、中心数值编辑、新建/复制、显示、导入/恢复均不能绕过同一策略。
6. 恢复/导入的历史重叠或超大配置不静默覆写。先保留原意图及备份，生成可预览的合法投影；无解目标进入可由中心访问的恢复状态，不以重叠显示或自动删除掩盖。环境强制变化不是另一个海报的推动，需独立声明投影原因；不能借它绕过锁定。

## 5. 无障碍时的保尺寸两阶段展开

定义：工作区顶部 T、底部 B；当前收起顶边 y0、高度 c；原展开高度 H。先决条件：收起框有效且 `c ≤ H ≤ B-T`，宽度也能容纳。外框扩展不缩放标题、按钮、Item；内容仍按已接受的响应式列数与连续滚动模型呈现。

```text
extra = H - c
freeDown = max(0, B - (y0 + c))
d = min(extra, freeDown)
u = extra - d
finalTop = y0 - u
finalBottom = y0 + c + d
finalHeight = H
```

- 第一阶段：顶边保持 y0，高度从 c 增至 c+d。
- 还有 u 时第二阶段：底边保持 B，高度继续增至 H，标题随顶边向上移动；不可突然跳转标题命中区域。
- 贴底时第一阶段长度为零，直接向上；空间足够时没有第二阶段。不要求固定动画时长，关闭动画时终态仍须一致。

示例（统一逻辑单位）：工作区 `[0,1000]`，c=60、H=600。

| 收起顶边 | 下扩 d / 上扩 u | 过程 | 最终范围 |
| --- | --- | --- | --- |
| 100 | 540 / 0 | 顶边100保持，直接向下 | 100..700 |
| 940 | 0 / 540 | 底边1000保持，标题向上 | 400..1000 |
| 760 | 180 / 360 | 先760..1000，再顶边移至400 | 400..1000 |

本节公式只描述可容纳完整高度、无邻居阻挡的默认轨迹。若H大于工作区或默认推让路径失败，不再立即拒绝；按以下回退链选择全尺寸替代或临时高度。临时模式不冒称完整尺寸成功，内容保留并可滚动，不承诺一次显示任意数量。

### 5.1 三档裁决与候选顺序（R2）

同一冻结场景内定义：Hpreferred为保存的展开高度，Hminimum为当前内容度量得出的最小可用高度，Heffective为本次合法实际高度。源的X、宽度及内容参数不变，所有占位继续扣除任务栏/AppBar并纳入邻居碰撞。

| 顺序 | 求解/结果 | 必须遵守 |
| --- | --- | --- |
| 1 完整尺寸 | 有下方合法容量始终先下扩，再在同一场景向上补足；只有下方容量为零才纯向上。输出Full，Heffective=Hpreferred | 下方链末端贴底/锁定仅限制下扩容量；不能跳过A与B间空隙，也不能因为向上单独足够就提前接受纯上方案 |
| 2 临时受限 | 完整尺寸不可行后，在同一X/宽度及当前竖直推让规则下求最大合法Havailable；Hminimum≤Havailable<Hpreferred时输出Constrained | 不缩放内容、不改Hpreferred、不缩小/收起邻居；同高先利用下方容量，再向上；只推动必要邻居且不随枚举顺序跳动 |
| 3 空间不足 | Havailable<Hminimum，输出InsufficientSpace | 源保持收起，邻居原位，零布局提交；只反馈按钮轻抖，不播放半展开/推让再回滚的假尝试 |

完整候选允许的推让仍服从固定障碍/工作区/连续路径及全组有效性，不自动扩充为横向绕行、跨屏搬迁或任意装箱。上下组合的容量必须从同一组合法终态和连续轨迹证明，不能把分别以不同邻居终态计算的上/下最大值简单相加。求解预算耗尽、旧读集、宿主未就绪等应独立报告，不能冒称已证明InsufficientSpace或因错误而静默降成Constrained。

所有候选均先完整准备，再只呈现选中结果；失败候选没有窗口动作、持久化、因果账本或视觉预演副作用。已有无障碍三种方向轨迹保持兼容，针对新阻挡才选择替代路线。

### 5.2 最小可用高度合同

用户确认的语义为“完整标题区域＋至少一行完整Item内容区＋必要页脚”，工程度量建议为：

```text
Hminimum = ReservedTop + CompleteItemRow + ReservedBottom
```

- ReservedTop包含从可见外框顶到内容viewport顶的完整必要占位：标题栏/操作按钮、固定标题说明以及实际内边距/间距；不能只计算60DIP收起条而漏掉固定标题块。
- CompleteItemRow包含当前模板/密度下一行卡片或图标、标签及行内间距；同一行取完整所需高度，不能仅用图片高度。空列表也用当前模板的一行占位，不取ItemCount×高度。
- ReservedBottom包含viewport底到外框底的必要页脚、边界安全距离及间距；各部分不重复计算。
- 逻辑单位度量与renderer共用同一版本，最后按当前DPI和呈现边界规则保守投影到物理像素再比对。不要把现有固定窗口最小高度、截图像素或主题缩略图高度当作本合同。
- 恰好Havailable=Hminimum允许临时展开，少一个物理像素则拒绝；当前主题/内容参数改变后需使旧度量/计划失效。若保存高度本身低于当前Hminimum，作为配置/内容度量不兼容报告，不偷偷放大或覆盖用户尺寸。
- Hminimum约束最终展开终态，不要求收展动画的每个中间高度也容纳完整一行；中间帧继续裁剪视觉/输入到当前viewport，不能因此中断动画或让内容覆盖页脚。
- M05尚未实现完整ContentMetrics时，先从当前布局实际常量/度量抽取一个共用合同；后续M05接同一入口，不能要求先完成整个主题平台才修复此交互。

### 5.3 意图、有效投影与反馈边界

保存的ExpandedHeightDip及归一化完整高度仍是用户意图；Heffective、选定方向、Constrained标记与EffectiveBounds属于带场景/布局版本的可重建有效投影。不能只在求解器里改一次高度，而让三端刷新、状态提交或物理读回又把它解释成新的完整高度。

中心与海报读取同一有效结果，必要时可解释“空间受限，当前临时高度”；不各自在UI层重新计算另一份大小。源收展、实际受影响邻居及推让因果仍走一次完整读集CAS；收起继续沿此次有效锚点逆过程，并复用R1同步归位。重启/恢复及跨机配置仅携带持久尺寸意图，当前投影按新场景重算；严禁保存临时受限高度、重放过期动画或静默穿过障碍。

空间恢复后的下一次显式展开重新优先尝试Hpreferred，不加入“持续监听任何空位并自动撑大”的新动作。显式尺寸编辑是另一种用户命令，不能将自动受限投影等同于一次resize。新策略应在后续实现中给出清晰的意图/有效几何端口，是否需要新增持久字段需单独说明，当前不假定或改动migration。

InsufficientSpace是正常可行性结果：窗口几何、收起标记、邻居、布局代次及推让证明均不变。仅展开按钮视觉作短促轻抖，不移动整个HWND或输入岛、不抢焦点、不抬层、不弹模态框；连续点击合并提示、结束归零，减少动效时短暂静态强调。控制中心对应命令需得到明确空间不足结果，自动触发不反复抖动。具体微动幅度/时长作为可调整样式参数，不写入碰撞尺寸。

## 6. 碰撞与推让求解

拖缩以连续扫掠或等价保守算法检查路径，不仅检查鼠标事件的终点。碰撞裁决不能结束 capture 或要求重新按下；沿边滑动、斜角和越过多张的快速移动要有确定性测试。锁定的邻居禁止被推移；锁定源仍按原合同禁止人工拖缩。

收展先算无障碍理想轨迹，再根据增长前沿沿下/上方向传播最小必要位移：源触及 B，B 又触及 C 时纳入同一候选变更集。按稳定 ID/几何顺序消除遍历偶然性；检测环和迭代预算，不能无限递归或偷偷把别的海报收起。独立性的含义是只有明确纳入本操作的邻居几何可变，邻居尺寸、锁定、收起、主题、内容顺序不变。

任一候选碰到锁定者、工作区边界或无可行通路，丢弃整个候选并保留上次有效结果，再按§5.1选择替代；所有候选与最小高度回退均不可行才拒绝请求。不先推B后才发现C无路可退，不擅自横向绕行或跨屏搬迁。

收起通常释放空间，但沿原路径返回标题条或执行邻居归位也可能接触新障碍，仍须求解。自动收展采用同一规则；拖动、缩放、菜单/确认框活动期间不插入另一轮空间手势。

## 7. 条件归位与因果账本

2026-09-08同步时序补充：先冻结有资格且全程可安全归位的子集，再在源海报每个收起阶段内随边界释放空间推进这些邻居；源和邻居同一批次提交，连锁不按海报逐个等待下一段动画。源完成收起时应已完成该子集归位，不追加归位专用尾帧。保持既有合理间距/不额外拉大空挡；不能以提前相交、突破锁定或半归位替代安全条件。本条为用户明确调整，替代先收完再归位的旧时序。

每次成功推让生成属于源 PosterId / operationId 的布局记录：受影响 ID、推让前后几何、几何变更代次、相关锁定/显隐/收起状态、工作区/拓扑及会话有效期。几何代次不是 global revision；无关主题变化不应自动剥夺归位资格。最终字段、持久化和迁移在 M04-02 冻结，不能改写已发布 migration。

归位检查同时满足：

1. 对象仍存在，且仍处于该推让预期位置；发生过人工移动/缩放（即使移回相同位置）也视为再次调整。
2. 未被另一轮独立推让接管；锁定、显隐、收起或布局归属变化使旧记录失效或必须重新评估，绝不推动当前已锁定者。
3. 环境可匹配，原位置和归位路径没有新障碍；仅终点为空但路径穿过锁定海报不算安全。
4. 采用最新完整读集复核；源收起和可归位子集作为一个合法布局提交。不满足者保留当前位置，并记录未归位原因，不强制全部回旧位置。

归位记录一次消费/失效，重复收起或重复请求不能二次搬动。源被删除不默认触发一场未确认的布局恢复；相关记录失效。跨重启若没有持久证明，邻居保持当前位置；跨机配置不携带旧 HWND/回调/会话代次或推让回滚指令。

## 8. 模块、CAS 与物理提交边界

| 责任 | 设计落点 | 约束 |
| --- | --- | --- |
| 空间纯计算 | Domain 几何策略 | 输入快照/意图，输出候选、阻挡和轨迹；不访问 SQLite、HWND 或主题 |
| 空间操作协调 | Application PosterSpatialCoordinator（职责名，可并入现有服务） | 收集所有参与/障碍读集、操作幂等、推让因果和失败结果，不新增权威库 |
| 状态提交 | 现有 StateCommandPolicy / IStateCommandRepository | 扩充异构多 Poster 几何命令，同一事务 CAS 和 committed revision；不能用现有仅批量锁定/显隐冒充完成 |
| 呈现协调 | App 会话注册表＋既有 Host/几何提交 | 预备每个窗口视觉尺寸、裁剪、输入；同轮批量提交及读回，保留已验证层级保护 |
| 中心/托盘/海报 | 同 revision 的三端投影 | 展示阻挡/降级；中心选择是 UI 状态，命令目标在发出时冻结 |

读集不仅包含被移动者，还包括被用来证明空间可用的障碍及相关目录版本：未移动障碍的并发移动、新增海报、删除/隐藏/锁定变化都可能使方案过期。全局无关设置更新不应一律阻塞；目录插入导致的“幻影障碍”必须被检测。

手势内只产生暂态候选和有界预览，不每像素写库；结束时一次校验/提交，失败回到已提交布局。离散收展先完整预备并复核再提交。新的同事务投影不能被旧恢复回调分拆覆盖。Explorer generation / 显示拓扑变化、源删除/隐藏或退出时取消整轮旧方案，复用 M03 lifetime/epoch 门。

数据库事务、Win32 多 HWND 移动和渲染合成并不构成跨系统原子事务。需要预备完整变更集、同轮布局版本、批量位置提交、视觉/输入读回和失败账本；不能只加 DeferWindowPos 就宣称无闪烁。物理失败时禁用不匹配输入、保留/恢复最近完整可用呈现并重试权威快照，报告 degraded，不伪报所有窗口同步成功；不以静默数据库回滚覆盖后续命令。

## 9. 自动与人工出口

| 用例组 | 必须证明 |
| --- | --- |
| 中心选择 | A/B/C 列表完整，选择B后动作只作用B，重开/删除目标/零目录安全 |
| 几何性质 | 有效占位无正面积相交、尺寸保留、工作区内、确定性；临界接触和 DPI 取整复验 |
| 连续拖缩 | 四边四角、贴边滑动、快速越过障碍、列数切换；不断 capture、不穿透、无白底闪帧 |
| 方向与受限展开 | 既有足够/贴底/部分空间及§5.1～5.4邻居阻挡回退；完整优先/临时最小阈值/拒绝轻抖，标题按钮命中跟随，内容可滚动且保存尺寸不变 |
| 推让 | A→B→C，锁定B，锁定C，工作区满，迭代预算耗尽；失败无半提交 |
| 归位 | 未改者归位、手动改动者不归位、改回原数值也不误归位、新占位/再次推让/锁定后不强归位；可安全归位子集 |
| 并发恢复 | 未移动障碍变更、目录插入、陈旧请求/重放、删除/隐藏、Explorer/拓扑失效和退出；旧回调不复活窗口 |
| 物理失败 | 第N窗口预备/移动失败，投影不乱序、不留错误输入；中心可见降级、可恢复，不越过普通程序 |
| 其他入口 | 中心数值、新建/复制/显示、历史重叠配置和跨机导入复用约束；不改用户文件/原生图标 |

历史 M03 的163/163及Release/smoke是会话证据，不覆盖这些新行为。本轮没有运行应用测试；实现时先纯合同、再真实多窗口 smoke、最后集中短人工门，不重复不相关的全套 DPI/安装认证。
