## 1. 本次明确修订

**下方仍有合法容量时，先向下展开至所需高度或下方极限，再向上补足。只有下方容量为零时，才纯向上展开。**

“下方容量”不是只量到屏幕底部，也不是只量最近的空白：须同时考虑工作区边界、固定障碍、可移动邻居及其整条推让链的合法移动余量。先使用空隙，接触邻居后仅作必要推让；不能跨过锁定者，也不能将链末端推出工作区。

旧 R2 的“常规失败后先接受向上完整方案”已被替换。上方单独足够也不能跳过下方余量。全部候选均先纯计算，不能让窗口先撞一次、失败回退，再尝试另一方向。

优先级依次为：

1. 安全和一致性：不重叠、不越工作区、不推动锁定邻居、不提交过期结果。
2. 在既定同列竖直推让模型中尽量恢复保存高度；无完整方案才考虑临时高度。
3. 可达到相同高度时，优先利用下方容量；动画先下、后上，不同时向两侧拉伸。
4. 只移动为本次操作确有必要的邻居；稳定结果不受集合枚举顺序影响。不承诺任意二维最优装箱。

## 2. 术语与共同不变量

| 项目 | 含义 |
| --- | --- |
| 源 A / 邻居 B、C | 本次点击收展的海报 / 可能被推让或归位的其他海报 |
| Hc | 当前收起占位高度 |
| Hp | 保存的首选展开高度，即用户意图 |
| Hmin | 当前模板完整标题区域＋一行完整 Item（含标签）＋必要页脚与间距 |
| He | 本次实际展开高度，最多 Hp；空间受限时只是有效投影 |
| d / u | 在同一合法场景中选中的向下 / 向上增长距离；He = Hc + d + u |
| 工作区 | 所在显示器扣除任务栏/AppBar后的区域；不借另一屏幕空位推进邻居 |
| 占位 | 可见海报外框矩形；圆角/透明区仍参与碰撞，装饰阴影不额外占位；贴边可以，正面积重叠不可以 |
| 内容 | 外框扩展不同比例缩放文字、按钮或 Item；列数可重排，溢出采用连续滚动并与页脚隔离 |
| 状态边界 | 成功收展可提交收起标志、源/参与者位置及因果证明；临时 He 不覆盖保存的 Hp/完整归一化高度 |
| 原生边界 | 所有海报低于普通/全屏程序、高于桌面图标/壁纸；不改变桌面图标位置，不用抬层遮盖碰撞 |

当前内置模板 Hmin 为346 DIP：46＋130＋10＋118＋42，各段按DPI向外取整。它是共享内容度量的结果，不是所有主题永久共用的固定高度；空列表也保留一行度量。最终展开状态须满足最小高度，动画中间帧不要求一行完整可见。

下表“已接入”指代码与合同自动验证，不等于该行已有真实鼠标/视觉 PASS。历史 G1～G4 用户 PASS 保留；本次调整的方向和观感待受影响人工门确认。

统一几何：初始顶边 y0，初始底边 y0+Hc。下段结束为 [y0, y0+Hc+d]；上段结束为 [y0-u, y0+Hc+d]。上段固定的是**已求得的合法底边**，不一定是屏幕底边。

### 3.1 本次反馈的直接算例

工作区0..1000；A收起占600..660，Hp=600；不可推动的B占800..1000。

| 阶段 | A范围 | 解释 |
| --- | --- | --- |
| 起点 | 600..660 | 高60 |
| 先下扩140 | 600..800 | 先利用A与B之间的空隙，B不动 |
| 再上扩400 | 200..800 | 固定底边800，标题上移至200；恢复高600 |
| 本次排除的旧结果 | 60..660 | 虽然也高600，但跳过下方140空隙，不符合最新要求 |

若上方固定障碍占0..350，可得350..800、高450；若低于当前模板最小高度则不展开。算例中的600/60是说明用数值，不改变实际模板度量或工作区坐标。
