## 1. 用户决定与本轮解释

用户认可样片夹方向，要求它可以收起；海报模板不能只换主题色，应包含顶灯照明、雨电外框等有趣体验。既有换色模板可以归为“极简主义”。AI辅助风格化的长期目标不能被缩减为配色生成。

因此区分两个入口：顶栏“主题”仍只更换控制中心颜色；“海报模板”面向当前海报的材质、字体、装饰、受控交互光影，以及未来经过验证的内容结构。本轮不是在用“视觉层独立”否定结构型模板，而是先验证用户给出的两个例子是否必须重写布局。雨天第一版的边框天气现已按反馈替换为云下透明场景，旧验证只保留为历史证据。

样片夹保留当前模板名的折叠行，按钮支持鼠标/键盘展开与收起。收起不切换模板、不折叠真实海报、不重置内容滚动。折叠状态仅属于本页UI，不加数据库字段；默认打开为本轮便于比较的假设。

## 2. 看过哪些参考，借鉴与不搬入什么

2026-09-24只读查看公开源码，未安装、运行或拷贝项目资产/实现。下列为思想借鉴；本原型CSS/JS为独立实现，不是第三方代码移植。

- [HTML-Light-Demo](https://github.com/jinruozai/HTML-Light-Demo)：[MorsLightCanvas.tsx](https://github.com/jinruozai/HTML-Light-Demo/blob/main/app/light/MorsLightCanvas.tsx)用HTMLTexture与Three.js灯光表现内容受光，含鼠标目标、悬灯Verlet约束、稳定后停止requestAnimationFrame和资源释放。借鉴“同一内容表面受光、稳定时休眠”；不引入WebGL/HTML-in-Canvas、完整物理摆动、灯具抓取/右键/双击手势，避免侵占内容操作。
- [雨与闪电示例](https://github.com/Silvana-kite/html-css-js-project/tree/main/CSS%E5%92%8CJavaScript%E4%B8%AD%E7%9A%84%E6%83%8A%E4%BA%BA%E9%9B%A8%E5%92%8C%E9%97%AA%E7%94%B5%E5%8A%A8%E7%94%BB%E6%95%88%E6%9E%9C)：index.html持续创建/删除雨滴；style.css用位移缩放模拟下落与落地扩散，用高亮滤镜模拟闪电。借鉴天气氛围，不照搬持续DOM创建、原强亮度跳闪或无限整页特效。原示例不是现成海报外框，本轮是围绕内容边框的再设计。

## 3. 三个系列与可试操作

| 系列 / 样例 | 超出换色的变化 | 动作与结果 |
| --- | --- | --- |
| 极简主义 / 夜航、清简等 | 原有平面材质与标题有无；保留为低干扰选项 | 旧换色样例仍可选，不强加动效 |
| 交互光影 / 深夜书桌 | 悬吊灯具、暖色光锥/光池、纸质纹理、卡片局部亮度及小幅投影、衬线排字 | 鼠标在海报内移动即照向当前位置；无需按住灯具。离开回静态中心照明；键盘聚焦Item也照向它 |
| 天气场景 / 雨夜窗边（云下修订） | 顶部完整雷雨云；整体海报透明、无卡片底板/窗框/整体阴影；云下雨丝铺满内容背景，低频云内柔光/局部闪电 | 雨在Item后方下落而非仅限边沿；不盖文字、不拦输入；单项轻量底片仍保留可读性。关闭动效保留云朵，只隐藏雨与闪电；无声音 |

初次打开演示以“深夜书桌”展示，不是新海报的生产默认。首组三张包含极简/顶灯/雨夜，其他模板仍可翻页或搜索。13份初始样例，自己的副本仍入“我的”；从场景另存会保留effect/family，不静默退回纯换色。此表单只是受限样例，不是场景创作器或AI生成器。雨天不再显示整块背景色，原背景色字段仅保留样例参数；关闭副标题仅隐藏云内标语，保留云体占位以免内容顶入云中。正式参数表需依各模板能力定义，不能直接把此演示表单作为通用模板协议。

“环境动效”只影响当前演示海报；灯光对键盘聚焦的响应不增加另一套内容选择规则。Item文字始终可读，不要求先照到才可见/可点击。浏览态的场景卡片取消冗余DEMO悬停说明，避免说明挡住光影；全页仍明确DEMO，不执行真实打开。

## 4. 底层设计结论：扩大模板表达，不把操作交给模板

以下是后续主题平台的**设计建议**，尚未写入生产manifest或实现。当前两例不需要更改格子大小、排名/图钉、solver、滚动轴或输入命中；HTML仍是原内容。视觉层不能自行推进布局revision。

| 层 | 允许表达 | 不允许绕过 |
| --- | --- | --- |
| 结构与度量 | 标题/底栏、已验证的内容区域、内边距、最小可读与装饰安全带 | 结构变化须形成显式度量提案，经同一solver及事务验证；不能用装饰CSS临时挤压/裁切Item |
| 表面绘制 | 背景、边框、字体、Item材质、图案、封面适配、裁切 | 布局与绘制使用同一几何版本，Item身份不复制、不由材质改变尺寸或命中 |
| 被动效果 | 宿主提供的局部指针、焦点、可见性、时间驱动受控灯光/雨粒 | 无输入capture、全局钩子、任意点击消费、Shell或文件权限；鼠标点到内容还是原内容 |
| 参数与资源 | 有范围的强度/配色/素材引用，按模板能力显示少量参数 | 不因为主题自由度高就向用户暴露全部内部数字；不执行任意导入脚本/原生代码 |
| 生命周期 | 启用、静态降级、暂停、恢复、卸载 | 不另建每海报无界调度器；不在隐藏/退出后继续资源工作；故障保留last-good或极简fallback |

今后“标题在左侧”“多个内容区域”“不规则外框”等确实会影响结构，应在稳定前置度量中声明与验证，而不是宣布所有模板永远不能改布局。应用前预览影响；保护Item尺寸/顺序/图钉，冲突显式反馈。用户当前只是授权试原型，不视为已批准这套完整结构协议。

R4约束继续保留：后续生产接入须在动画前固定内容度量/效果裁切，整段统一提交，终态恢复并解除租约；光影不得逐帧反过来驱动Measure/Arrange、宿主尺寸或另一套收展模型。光影/天气在编辑、拖动/缩框等高优先交互期间如何暂停，以宿主许可为准；本原型只真实演示了整理、页面可见性和减少动效，不冒充WinUI/R4组合已验证。

## 5. AI主题的安全接口预留

建议AI未来输出可校验的模板描述与资源，而不是任意JS/XAML/native程序：基础模板ID/版本、结构preset/区域、材质tokens、白名单effect ID和有界参数、资源清单/大小、静态fallback、权限声明。当前lamp/rain只是硬编码演示ID，不是可导入协议。

仍走既有ThemeInstance/AIChangePlan：固定目标和预期版本→diff/预览→确认→核心单事务→可撤销。切控制中心选中项不改变既定目标。结构/素材/安全加载的完整实现仍归V3-07/08，不借原型提前搬移文件或接AI服务。

## 6. 有界实现与待验范围

- 只在样片夹加载[场景CSS](Designs/content-layout-controls-scenes.css)和[场景脚本](Designs/content-layout-controls-scenes.js)；原B+布局脚本不变。无外网资源、音频、WebGL、外部库或持久化。
- 悬灯不做物理模拟，只在输入/焦点/滚动或状态变化时更新有限卡片；指针事件合并到一个待执行帧，不持续空转。
- 雨滴固定28个，分布在云下整个透明内容区；CSS动画在非雨夜/关闭/整理/不可见/页面隐藏/减少动效时停止。云内柔光13秒一轮，非全屏白闪；这些数值只是探索参数，不是性能/光敏安全认证。
- 所有效果节点pointer-events:none和aria-hidden。灯光在Item上方，雨天整体效果在Item下方；顶部云朵占既有标题/副标题槽，内容下方为透明。绘制轮廓不等于交互区域，原型仍为矩形宿主，未实现异形原生窗口/透明区桌面穿透。透明外观不会自动改变空间碰撞占位。
- 遵循减少动效，无声静态降级。关闭效果不改Item/模板ID，恢复只恢复呈现。
- 真实1/3/6海报GPU/内存、系统遮挡/电池/高对比、原生DPI、收展/拖动全过程与退出资源尚未验证；不能把浏览器原型PASS当生产准入。
