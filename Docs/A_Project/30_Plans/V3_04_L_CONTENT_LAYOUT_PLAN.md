## 4. 关键连续场景矩阵

| 场景序列 | 不变条件 / 预期 |
| --- | --- |
| 网格/跨度提示四种组合→选择/拖动/缩跨度 | 两开关互不联动；左上角跨度提示与布局同快照；卡片位置、排序与命中不受显示开关影响 |
| 新增→换皮肤→改变跨度→关闭重开 | 同一引擎身份，可编辑；主题不覆盖order/span；一次动作一个revision |
| 主卡变大→邻项重排→撤销→重做 | 不重叠、不漏项，稳定ID/顺序，撤销还原完整语义 |
| 固定大卡→自动重评→插入新项→解除固定 | 固定语义不被静默移除，剩余项有稳定可达路径 |
| 编辑卡片→容器变窄→变宽 | 手势代次校验；preferredSpan/基准尺度不漂移；受限投影不写回 |
| 滚动至大卡中段→热度重排 | 同ID项内滚动锚尽量保持，已删除锚有确定后继 |
| 拖动中主题度量更新/自动重评 | 不抢占本次手势，最新待用提案在安全点统一应用 |
| A编辑→切B→A被删除→旧回调到达 | 不重定向、不复活A，不影响B |
| 1/3/6海报开关/隐藏/恢复/退出 | 会话独立，资源不单项常驻；退出ledger归零 |
| 导入旧网格/新跨度/未知未来布局 | 已知合法迁移；便携未知必需版本拒绝并保留源文件，本地未知原文只读保留，不冒充兼容 |
| 海报收展/R4→内容滚动/编辑→异常取消 | 原宿主与空间所有者不变，输入不使用旧快照，不制造白条 |

## 5. 风险及防止范围失控

- “自由”不等于任意重叠画布；首轮采用跨格/区域/尺寸覆盖足以表达参考的结构层级，素材完整度留07。
- 不将图标放大和容器占位混为一件事；卡片、图片、文字/点击各有边界但共用快照。
- 旧行流/子列具体算法不是强制第二实现；由同一layout engine策略吸收。保留不重叠、连续可达、自动/固定/手动的产品不变式。
- 不先实现复杂粒子/动画/AI来证明布局；先求解、事务、静态/可交互呈现。
- 如某种跨度在极窄宽度不可用，应暴露响应策略和原因，不静默丢Item或改用户偏好。
- BUG-001仍是已知风险，L05碰到同输入边界应按既有证据重新评估，不能借L阶段宣称修复。
