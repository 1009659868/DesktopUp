### 协议 v1

- 可信编译期注册 `IContentBehaviorModel`，运行时按海报选择注册模型；替换模型不修改统计、producer 或窗口调用链。新增任意 DLL／脚本、不重启安装外部代码不在本批范围。
- 输入为冻结作者文档、只读 Item／使用统计、视口、统一时间与请求版本。不给数据库、路径执行权、窗口或计时器。保留既有统计口径、幂等消费与真实对象身份。
- 描述符区分协议版本、模型 ID／版本、参数版本与能力位；提案含可选排名、连续相对尺度、区域内逻辑网格 Column／Row 和受限过渡。缺省排名沿作者顺序；缺省尺度不覆盖作者尺寸；缺省位置走既有排版。
- 位置只作用于派生画面，不写入作者的固定位置。坐标必须有限、有界；宿主复用现有布局器验证占位、保留区与可达性。手动模式、固定位置、顺位图钉优先；空间变化造成位置不可用时降级为标准排版，不搬动文件、不制造不可达卡片。
- 过渡首批支持 None／Fade（最长 300 ms，线性或缓出）；目标几何与输入区域先同代提交，再短淡入，不是逐帧位移动画。遵守系统减弱动画设置；新呈现、交互、收拢或退出均结束过渡，不增加常驻计时器。
- 宿主校验模型能力、身份、成员、有限数值、版本及作者／视口见证；计算在 UI 线程外，有取消和超时预算，同一模型不允许挂起计算无限堆积。异常、迟到和不兼容结果不替换最后有效提案；不自动重试失控模型。
- 海报模型选择随既有 Activity 配置保存，不增加事实库或 SQL 迁移；缺省为已验内置算法。参数版本 v1 复用现有尺度／平滑参数，不引入任意参数 JSON。新配置不改变旧模型公式、统计或默认动画行为。

## 扩展一个模型

实现 `IContentBehaviorModel.Descriptor/Evaluate`，只读取 `ContentModelInput`（含可选的最后已呈现快照及其版本）；返回 `ContentModelOutput`，不自行生成海报／作者／请求身份。模型描述符需声明实际使用的能力。将实例加入组合根传入的 `ContentModelRegistry`；控制中心自动列出描述符，无需修改 producer 或窗口的类型判断。参数 v1 使用 `ContentActivityOptions` 的现有尺度和平滑字段；新参数形状须升级合同，不把未校验字典穿透至 UI。

接入门：使用同一统计输入，测试缺省维度、非法值、取消／迟到、手动／图钉、空间降级及状态保存。模型若依赖 `CurrentLayout`，必须理解其可能是前一作者版本；宿主仍以本次作者、成员、实体及视口见证接纳输出。位置是区域内 Column／Row；不是桌面像素，也不改变真实文件路径。

宿主计算预算 2 秒（包含等待同模型的计算槽）；每模型最多一个计算，超时取消但不强制中止线程。可信模型若不响应取消，该槽保持占用直到自行结束，后续等待会超时而不增生线程；其他模型不被它占槽。这不是不可信代码隔离机制。

当前两个注册模型：`desktopup.activity@1` 保持已验公式；`desktopup.recent-strip@1` 按最近打开排序、沿用连续尺度计算、建议单条带位置并淡入。任意顺位图钉存在时，本批保守地忽略整组位置建议，沿既有带图钉排版；不是取消图钉。

实现／验证状态见[本批交付](../40_Implementation/V3-06/PLUGGABLE_MODEL_DELIVERY.md)。发布包 preview-20261026.1 尚不含本批实现。

## 历史：发布前现状与缺口

`ContentActivityProducer`直接调用静态`ContentActivityPolicy.Evaluate`，Bootstrap构造固定producer；`ContentHeatProposal`只有Rank、RelativeScale、Reason及版本，校验仍引用内置policy版本。已有事实／策略／会话分责、连续提案及交互保护可复用，但没有模型注册选择、可替换接口、目标位置或动画提案。不能把现状描述为已可插拔。

## 历史：初步协议方向

- 输入：不可变Item身份／统计／作者意图／当前有效布局、视口及约束、统一时间、模型参数；不提供数据库、窗口或文件句柄。
- 输出：声明能力与版本的提案；可含排名、目标比例／尺寸、海报内目标位置、受限过渡建议及解释。缺省维度沿宿主默认规则，不强制每个模型包办全部职责。
- 版本：区分ProtocolVersion、ModelId/ModelVersion、参数版本和请求序列；携带成员／作者／环境见证，不用内置模型版本充当通用协议版本。
- 宿主：校验有限数值／范围、成员身份、坐标系、空间可达性和版本；处理手动／图钉优先、交互保护、迟到淘汰、空间限幅与失败保留。模型只建议目标，不能直接重排控件、驱动计时器或搬动真实文件。
- 动画：允许声明支持的过渡种类、时长／曲线等建议，由统一呈现调度执行、取消和降级；不把每帧UI执行权交给模型，不让模型绕过系统减弱动画设置。
- 加载与安全：首批先确定编译期可信注册、外部受控宿主或声明式模型的适用范围；“可插拔”与“不重启动态加载”分开定义。任意原生DLL／无限脚本执行不作为默认实现。

## 历史：初步实施顺序

1. 核对现有链路，冻结最小输入／输出及能力协商，明确位置坐标／约束和动画合同；不用新平台包围全部代码。
2. 内置模型改为同一协议适配；接入至少一个独立替代模型证明不是接口装饰。模型替换不改producer／窗口调用链，移除被替代硬编码，不建第二套事实库。
3. 选择／参数与安全切换：候选计算通过后原子替换，统计不重置；不兼容、异常、超时或过时结果保留最后有效画面。人工覆盖及文件安全保持。
4. 定向合同和一次组合冒烟，再集中两组体验：模型切换／统计保真；排序尺寸位置过渡及手动保护。不重复已验安装／拖放矩阵；成本先测量新增开销，保留现有未定因。

此为下一批准备，不改变当前发布模型行为。实现前从届时已确认impl/develop派生新功能分支；统一协议获验后再决定发布。剩余成本、P1/R6锁冲突、历史卸载／升级首因继续独立保留。
