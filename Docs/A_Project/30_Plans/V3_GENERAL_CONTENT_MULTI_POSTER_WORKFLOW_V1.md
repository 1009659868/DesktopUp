### 7.1 真实热度链路与当前分支状态（2026-10-26）

以下为本轮整合的已验功能及后续决定。旧准备稿的“只在下次展开更新、不主动扩框、整体尺度0.4～3”已被替代；A层正文及导航已逐项协调，原始来源见[审查快照](../40_Implementation/V3-06/ACTIVITY_BRANCH_REVIEW_20261026.md)，本轮证据见[整合记录](../40_Implementation/V3-06/ACTIVITY_DRAG_INTEGRATION.md)。不重复询问已定规则。

**职责与数据链：** 可信打开完成 → 持久成功事实 → 增量幂等统计 → 纯评分/连续尺寸提案 → 海报安全时点应用。复用ContentActionService/SqliteContentOpenJournal已有事实，不新增第二套打开路径；Application负责消费协调和提案生产，Infrastructure负责事务/读写，Domain负责纯数学/确定排序，PosterContentSession/ContentHeatSession保护会话与人工意图，Presenter/原生命中复用同代几何。不向大窗口或SQLite类塞评分政策，不为接口拆出只有转发的层。

1. **真实统计。** 仅可信成功交接计数，选择／扫描／Reveal／无成功证明的失败取消不计；取消发出后真实交接已成功仍按原合同记事实。迁移027提供显式队列序列和事务游标，每批最多128条，统计／游标／移出队列原子提交；失败只重试统计，不重放打开。ContentItemId随当前有效对象转移，移除后同路径重加不继承旧热度。
2. **排名规则。** 已实现最近使用40%＋有效频次35%＋新项曝光25%，同分保序。已采用连续公式：H=7+21×min(1,ln(1+N)/ln51)²，D=max(0,min(A−30,I−14))，E=N×max(0.1,2^(−D/H))；A为加入天数，I为距最近成功打开天数，N为累计成功次数。旧有矛盾公式不再作为待实现方案。
3. **连续尺寸。** 当前热度相对倍率默认0.5～3、无数据1.5，K=20低样本平滑可配置；整体倍率独立0.4～1.8，以标准图像区域48 DIP校准整套几何。每次从作者基准派生，不累乘；旧注入五档只保留兼容，非生产热度。旧preferences v1合法值可读、超新上限先内存限幅，正常提交前保留原JSON。
4. **人工意图与发布时机。** 成功事实消费提交后按当前归属唤醒相关海报，立即入队、每海报单计算并合并最新请求；交互／过渡期间延期，版本过时丢弃或重算。热度可在安全空间原点扩框，不推邻居；受阻按现框限幅，用户resize只重投影、不反向撑回。手动模式、手工尺寸、图钉和原文件保护保持。
5. **可替换与成本。** 纯规则、事实／策略分离、事件驱动有界消费已接，不是任意DLL／脚本热加载。无每海报新增高频timer不等于所有全局读、锁等待和大集合成本已认证；沿现有成本计划测量，不删保护换数字。

规则与集中体验按该分支记录及用户确认承接，不另建平行实现。临时排名奖励、主动刷新菜单、动态代码插件不扩入本批；共享多引用规则不得恢复。内置功能随preview-20261026.1发布；可插拔增量此后随preview-20261026.2发布，准确差量见§7.3，不混用各轮验证范围。
