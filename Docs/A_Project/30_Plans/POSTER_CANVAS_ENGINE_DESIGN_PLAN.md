## 目标与不变量

底层以可收纳对象的可视化容器实例为单位，海报继续作为产品名称。统一身份、对象绑定、能力协商、几何代次和提交语义，不统一矩形外框、标题栏、装饰层数量或组件排列。具体字段和样例以[联合协议](../20_Architecture/CanvasContracts/CONTRACT.md)为唯一设计来源。

- 模板可复用，实例保存覆盖；文件单一归属、统计、手动编排及热度建议仍由现有业务拥有。多个外观区域不是多个海报，也不是共享文件引用。
- AI 是内置独立创作面板，只参与设计决策，不负责逐帧绘制、拖动或日常热度。手动与 AI 共用用例；内置 Skill 不是授权边界。
- 声明能力内换装不重新构建／重启；新增原生能力仍需软件更新。不执行生成的 XAML/C#/JS，不自动加载第三方原生插件。
- 外观、内容布局和命中分责，同一提交发布一致的几何代次。必要操作保持可达；没有标题栏时由宿主提供操作入口，不能只靠控制中心找回。
- 透明度不决定输入归属。J0 可表达非矩形；矩形之外的空洞／分离区原生输入待专门裁决与验收，不在本批改变 DEC-043。
- 增量失效、按需调度和资源预算随切片进入；不恢复全量 Item 重建、每组件常驻 timer 或长期全局缓存。文件保护、新鲜检查、CAS、取消和失败保留继续有效。

## J1重审后的实施顺序

1. **当前设计门**：修订声明／资源／子场景语义，交付工作台、基础收纳及雨夜书桌视觉稿；区分可交互演示、静态示意和未实现能力。此门已于2026-10-28通过；进入原生实现和集中人工验收。
2. **自由创作贯通切片**：空白起步，添加／复制／删除／重排／重挂父级，移动、尺寸、基础装饰旋转、分组；树、画布与属性联动。图像导入和资源包保存同时落地，不再先做样例专用开关。
3. **复用与实例**：选中子树另存为组合；以固定快照／摘要插入多个独立实例。首批复用装饰子树，不携带真实文件绑定，不加独立组合创作页。源版本编辑与实例升级 UI 延后；本轮按 2026-10-28 已认可交互稿实施，见[实施清单](../40_Implementation/V3-07/CANVAS_J1_STUDIO_IMPLEMENTATION.md)。
4. **闭环与替代清理**：草稿撤销／重做与已应用设计撤销分开；接预览、应用、重开和资源生命周期。两份样例改为普通数据资源，移除被替代的CanvasSamples生产注册、编辑器模板ID／节点名分支、文字加槽专用限制；保留仍有效的安全和恢复逻辑。清理与行为修改分清，不再次大规模搬文件。
5. **定向验证后集中人工**：自动检验数据／依赖／生命周期及直接风险，人工只做下述两组。性能在同机同数据下配对，不以测试数量或节点数量预算替代成本结果。

## J1新的退出标准

- **表达**：内核不识别两样例名称；同类节点可多实例；自由排布与锚定／流式布局有明确边界。一个可用内容承载节点由语义绑定确定，不靠节点必须命名members。
- **素材**：用户显式选取PNG／JPEG后复制到设计资源库，经类型／大小／解码配额校验；重开不依赖原路径。取消不删除源文件；模板包无绝对路径／执行代码；依赖缺失拒绝发布，保留旧版。
- **复用**：组合可保存为子场景，在两作品中实例化；变换和开放参数覆盖独立、源版本固定，循环依赖拒绝，展开后预算照常计算；复制场景不复制收纳成员。
- **创作**：不修改C#、不重新编译，使用同一工作台完成基础收纳、雨夜书桌，并再制作一种结构明显不同的作品。导入图片或新增场景不能要求新增代码分支。
- **闭环**：草稿预览不改真实文件／统计；关闭回到已应用设计；保存草稿／模板不等于应用；应用保留新鲜检查／CAS，撤销仅改设计，重开保留素材和实例覆盖。实际发布失败按既有恢复路径处理。
- **操作与成本**：内容可读、菜单／拖动等必要操作可达；画面和命中同代。不重建无关Item，不加每节点timer；测资源解码、连续编辑、预览提交、纯平移、退出回收，历史成本与未定因不销项。

集中人工只分两组：①从空白创作、导入素材并在不同作品复用子场景，核对视觉效果；②预览／取消／应用／重开／撤销及一轮相邻原生操作。同步对齐候选已完成自动与原生检查，等待这两组一次验收，不再让用户逐步骤确认。

## 成本与边界门

J0 的数量预算是可调整的设计起点，见联合协议；不是现有产品上限或性能认证。J1/J2 先测再收紧：同机同数据的现有版与新切片配对，记录静态空闲CPU／内存、创建和换装时间、拖动更新次数、Item复用、进程退出及资源回收。不强行给未测帧率 PASS，不以一次快速测量销掉尾部等待。

J0未迁移数据库、接外部API、引入生产依赖或移动源码。J1沿用现有安全规则，确需持久化格式变更时先验证隔离迁移；文件移动和行为修改分开，不合并T1，不提交／推送／合并或发布。剩余读取／观察成本、P1/R6锁冲突、历史卸载／升级首因及环境余验继续按 [CURRENT_STATUS](../../00_Catalog/CURRENT_STATUS.md)独立跟踪。
