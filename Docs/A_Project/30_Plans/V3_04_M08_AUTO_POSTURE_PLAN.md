## 3. 最小行为合同（M08-01纯模型已验证，用户规则已冻结）

具体输入、状态、取消回执、热区边界与测试矩阵见[M08-01实现合同](../40_Implementation/V3-04/M08_AUTO_POSTURE_MODEL.md)。TBD-017于2026-09-11由用户明确确认，合同冻结；后续原生门仍须实际验证。

### 3.1 设置与权威

- 默认关闭；离开延迟为整数 1～300 秒、默认 3 秒。它是“离开到收起”的时间，不是展开动画时长或悬停展开延迟。
- 每张海报独立设置；新增默认关闭，复制复制策略但不复制计时器/待执行动作。
- 设置通过目标化命令、实体读集 CAS、同一 committed revision 发布；UI 不直接写库。
- 自动收展亦走既有 SetCollapsed/System 通道，成功姿态及必要邻居变更按现有事务落库；不引入另一份“自动姿态”权威。
- 倒计时、指针归属、保护状态、请求代次只存在内存，不保存绝对截止时间，重启不补执行。
- 关闭自动开关：取消待执行自动行为，保留当前姿态；不得额外反向播放。若事务已经开始，沿用现有取消/提交规则，不能强行半途改 HWND。

### 3.2 指针与手动操作

- 使用“逻辑可见范围＋实际桌面输入归属”观察指针；热区观察不改变空白点击穿透。透明容量外沿和另一个普通窗口覆盖的区域不算海报悬停。
- 收起态的展开热区与“...”/收展按钮区区分，避免正要点击菜单时标题移动；具体区域由 M08-01/03 对照现有命中合同冻结。
- 展开态离开保护热区才开始完整延迟；期限内重入取消。收起态有效进入展开热区后，在可执行时申请一次展开。
- 用户手动操作优先。A层V2-TBD-017已确认：手动收起且鼠标仍停留则保持收起，必须真正离开再进入才自动展开。布局/窗口移动不能冒充真实离开。
- 程序推让/展开导致边界移过静止鼠标，不等价于新一轮用户进入；用代次/抑制状态消除自身布局引起的收展振荡。
- 锁定仍指禁止用户拖缩及作为邻居被推动，不自行改成“禁止自身自动收展”；其自身已启用策略照常受空间可行性约束。

### 3.3 交互、并发与无空间

- 本海报编辑态暂停；结束编辑后按当前指针重新判定，在外则重新计完整延迟。
- 活动菜单、删除确认、capture、拖缩、指针按键按下/拖放会话期间不发起自动空间事务；共享菜单期间保守阻挡全局自动收展，避免菜单落点被邻居推动。
- 当前源码的 M08-07 [R1阶段保护修订](../40_Implementation/V3-04/M08_ANIMATION_INPUT_R1.md)：原始按键/临时PointerCapture只阻挡新自动请求，不单独取消InFlight；真正空间Gesture、语义操作、Unknown、策略/生命周期失效仍取消。普通点击不等于按功能按钮；新TI接入后标题空白有效点击改为快展，外部点击仍保持R1语义。
- R2-A无关桌面/前台点击不能重置或阻止收起计时，真实海报交互含auto关闭邻居仍保护，见[R2证据](../40_Implementation/V3-04/M08_INPUT_ARBITRATION_R2.md)。标题交互改按V2-DEC-003及[TI合同](../40_Implementation/V3-04/M08_TITLE_INTERACTION_CONTRACT.md)：按下暂停整组，未拖释放快展，未完全展开/正在收起时采用收起态拖动，展开完成则展开态拖动。旧继续增长默认、18行CD矩阵与TBD-019接线前置撤销；[921项旧证据](../40_Implementation/V3-04/M08_COMBINED_VALIDATION_R3.md)只保留为历史，不算TI通过。
- 仅打开控制中心不强制任何海报改变姿态；具体编辑/确认过程获得相应保护。M08-05旧UI用dirty/pending草稿临时共享Editing保护；新UX入口应在预览/提交期间接同一保护，编辑结束/失败/取消/切换/关闭按会话所有权释放后重新判定，不保存保护状态，不因浏览/定位长期保护。关闭中心不制造自动请求，详细时序由04-04-UX-01验证。
- 自动状态机每海报独立，但空间运行器仍全局单航班。busy 时仅等待重新评估资格，不建立手动“最后意图”队列，不积攒历史收展命令。
- 再次可用时重新读指针、开关、姿态、交互、会话代次和实体版本。多个合格自动候选以首次合格时间、PosterId 稳定排序，每次只提交一个，完成后重判其他候选；条件失效立即撤销。
- 复用当前先下后上、完整高度/临时高度、最小高度拒绝、锁定障碍、链式推动及完整安全归位，不重写求解器。
- 无空间保持收起、不推邻居、不写部分状态、自动行为不抖按钮。每个有效触发代次最多尝试一次；空间条件不变时轮询不重复求解/提交。真实重入或独立障碍/拓扑变化可重新评估，自身失败日志或动画帧不是重试触发。
- 归位保持用户已决定的规则：不能完整安全归位就原地不动，不改成部分回收。

### 3.4 暂停、隐藏与生命周期

- 隐藏/删除/退出、Shell 或显示恢复未完成、系统会话暂停时取消待执行计时，并使旧回调失效。
- Ready/恢复后先读取 committed 状态与当前指针；不补播暂停期间动作。在外重新计完整延迟；恢复本身不视为鼠标主动进入，不强制展开收起态。
- `DynamicEffectsPaused` 是动效设置，不能偷偷解释为禁用自动功能；系统/宿主暂停才是执行保护。完整收展减少动效映射仍属按需优化，不能由本阶段冒名完成。
- 生命周期取消使用 PosterId＋session epoch＋策略/请求代次；删除后同 ID 的迟到回调、旧截止时间、旧 HWND 均不得生效。
- 零海报或全部关闭自动功能时，不保留专用指针轮询/计时任务；退出必须全部释放并可由资源台账验证。

## 5. 连续操作验证矩阵

| 场景 | 必验序列 / 预期 |
| --- | --- |
| 默认与延迟边界 | 默认OFF移动鼠标无动作；1/3/300秒虚拟时钟，期限前不收、到期只一次；时间回拨不影响单调计时 |
| 重入与抖动 | 离开→到期前重入→再离开，从新起点计时；边界噪声不连发，不持续写revision |
| 手动优先 | 手动收起或CompactDrag结束后鼠标不动不反弹，真实离开再进入；标题点击/两类拖动按TI合同固定分类，非标题普通点击保持原语义 |
| 编辑/菜单/确认 | 倒计时期间进入编辑或打开菜单/确认，不能被收起或推动；保护解除后重新判定和计时，不立即执行过期任务 |
| 外部窗口与桌面输入 | 普通窗口遮住海报时操作该窗口不能触发下面的自动展开；透明空白仍能桌面选择；鼠标按住拖选/拖放经过海报不插入推让 |
| 多源竞争 | A到期时B收展/拖缩，A不抢占；等待中A重入则取消；A/C同时合格执行顺序稳定，B的用户调整保留 |
| 空间与链式 | 顶/中/底、贴边、邻居贴底、锁定障碍、临时高度与无空间；自动路径与手动路径同求解；连续展开/收起不重叠、不漂移 |
| 自身布局反馈 | 一张展开推动另一张穿过静止鼠标，或收起使鼠标落到邻居上；不产生无穷连锁自动振荡 |
