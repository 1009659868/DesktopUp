## 1. 总目标与当前边界

在已验多海报／真实内容基础上增量开发可解释热度、模板风格和受控AI能力。优先可读性、安全性和实测性能；不为满足架构图继续增加无业务价值的层。

普通点击穿透、共享内容引用、额外拖放确认与恢复任务UI均已取消。新配置零海报；真实文件的单一归属、预写意图、结果观察、失败保留、新鲜身份检查和CAS不变。

## 3. 推进顺序

文档对齐及[海报拖动呈现优化](../40_Implementation/V3-04/POSTER_DRAG_PRESENTATION.md)集中验收已完成；当前功能分支待授权集成。后续：热度规则裁决 → 经授权从最新develop派生热度功能分支 → 真实统计 → 纯评分与连续提案 → 会话／呈现接线 → 集中验收。获授权后才集成和发布。

模板／AI在后续分批接入；安装维护与环境余验是并行责任，不要求先做完AI才能发布。成本问题按证据触发，既不无限前置架构重做，也不隐去现有未定因。

## 4. 实施约束

- 业务规则落Domain／Application；副作用经窄端口与Infrastructure／Windows适配；组合根显式装配，窗口只接交互与呈现。
- 沿唯一状态与已验会话／呈现链扩展，删被替代旧路径，不建双轨事实库／评分器。
- 目录移动与行为修改分开；局部可读性改善随真实调用链，不按文件数或接口数评价成果。
- 仅验证改动与直接风险；文件／迁移用隔离数据，测试后按精确归属清理；原始失败证据保留。
- 用户验收、自动验证、发布测试与未验环境分别登记。Git／发布授权不能从历史任务继承。
- 细则见[实施与验证](../../Rules/IMPLEMENTATION_AND_VALIDATION.md)和[Git策略](../../Rules/GIT_STRATEGY.md)。

## 9. V3-05：真实内容基础（已验范围收口）

逐项状态／支持边界统一见[工作流§6](V3_GENERAL_CONTENT_MULTI_POSTER_WORKFLOW_V1.md#6-v3-05真实通用内容与安全文件闭环)，不再把目录映射、Win菜单、行内命名、外部同步、跨海报拖放等列为待实现。

05-04-V3「构造卡片」延期。首版本机能力不包括全部Shell虚拟对象、网络／云和可移动盘搬运认证。普通拖放没有应用额外确认；真实删除、冲突和取消沿Windows语义与底层安全保护。删普通海报／卸载归还与映射目录保留语义不变。

## 10. V3-06：真实热度与动态排版（下一主线）

连续视口、布局、手工尺寸／图钉、会话保护、成功打开事实已有。缺的是事实的正式增量聚合、纯评分与连续尺寸策略以及受控生产接线。

| 顺序 | 工作与依赖 | 退出标准 |
| --- | --- | --- |
| 开工前规则 | 30天保护／衰减最终式，跨海报统计身份和作用域，模板默认模式，尺寸合成／上下限 | 新旧、高低频、同分、时钟、跨海报样例可解释；不把有矛盾的旧公式当定稿 |
| 06-05：真实统计 | 复用打开成功事实，以ActivationId去重；稳定消费位置／标记与聚合原子提交 | 成功一次仅记一次；扫描／定位不计；失败重放不重复，绝不重放打开；新增成本可测 |
| 06-06／07：纯策略 | 注入有版本的评分／连续尺寸规则，原始事实与模型版本分离 | 连续性、单调性、30天边界及极值定向验证；替换旧五档／整数适配，兼容旧数据 |
| 06-08～10：现有会话接线 | 自动模式资格／图钉／手动尺寸优先；安全触发、延期、过时提案丢弃 | 首屏／展开等已定时机应用，交互中不跳动；全手动不受干扰；无全图标重载，不自动扩外框 |
| 集中验收 | 统计与冷热变化；自动／手动／图钉与交互稳定两组 | 不要求人工等待30天，不追加历史安装／拖放全矩阵；自动边界与人工结果分别记录 |

50%～300%、无数据150%是旧热度相对尺寸基线，**待与已验宏观尺度0.4～3合成裁决**，不是立刻写死的实现值。临时拖前后5分钟内打开奖励是否首发仍待定；不恢复旧刷新菜单。

详细方案与源代码入口见[工作流§7.1～7.2](V3_GENERAL_CONTENT_MULTI_POSTER_WORKFLOW_V1.md#71-2026-10-21-真实热度准备未实施)。首批是可注入／带版本的纯策略，不等于任意DLL或脚本热加载；不为每海报增加高频计时器或每次打开整库重算。

## 11. V3-07：模板、风格热替换

后续按稳定声明schema／组件参数 → 包导入与安全校验 → 候选预览／原子切换／失败保留 → 兼容迁移逐步推进。既有内置Lamp／Rain及基础收纳不等于任意风格平台。非矩形、离散区域作为后续目标，需先明确几何／受保护操作区／同代命中，不能恢复日常点击穿透作为默认前提。

退出要求：不重建／重启即可应用声明式风格，单实例作用域、不串改其他海报；坏包／缺依赖保留最近可用版本。不默认执行任意用户代码；若确需代码另设受限宿主安全门。细项见[工作流§8](V3_GENERAL_CONTENT_MULTI_POSTER_WORKFLOW_V1.md#8-v3-07独立主题与热更新)。

## 12. V3-08：AI接入

基于稳定参数／命令合同，provider-neutral适配、密钥隔离、发送前隐私范围、带目标和版本的变更计划／diff／确认／撤销。AI不得绕过普通用例、文件安全或模板权限；离线／无Key不影响主程序。细项见[工作流§9](V3_GENERAL_CONTENT_MULTI_POSTER_WORKFLOW_V1.md#9-v3-08ai-辅助定制)。

## 13. V3-09：交付与安装维护

### 14.1 基础功能完成后的联合长时验证（原R7-C2）

原R7-C2承接到10-01/02/06，**NOT RUN**。安排独立负载与长时验证时，记录硬件、DPI、构建和1/3/6张及真实内容规模，测UI等待、CPU／内存／资源释放、图标缓存、文件突发与恢复。容量是测试样本而非支持承诺。无需等待完整AI／AOT，也不在每次局部修改重跑。

其他主机／普通权限／混合DPI、真实满盘及长期稳定仍按已有记录分别验证；AOT兼容审计和A/B属后续优化，不删功能换性能数字。
