# 基础拖放与失败自动收尾

2026-10-10，依据DEC-041。目标是拖入收纳、拖回桌面取出，普通失败后直接重新拖动；底层安全记录不再作为用户任务。

## 1. 实施顺序与边界

1. 自动结束未移动项；自动核实已移动结果并修复原意图关联；结果不确定保留文件、结束调度并提示位置。
2. 移除日常收纳恢复任务菜单。持久存储只需选址；旧归属迁移保留底层能力，不成为所有用户的步骤。
3. 原生CF_HDROP接入既有标题／内容输入窗口，本应用唯一执行Move；不让Shell重复清源。
4. 沿Item既有鼠标捕获拖到真实桌面，松手才执行；旧引用确认源路径。内部拖动、返回、Esc、失效、关闭、重复回调只允许一次提交。
5. 隔离自动门、普通权限人工候选；人工通过前保留备用添加入口。

首批开放同卷本机文件、文件夹、快捷方式本体；跨卷、Copy／Link、虚拟对象、任意Explorer目标明确拒绝。内部跨卷执行器仍保留，真实满盘继续按用户决定延期，不创建VHD。未确定结果不删副本；数据库与文件系统不冒充批量原子事务。

## 2. 旧方案处理

账本实施§7～10的工程证据及schema16～18保留；四项新增恢复UI人工任务退役，不登记通过。旧包、配置、故障现场和诊断API不删除。用户无需停止旧任务才能重新拖动；后台也不自动重新执行旧Move。

## 3. 验收目标

- 拖入文件／文件夹／快捷方式后原位置移除，海报可打开；快捷方式目标程序不移动。
- 海报内排布不动文件；拖出后回真实桌面、当前卡片移除，共享引用位置一致。
- 旧引用拖出确认真实源路径，取消保持原样；Esc及非桌面落点不移动。
- 同名、占用或普通失败短提示后可重新拖动；未完成文件动作不显示成功。
- 退出／重启保留文件和关系；启动只收尾已有结果，不重放Move。
