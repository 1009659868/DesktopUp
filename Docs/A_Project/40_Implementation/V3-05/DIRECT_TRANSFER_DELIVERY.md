### 10.1 DeskBox如何处理 → 本项目差异

- **实际落点**：Windows把指针位置交给实际目标；桌面/文件夹决定放置方式。桌面自动排列/对齐网格仍由用户系统设置决定，不偷偷改变，不注入Explorer或用图标坐标作文件真相。不再用“源图像跟手”代替原生Drop认证，参见[DoDragDrop](https://learn.microsoft.com/en-us/windows/win32/api/ole2/nf-ole2-dodragdrop)。
- **完成与共享**：逐项核实真实操作、来源身份和目标定位；不能仅凭effect、源路径消失或鼠标所指窗口猜目标路径。同名重命名、跨卷、异步/部分完成要能关联到正确对象。成功Move只撤当前卡片，其他共享卡片更新到已证实的新定位；不确定时保留文件/关系并短提示，不报成功或全盘猜找。最小外部同步在相关交接期间退让，终态再观察，防止先删掉全部共享卡片。外部观察与拖出继续复用ContentRelationRemoval，不合并二者不同的移除范围。
