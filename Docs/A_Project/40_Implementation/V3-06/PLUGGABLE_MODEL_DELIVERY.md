## 实现边界与清理

- Domain `ContentBehaviorModel` 定义版本／能力、冻结输入和四类可选建议；模型不拿存储、窗口、文件操作权限。输入含作者意图、统计、当前已呈现快照及其版本、视口和统一时间。
- Application `ContentModelRegistry` 可信注册／版本选择、共享有界计算槽、UI 外计算及总计 2 秒超时。`ContentActivityProducer` 去掉固定静态评分调用，继续消费原事实库；不增加统计或轮询时钟。
- `ActivityContentModel` 保持已验综合公式；独立 `RecentStripContentModel` 按最近使用排序、连续尺度、条带位置及淡入输出，验证替换不改 producer／窗口。注册时重复 ID／版本拒绝；不兼容、异常和迟到不替换已接纳提案。
- 宿主复用 `ContentHeatSizing`／原布局器，位置只是 `[JsonIgnore] ModelPosition`，不伪造作者 FixedPosition。手动／固定位置优先；有顺位图钉时保守忽略整组位置建议。位置冲突／空间不适合退回既有排版，排序及合法尺寸建议保留。必要扩框／限幅仍走原空间规划。
- `ContentHeatSession` 增加同步发布完成／回退；原生输入接纳失败不把新提案当下一次基线。作者／成员／实体／环境与视口见证淘汰迟到结果，交互期继续延期。
- 控制中心“行为 → 使用热度 → 热度设置”自动列出注册模型、保存当前海报选择及过渡开关。旧配置缺省仍为综合热度；使用统计不清空，无 SQL 迁移，001～027 不改。
- `PosterVisualWindow.ModelTransition` 只在同代目标画面成功后做 160 ms 淡入，最长 300 ms；不是逐帧位移插值。只改变 Surface.Opacity，帧内不排版／提图／重建命中；结束、新呈现、交互、暂停和退出取消。基础收纳共用已有系统动画设置观察，不要求有动画场景，也不为此启动场景计时器；遵守系统减弱动画和托盘暂停。
- 没有目录移动。本批替代了 producer 硬编码、旧无结果刷新调用和场景设置内嵌初始化，未留下双套生产路径。旧五档提案仍有历史兼容／测试调用，未以“清理”名义破坏它。

已注册模型可不重启切换；新增可信 C# 模型仍需编译注册。任意 DLL／脚本加载、任意参数编辑器、逐帧移动插值、模板平台不在本批。可读性优先，未引入 DI 框架、第二套布局器或权威缓存。
