## 设计结果

- 将海报底层明确为容器实例，复用PosterId与现有内容集合；模板是可复用描述，不拥有文件。最小语义不要求矩形、标题栏或固定装饰槽。
- 控制中心按能力和配方生成折叠参数，进阶层负责组件／布局编辑，配方管理另存版本；实例覆盖不反向改全部实例。
- 画板声明、能力目录、设计草稿分责；AI只提议，目录／权限／资源／版本／实际命中准入归宿主。预览与应用绑定草稿和设计版本，应用由用户动作触发。
- 基础收纳为无介绍标题的单区域；雨夜书桌为桌面与分离灯盘、雨效和可选文字。两者只绑定同一个members语义槽，不嵌入真实Item或路径。
- 第二份草稿调弱灯光／雨效并隐藏文字，保持目标、内容绑定和配方字节摘要，仅递增草稿版本并改变实例覆盖。
- 仅原位替代旧的固定标题栏／固定插槽、通用AI和未知字段静默丢弃要求，历史验收记录不改写。
