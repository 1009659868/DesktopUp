## 历史：review06确定的方向

用户明确要求这批就能在工作台**编写、保存、运行受限脚本**，不只注册内置C#行为。行为与UI分离：代码形成可复用行为预制体，图层绑定多个行为，配置事件、状态条件、执行顺序。默认“收纳／展开”亦为预制体，标题`v`作为UI绑定；画板提供编辑／运行模式，运行时直接点击`v`，而不是只能另开桌面预览。

- 脚本采用版本化的画板领域语言，不解释C#／JavaScript或加载DLL。支持有界动作调用、等待、收展状态条件；不支持循环、递归、动态代码、文件、网络、进程或反射。解析失败保留原稿并给行号。
- 预制体为名称＋脚本＋语言版本，可独立保存到设计库；作品内携带快照，不因改库意外改所有实例。默认预制体可复制、查看代码。
- 图层的行为绑定列表独立于视觉属性：事件源、预制体、目标别名self、启用、收起／展开条件和顺序。一次事件按列表顺序执行；等待／动画由宿主时钟推进，重复事件取消同来源尚未完成的旧执行，不建立无界队列。
- 运行模式使用与实际海报相同的编译器及执行器，只把宿主收展适配为画板内状态，不修改实际文件、配置和草稿。退出／切换作品／编辑即销毁临时状态。实际海报收展仍经原用例与空间／交互保护；失败停止后续动作并反馈，不能自行写状态绕过CAS。
- 静态文字／图片／形状与组合可绑定；真实内容操作及菜单命令权限归宿主。历史提出“更多菜单强制保留收展”的方案已被用户否决；按顶部新方案，v／…的UI与行为归作品，移除不补回，不能再执行旧强制保留规则。
