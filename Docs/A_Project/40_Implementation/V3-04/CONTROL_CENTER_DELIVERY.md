### 几何提案与提交

1. 01编辑器保留basis，应用时冻结全目录/实体读集；宿主必须能读回当前工作区、运行代次和全部可见邻居。
2. 复用PosterSpatialSolver的精确路径校验，有限尝试“先移动再缩放”“先缩放再移动”；不另写碰撞/推动模型。均失败时明确拒绝，不悄悄夹到另一个位置，也不推动无关海报。
3. 输入DIP向外取整为物理像素。仅移动时保持实际宽高，受限高度不覆盖保存展开高度；尺寸编辑则形成新的保存意图。
4. ControlCenterGeometryProof在事务内重验初始场景、实体/目录CAS、布局代次、操作种类和结果字段；不能混入其他空间证明或偷改内容参数。
5. 复用PostureRun、SpatialAnimationSchedule、R4容量预布局、两次就绪回调、组提交、逐帧环境/读集校验，以及RestorePresentedGroup结束恢复。状态提交仍由原Coordinator执行一次revision；冲突恢复后展示失败，不假装成功。

旧无空间证明的Move/Resize及Create/Clone兼容口仍用于既有夹具/旧合同；新中心入口不走裸几何写库或“先创建后挪开”路径。真实呈现读回仅由App运行器负责；纯证明不冒充HWND见证。

### 安全新增/复制

- 对话框打开时冻结目标/全目录读集，关闭确认后再检查；变化则冲突，不把旧操作重定向。
- 在主显示器当前工作区，用原实际占位的右/下边界候选寻找完整空位，按Y/X确定顺序；不调整原海报，不缩小新配置。
- 无空位时返回InsufficientSpace，零新增、零revision。所有可见会话须已就绪。
- 复制保留源配置（包括锁定/收起/显隐/自动设置及最小主题参数），不复制会话/计时/租约或真实内容；身份由原创建策略生成。
- 本阶段不是跨主机便携配置实现，也不保证任意碎片布局都能自动整理出空位。
