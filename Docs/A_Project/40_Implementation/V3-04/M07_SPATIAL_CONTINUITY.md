- 首轮10通过/2失败：合流缺少“无新增位移但占用归位通道”的关系；另一失败为测试把新障碍直接放进展开源内，属非法起点，已改成窄源旁、宽目标回程中的合法障碍。
- 补合流后12/12；扩展六节点后18通过/1失败，发现当前收起源自身仍携带位移，不能只处理邻居。
