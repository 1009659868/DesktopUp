# M04-07 R2：展开候选、有效高度与反馈

日期：2026-09-08。R2-01～03 已接入，自动合同通过；用户已认可收展策略体验，动画延期并明确进入M05。剩余安全人工格保留，不补写M04整体PASS。

## 1. 实际策略

`SpatialExpansionPolicy` 调用同一 `SpatialPushSolver` 做完整场景候选：先尝试最大下段的完整路径；失败后求合法下侧容量，再在同一下段前缀中向上补足。**有下方容量必须先下后上，容量为零才纯上。** 本次删除“上优先完整路径”提前返回，避免跳过下方空隙。上下容量不是两个不同邻居终态的简单相加。所有候选只生成数据，选中路径进入原16ms批次，完整尺寸可行时不提前取短高度。全规则见 [策略矩阵](../../20_Architecture/POSTER_SPATIAL_STRATEGY_MATRIX_V1.md)。

完整尺寸均不可行才选择最大合法高度。至少容纳共享度量的一行内容则为 Constrained；否则 InsufficientSpace，源和邻居无布局提交。固定邻居不移动，不缩小邻居，不加入横向绕路/跨屏搬迁。候选数和工作量设有预算；BudgetExceeded、IncompatibleMetrics、旧读集或原生提交失败不冒充普通空间不足。

R2历史night-ops默认度量：标题操作栏46＋标题说明130＋顶部间距10＋完整Item行118＋页脚42＝346 DIP；四DPI像素分别346/434/519/692。M05已改为逐Poster解析Presentation.Metrics，basic-box默认210 DIP；输入、renderer、源展开、事务重算及恢复使用同一目标度量。`PosterContentMetrics.Current`仅保留旧等价默认/兼容身份，不再给所有实例强套346；公式与参数见[M05合同](M05_PRESENTATION_PARAMETERS.md)。

恰好达到阈值可展开，少1物理像素不展开；中间动画帧仍裁剪，不要求每帧满足完整一行。已保存高度低于当前内容最小值时报告 IncompatibleMetrics，不偷偷提高用户尺寸。已有展开的旧短海报可作为恢复障碍保留，但其下一次显式展开仍执行新度量合同。

## 2. 持久意图与有效投影

- SQLite schema 仍为v5，无新增持久字段。ExpandedHeightDip与归一化完整高度继续保存用户意图；本轮没有将450 DIP等临时高度写进尺寸偏好。
- 既有spatial_operations因果证据仍会记录实际端点Bounds（因此可含受限高度），用于有session/generation校验的条件归位；它不是尺寸配置或有效高度缓存。新进程不从旧证明恢复临时高度，也不能把它当作便携配置中的用户意图。
- `EffectivePosterLayouts` 是会话内可重建投影，保存 Bounds、意图签名、revision/layout generation、工作区/DPI及度量版本；没有持久化或独立命令写入口。
- `PosterVisualWindow.TryReadSpatial` 始终把保存高度作为 ExpandedHeight；物理Bounds可小于该高度。移动保留意图，显式resize才改变意图。锁定/改名不会把当前临时高度弹回完整尺寸。
- 收展事务内 `SpatialPostureCommitPolicy` 用同一内容度量和候选策略重新求解，验证完整实体读集CAS及物理快照中的首选高度。成功后才发布本组有效结果；原批次准备、原生读回、失败恢复和R1同步归位继续复用。
- 中心查询同一有效投影并显示“空间受限，当前临时高度”；托盘从同一读口生成受限海报数量摘要，不独立计算另一份高度。
- 重启不读取会话临时高度，也不重放旧动画/推让证明。按持久意图准备全场景：正常合法布局保持；冲突布局以compact锚点规划，先保留不侵入其他锚点的完整邻居，再求冲突目标。已提交的位置可作恢复种子，不能将字典缺失键解释为零矩形。新场景仍不可行则恢复失败/降级，不显示重叠布局。
- 相同工作区/DPI的普通刷新与Explorer重挂保留会话有效结果；新显示环境重新求解。空间变大不会持续自动撑开，下一次显式展开重新优先完整高度。

## 3. 反馈与输入边界

空间不足返回独立 `StateCommandStatus.InsufficientSpace`。仅展开glyph应用最大2 DIP的短促水平偏移及强调色，总时长280ms；不移动HWND或输入岛、不改命中区域、不抬层、不抢焦点、无模态框。同一时段的连续点击合并，结束或销毁时归零并停止timer。Windows关闭动画或应用暂停动态效果时，采用零位移静态强调。System自动来源不触发反复抖动。

既有ScrollViewer继续使用实际窗口高度，内容大小不随临时高度缩小；未改宿主owner/bottom与原生鼠标捕获逻辑。
