## 范围与实现顺序

1. 整体尺度由 0.8～1.5 扩展为 0.4～3.0；保留默认 1、已有配置以及独立间距。
2. 单项尺寸允许小数并持久保存；位置仍对齐现有网格。网格占位向外取整以防重叠，实际绘制、命中和最小空间使用完整小数尺寸。不是动画，也不实现热度采集/排序。
3. 移除 240 DIP 固定外框下限对交叉轴的限制；纵向最小宽度、横向最小高度跟随最大有效 Item，加必要内边距和标题操作空间。空海报保持可操作下限；不自动缩小已有海报，不修改文件与布局身份。
4. 悬停只更新局部背景，不改变选择、不触发持久化/资源加载或整张海报重建；离开、拖动、收起和失效时清除。
