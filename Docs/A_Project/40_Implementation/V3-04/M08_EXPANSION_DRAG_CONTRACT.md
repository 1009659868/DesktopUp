# M08-07 R2-B：展开与标题拖动组合合同

日期：2026-09-11。用户已确认目标；实施/验证状态见文末。不采用先前拟议的200ms悬停延迟，也不采用“取消展开→恢复收起→重新拖动”。产品决定归A层V2-DEC-002。本合同不关闭M08-06/07余门。

## 1. 意图与范围

- 自动展开已开始，同一海报标题上的真实拖动接管位置，展开从已呈现进度继续；普通按下、释放未越过5px阈值时保持R1行为。
- 本轮仅组合**同一源海报的展开＋标题移动**。不是并发拖缩、跨海报抢占、手动连点队列，也不让收起途中任意点击反向播放。
- 单一组合会话同时拥有展开进度、指针捕获、源和邻居的几何提案。两个独立运行器不能分别写同一窗口。
- 已呈现几何是后续运动起点；committed状态仍是唯一持久权威。不得为了让Begin成功，删除起点/实体/环境校验或把中间高度持久化为偏好高度。

## 2. 状态与结束合同

| 状态/事件 | 结果 |
| --- | --- |
| Expanding：普通按下/抬起 | 不改变展开方向、不回滚；尚未产生拖动意图 |
| Expanding：同源标题越过阈值 | ExpandingAndDragging；保留当前高度和已呈现邻居位置，建立当前位置的抓取基准 |
| ExpandingAndDragging：先松手 | Expanding；保留已接受位置，剩余展开继续，不提前提交位置 |
| ExpandingAndDragging：先展开完成 | Dragging；展开目标完成但捕获继续，鼠标移动继续有效，不提前释放输入 |
| Dragging：松手，或Expanding：剩余展开完成 | AwaitingCommit；冻结一个最终候选和完整读集，禁止继续修改 |
| AwaitingCommit：CAS及物理恢复成功 | Completed；仅此时释放整个空间会话并回执成功 |
| 任意活动状态：真实失效 | Cancelled；统一取消/恢复，不生成另一方向命令；旧事件、旧回执不能重新激活 |

松手与最后动画帧同一轮到达时，无论顺序均只进入一次AwaitingCommit。动画已结束但仍按住鼠标，不等于应取消或重启动画。

## 3. 几何、抓取点与空间关系

1. 无约束时，标题抓取点跟随指针，不被剩余向上展开运动额外带走。工作区、碰撞、锁定和最小内容高度不能违反。**边界冲突待定V2-TBD-018**：若固定抓取点就无法继续增长，选择“优先跟手、暂缓剩余增长”还是“优先增长、夹持拖动位置”。不默认选择，也不把暂缓实现成回滚收起。
2. 移动使用原扫掠碰撞/滑动策略，只改变源的位置；**拖动本身不授权推移邻居**。展开增长才可按既有策略推动邻居。
3. 位置改变后，旧展开终点不能直接叠加位移。必须从当前实际呈现的整组几何重新求解剩余增长，先下后上、保偏好高度、受限有效高度及最小高度规则不变。
4. 可见高度不得因为接管而回到收起态；增长进度不回退。候选落点若无法提供剩余合法过程，不接受该候选，保留最后安全几何和捕获；不能在不足最小内容高度处提交“展开完成”。
5. 邻居Home/因果关系必须保留原始来源。手动调整源位置只重建源的用户锚点；不能把所有邻居的当前临时位置当成新Home，也不能因源移动把不相关海报拉走。
6. 展开所产生的推让仍进入同一条件归位体系；用户调整、锁定、目录/环境变化的失效规则不变。归位不能完整安全完成时原地不动，不做部分归位。
7. 同步动画按实际已提交的整组帧前进；准备失败不推进模型。R4内容预布局/容量租约、统一提交和结束恢复不另开旁路，不重新引入白边。

## 4. 失效、身份与权限

- 绑定PosterId、输入session epoch、捕获token、操作ID、完整实体读集、目录版本、Shell/显示/工作区/DPI代次。
- 相同源的组合拖动是会话内手动位置意图，不能再被旧自动请求的“任意ManualIntent变化即回滚”路径误取消；并不免除策略关闭、删除、锁定、隐藏、真实捕获丢失和生命周期失效。
- 其他海报的操作仍按共享空间忙碌/保护处理，不建立第二个竞争运行器。
- 限制语义事件/路径预算；重复或迟到事件不计第二次，不持续保存全局指针轨迹。
- 不能把System自动姿态口放宽为任意Move/字段写入。组合提交需要独立、可重放验证的语义证明；不能把源位置与姿态分两次数据库提交。
