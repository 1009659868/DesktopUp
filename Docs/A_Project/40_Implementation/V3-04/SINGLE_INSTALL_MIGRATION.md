### A 决定与 B 边界

- 同一 Windows 用户仅保留一份受管理 DesktopUp 安装和一条卸载登记，不等于禁止改变安装位置。首次安装可选目录；存在旧安装时选择原位置为覆盖升级，选择新位置为迁移升级；同版本允许换位置，禁止降级。成功后所有入口统一指向最终位置。
- 卸载登记使用固定产品身份，兼容读取历史 `DesktopUp.Preview.<版本>`。发现多份、无效登记或未完成事务时保守停止并报告，不任意选择最高版本或删除其他用户的数据。旧安装器/人工复制不受新版互斥约束，不承诺清除全盘副本。
- 配置、数据库、收纳、归还账本不进入程序替换清单；位于旧目录的未知文件仍保留，程序迁移不隐式搬移收纳位置。只清理摘要及归属已确认的程序文件/快捷方式。
- 原位和换路径使用同一日志事务；新文件准备、旧文件可恢复备份、入口/登记/自启切换、旧程序清理有明确阶段。跨卷不得依赖跨卷原子重命名；备份与目标各自本卷准备，提交前保持恢复能力。
- 自启动只在值仍指向旧安装且未被外部修改时更新目标；未开启保持未开启，Windows StartupApproved 不写入。卸载、自启动的固定身份校验同步修改。
- 安装 UI、命令行、辅助程序均不得绕过唯一安装判断；同一用户的安装/迁移/卸载串行化，提交前新鲜核对。保留已有维护租约、路径保护、文件摘要、占用保护及诊断，不强杀、不自动重试、不调用旧卸载归还流程。

### C 实施顺序与退出标准

1. 固定身份/发现：读取固定及全部历史登记，校验唯一性；清理只选最高版本和按目标目录决定是否升级的旧入口。新装、重复、同版迁移、降级、冲突各有确定结果。
2. 事务：分离旧根/新根，保留原位路径；跨卷备份/回滚、持久恢复和登记切换纳入同一用例。提交后无第二份可用安装、旧自有入口已清理；失败不吞掉原始证据、不删除未知文件。
3. 接线：NSIS 允许更改路径但不能新增并行安装；固定登记与卸载、自启动解析一致。正常用户数据零迁移；无新增后台服务或计时器。
4. 定向验证/打包：只覆盖唯一登记、旧版兼容、原位/换路径、同版迁移、取消/故障恢复、数据及自启保全。日常安装不作为自动测试靶；测试身份/文件独立，报告与失败证据保留，临时文件/入口收尾。
5. 集中人工仅两组：①原位升级、重复安装与数据/入口；②换路径升级、旧程序清理与配置/内容/自启保持。自动故障覆盖不转化为更多人工矩阵，人工通过前不记 CLOSED。

## 实现与集中人工入口

产品实现已完成，集中人工仍待用户确认，不记 USER PASS。固定登记为 `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\DesktopUp`，读取历史 `DesktopUp.Preview.<版本>`；同用户多个登记或无效身份保守停止，不自动挑选/删除。成功安装后只留固定登记；同版同位置不重复安装，同版允许换位置，较旧包不能降级。

新装、原位、换路径共用 Setup 事务，撤掉 NSIS 原独立新装写登记与选最高版本/另选目录并行的旧入口。每用户安装向导租约、安装事务租约及既有配置维护租约分别处理向导并发、安装/卸载并发与运行中保护。提交前核对登记、文件及自启动设置；固定键写到一半失败也按捕获的旧/新值恢复，不认领外部值。回滚对原文件位置只建立一次集合，不在每个文件上重新遍历所有旧文件。

程序本体跨卷：旧根本卷备份，新根本卷准备；登记/入口切换成功后清理精确旧文件，不调用旧卸载器，不执行内容归还。全局 pending 索引保证旧路径失效或登记部分切换时仍可找到记录；旧 schema1 原位日志继续兼容。位于旧目录的未知文件仍留原处，因此旧目录可能存在，但不再是第二份程序安装。

自启动只更新仍指向旧启动器的 Run 命令，不新增未开启的启动项、不写 StartupApproved。App 自启动身份解析同时支持固定/历史登记，并核对版本、路径；新版卸载也使用固定身份。安装附加选项页显示原位置和目标位置；可返回目录页调整。

### 两组人工，不操作日常安装

本机日常 F 盘安装保留。验收包是独立的 `DesktopUp SingleInstall Review` 测试身份，配置固定在 `out/single-install/review/profile`；它不是对外发布的安装器。测试仅替换编译时登记/入口名称、事务状态目录和夹具 profile，事务算法源码不变；正式包没有绕过唯一安装的运行期开关。Windows 应用列表中只核对 **SingleInstall Review**，不要把刻意隔离的日常安装也计入测试身份。

普通 PowerShell：

```powershell
$review = 'G:\A_\Tools\DesktopUp_V2\tests\Packaging\Review-SingleInstall.ps1'
& $review -Action Open
```

1. **原位升级**：在打开的隔离旧版中新建海报，只拖入脚本打印的 `samples/验收文档.txt`，调整一个外观参数；从托盘退出。执行 `& $review -Action Upgrade`，默认应识别测试旧位置，可在附加选项页核对原/目标路径。完成后 `Open`：海报、样例、外观保持，测试应用登记只剩一条新版；没有新增第二份测试安装。
2. **换路径迁移**：从托盘退出，再执行 `& $review -Action Move`，保留预填的 C 盘临时测试目标，向导显示 G → C 的路径变化。完成后 `Open`：海报、样例可正常使用；`Status` 显示登记指向新路径，旧位置的 DesktopUp.exe/Uninstall.exe 已移除。配置/收纳保留原位，不要求文件跟随程序目录一起迁移。

验收后退出，再执行 `& $review -Action Cleanup`，正常卸载测试身份，逐项摘要归档配置/样例后清理；`Status` 可只读查看位置。不得用真实文件做样例。隔离配置按现有保护不开放日常自启动开关；Run 目标迁移/关闭状态由本批定向及安装夹具验证，真实登录自启仍不补 PASS。
