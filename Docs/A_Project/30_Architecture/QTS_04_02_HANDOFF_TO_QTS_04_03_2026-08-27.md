## 1. QTS-04-02 关闭结论

用户已确认最新版 Release 海报实际可见。NIGHT OPS、六张卡片和 footer 完整，顶部/底部无白条或灰框，圆角外无矩形包络，普通窗口高于海报，有界运行结束后无残留。因此 QTS-04-02 的自动像素门和用户桌面视觉门均已关闭。

## 2. QTS-04-03 目标

在保持 visual HWND 全面 `WS_EX_TRANSPARENT` 的前提下，只为标题栏、卡片、按钮和编辑尺寸边建立独立 sibling input islands。透明空白不得由覆盖整张海报的交互窗口截获，必须直接落到 Explorer。

目标层级保持：

~~~text
普通窗口 / 全屏程序
  > DesktopUp input islands
  > DesktopUp visual
  > 桌面图标
  > 壁纸
~~~

input islands 与 visual 同属 DesktopHost 的 Explorer child 层级；它们不是 TopMost，也不激活应用。

## 3. 冻结输入

- `HitRegionSet` 与 frame 使用同一 projection revision；
- 旧 revision 的输入事件必须丢弃；
- 零区、一区、多区和重叠区均必须支持；
- 重叠时由显式 priority 决定最上层 island；
- 空白左拖、空白右键和原生快捷方式不得通过转发消息模拟；
- USING 模式命中标题、卡片和两个按钮；
- EDITING 模式额外命中右边、底边和右下角；
- lock 禁止标题拖动和尺寸变更，但不禁用卡片及两个按钮；
- collapsed 仅保留顶部标题/按钮命中，不保留已隐藏卡片命中；
- 收起/展开保持顶部锚点与按钮屏幕位置。
