# QTS-04-01 → QTS-04-02 交接（2026-08-27）

状态：`CONSUMED — QTS-04-02 CLOSED`
## 1. QTS-04-02 目标

在已经通过真实 attach/reconnect 的 Host 上，把最小 QPainter frame 替换为冻结需求中的 NIGHT OPS 单海报视觉。QTS-04-02 只关闭 renderer、premultiplied alpha、尺寸和像素边界，不提前实现输入岛或完整生命周期矩阵。

## 2. 已冻结的 Host 输入

- 当前生产路径为 raised-Progman layered child，位于 DefView/图标上方、普通窗口下方；
- visual 和 z-order 归 DesktopHost 所有，renderer 不得创建 HWND 或修改层级；
- attach/reconnect 后必须等待当前 SurfaceEpoch 的完整首帧才显示；
- Runtime 在 `ReattachedNeedsFrame` 后重发当前 accepted snapshot 的 frame；
- Host-capable manifest 是强制构建输入；
- TopMost、激活、ordinary top-level fallback、轮询保层级和隐藏/恢复补救均禁止。

## 3. QTS-04-02 实现范围

1. 在 `renderer-qpainter` 建立 NIGHT OPS 单海报 scene/model；
2. 绘制圆角外形、背景、标题区、六张 Item 卡片、footer、锁定和收起视觉；
3. 统一颜色、透明度、边缘、阴影/蒙层和 premultiplied alpha；
4. 让所有像素都由 frame bounds 驱动，不依赖窗口非客户区或 QML 尺寸；
5. 建立 expanded/collapsed、locked/unlocked 的纯视觉投影输入，但不在本阶段处理真实鼠标命中；
6. 增加离屏像素/边界自动夹具和有界原生展示入口；
7. 保持真实 Host attach/reconnect 和 QTS-03 全回归绿色。

## 4. 失败导向验收

自动门至少检查：

- 输出格式始终为 `QImage::Format_ARGB32_Premultiplied`；
- frame 尺寸与 Host requested bounds 完全一致；
- 四角外部像素 alpha 为 0，圆角内部无未初始化像素；
- 顶边、底边和外缘不存在额外白条、灰框、暗灰非客户区或一像素污染；
- expanded/collapsed 的左、上、宽保持合同，只有高度变化；
- 六张卡片均处于可见范围且不越界；
- 重绘结果可重复，旧 buffer 释放后不可复用；
- 真实 Host 首帧和 replacement 首帧仍通过。

人工视觉门只在形成可运行 Release 后执行；QTS-04-02 自动像素 PASS 不能替代用户对实际桌面的视觉确认。
