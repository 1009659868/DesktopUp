## 可直接使用的提示

> 在实际仓库 `G:\A_\Tools\DesktopUp_V2` 工作，先核对路径与 `git status --short --branch`。阅读 Docs/README.md、CURRENT_STATUS，再按 ACTIVE_PATH 的 A → B → C 阅读本次相关需求、计划、交接、锚点与最新验证。不要使用旧 DesktopUp 仓库的 V1／Tauri 分支或命令。
>
> 当前已验基线在 impl/develop，拖动优化已集成；基础架构 R1～R8、P1～P3已收口，发布线仍为唯一安装／换路径升级。远端 impl/06-real-activity@6bbfcfc 已实现热度和桌面标准尺度，用户2026-10-26补充确认集中验收通过；当前只完成合并准备，未合入热度。先读ACTIVITY_BRANCH_REVIEW_20261026，不从零重做或重复原两组验收。实际整合／发布须有对应授权。
>
> 保留已验行为、安全新鲜检查和 CAS；优先可读性与实测成本，不为对齐图表增加转发层。删除被替代的旧路径，文件移动与行为修改分开。只验证受影响范围，最终集中验收，不把历史未验环境补成 PASS。
>
> 普通点击穿透和共享内容引用已取消；不要恢复旧设计。新配置零海报，无测试数据。真实热度复用打开事实与会话提案链，不向窗口或存储类塞评分政策。
>
> 历史卸载首因、升级41、P1/R6锁冲突未定因和剩余成本继续保留。不得以新成功销项，也不自动重试、强删或杀用户进程。测试只用隔离样例，按精确归属清理并保留证据。
>
> 后续 tag／预发布更新说明只写本次变更，不重复完整功能介绍。任何提交、推送、合并、移动标签或更新 Release 都需对应用户授权；“更新文档”不等于授权这些操作。
