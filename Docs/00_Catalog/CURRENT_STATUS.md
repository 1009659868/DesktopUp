## 3. 已替代规则，禁止从旧稿恢复

- 普通点击穿透已取消（DEC-043）。可见海报矩形统一接收输入和 OLE 拖放；空白左键支持框选。视觉透明不等于输入透明。
- 共享内容引用已取消（DEC-047）。一个有效对象只允许一个可见海报引用；普通拖入／出一次按住完成，无应用额外确认，Windows 必要冲突提示和底层保护保留。
- “目录映射”在控制中心的**新增海报**，创建独立映射海报，不在海报空白菜单中。
- 统一原生菜单名称为 **Win菜单**。普通内容菜单提供真实删除，不恢复“仅移除引用／全选引用／刷新来源状态与图标”等已撤入口。
- 新配置**零海报、无演示卡片**。普通启动零海报时打开中心，有海报时后台启动；显式显示中心与自启入口各按其约定执行。新增默认基础收纳。
- “热度自动（可带顺位图钉）／纯手动”是两种模式；图钉不是第三种模式。
- 旧非破坏性引用添加、共享修复、恢复任务 UI、早期拖出二次移动等记录只用于历史追溯，不是下一批实施要求。
- 后续更新 tag／预发布说明**只写本次更新内容**，不重复完整功能介绍；具体规则见 [Git 与发布策略](../Rules/GIT_STRATEGY.md#发布说明与标签更新)。

## 4. 接下来按什么顺序做

1. **联合成本归因（已开始）。** 1/3/6张、每张20/100项，前后各三独立进程样本确认逐项关系解析重复冻结全目录是热点，已改同轮完整校验一次并批量索引解析。无窗口的producer／会话样本有收益，不外推UI帧率；全局读取／观察、真实UI等待与长稳继续携带，见[首批证据](../A_Project/40_Implementation/V3-07/JOINT_COST_AND_COMPONENTS.md)。
2. **V3-07模板／风格热替换（首批自动通过／人工待验）。** 在已有配方导入／实例／CAS上增加v2副标题、大标题、数量独立组件，保留v1。114项定向、30项架构和实际窗口组合通过；自动样例已清理，普通隔离候选只需一组组件体验。之后再做素材包、预览／原子切换／失败保留，才扩非矩形与离散区域。已注册模型切换不需重启，但新增C#模型仍需编译；不将本批等同于完整模板或代码插件平台。
3. **先完成已验成果集成发布，再设计画板引擎。** 用户已授权模型／性能的develop与main同步、打包和新tag；T1组件未验，代码不合入。随后按[画板引擎设计准备](../A_Project/30_Plans/POSTER_CANVAS_ENGINE_DESIGN_PLAN.md)重新明确统一组件／布局／资源／同代命中边界，不直接把原型扩写成通用平台。
4. **V3-08受控AI接入。** 基于稳定模型／模板／命令边界，先做变更预览、确认与撤销，不给AI绕过文件和版本保护的执行权。
5. **发布维护与环境余验并行。** 真实登录自启、多屏／高刷新率及长稳各保留原边界，不阻塞至完整AI完成；在线更新器独立规划。后续更新说明只写本次变化。

详细职责、幂等事实、发布时机与精简验收见[热度接入方案 §7.1～7.2](../A_Project/30_Plans/V3_GENERAL_CONTENT_MULTI_POSTER_WORKFLOW_V1.md#71-2026-10-21-真实热度准备未实施)。05-04-V3「构造卡片」继续延期。
