## 3. 已替代规则，禁止从旧稿恢复

- 普通点击穿透已取消（DEC-043）。可见海报矩形统一接收输入和 OLE 拖放；空白左键支持框选。视觉透明不等于输入透明。
- 共享内容引用已取消（DEC-047）。一个有效对象只允许一个可见海报引用；普通拖入／出一次按住完成，无应用额外确认，Windows 必要冲突提示和底层保护保留。
- “目录映射”在控制中心的**新增海报**，创建独立映射海报，不在海报空白菜单中。
- 统一原生菜单名称为 **Win菜单**。普通内容菜单提供真实删除，不恢复“仅移除引用／全选引用／刷新来源状态与图标”等已撤入口。
- 新配置**零海报、无演示卡片**。普通启动零海报时打开中心，有海报时后台启动；显式显示中心与自启入口各按其约定执行。新增默认基础收纳。
- “热度自动（可带顺位图钉）／纯手动”是两种模式；图钉不是第三种模式。
- 旧非破坏性引用添加、共享修复、恢复任务 UI、早期拖出二次移动等记录只用于历史追溯，不是下一批实施要求。
- 后续更新 tag／预发布说明**只写本次更新内容**，不重复完整功能介绍；具体规则见 [Git 与发布策略](../Rules/GIT_STRATEGY.md#发布说明与标签更新)。

## 4. 接下来按什么顺序做

1. **可插拔统一协议（下一批）。** 用户已确认先发布已验内置模型，再按[协议计划](../A_Project/30_Plans/V3_ACTIVITY_MODEL_PROTOCOL_PLAN.md)补输入／提案、模型身份与能力版本、替代模型和安全切换。支持排序、尺寸、海报内位置及声明式过渡建议；宿主负责校验与执行，统计不随换模型重置。
2. **联合稳定性与成本测量。** 按V3-10既定1/3/6张及内容规模样本，先量化新增模型成本、读取／观察、UI等待和资源释放，再定向优化；不把短样本外推为达标。
3. **发布与环境余验。** 本轮发布已完成，下一次发布另按授权；真实登录自启、多屏／高刷新率及长稳各保留原边界。更新说明只写本次变化。
4. **后续平台能力。** 再分批推进V3-07模板／风格热替换及V3-08 AI；在线更新器独立规划。统一模型协议不等于已经实现动态代码加载或完整模板平台。

详细职责、幂等事实、发布时机与精简验收见[热度接入方案 §7.1～7.2](../A_Project/30_Plans/V3_GENERAL_CONTENT_MULTI_POSTER_WORKFLOW_V1.md#71-2026-10-21-真实热度准备未实施)。05-04-V3「构造卡片」继续延期。
