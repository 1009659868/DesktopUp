# B 能力模块索引

本索引登记产品能力，不复制源码目录。只有 `ACTIVE_PATH.md` 可以选择当前活跃 B 节点。

| B 能力 | 责任 | 状态 | C 工作流 |
| --- | --- | --- | --- |
| Desktop Runtime Foundation | 桌面宿主、窗口生命周期、托盘、暂停、自启、恢复 | `ACTIVE AT B-DRF0` | Desktop Host Feasibility |
| Poster Redesign | 大幅面窗口、亮带根治、模板引擎、内置模板、状态机、交互 | `ACTIVE DESIGN · DEPLOY AT M1` | 待建立（M1 启动前） |
| Collection and Launch | 主动导入/扫描、预览、仅添加、两阶段安全收纳、恢复、启动和项目元数据 | `PLANNED FOR M2` | 待激活 |
| Poster Layout and Interaction | 排序得分、衰减、弹性流排布、锚定、拖拽跳变、动态缩放 | `PLANNED FOR M3` | 待激活 |
| Theme Runtime and Authoring | 参数化主题、素材包、预览、导入导出和脚本沙箱 | `PLANNED FOR M4` | 待激活 |
| Local AI Assistant | 用户自带 Key、Provider、受控 Tool Calls、预览、撤销和主题草稿 | `PLANNED FOR M4` | 待激活 |
| Game Source Discovery | Steam、Epic、Xbox/Store 等本地发现适配器 | `PLANNED FOR M5` | 待激活 |
| Distribution and Lifecycle | 安装、升级、签名、恢复型卸载和发布验证 | `PLANNED FOR M6` | 待建立 |
| Generalized Collection Platform | 从游戏扩展到应用、文件夹和自定义对象 | `FUTURE` | 待建立 |

规划模块只在成为活跃实施节点时创建完整 B 目录，避免空计划过早成为伪权威。
