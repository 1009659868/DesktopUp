# Desktop-Up 托盘与快捷入口设计 V0.1

状态：`ACTIVE DESIGN BASELINE`

日期：2026-08-02

## 1. 目标

Desktop-Up 运行时常驻 Windows 通知区域。用户可以从任务栏右下角的通知区域或“∧”折叠栏找到 Desktop-Up 图标，不必在任务栏保留普通窗口按钮。

Windows 决定图标显示在主通知区域还是折叠栏；Desktop-Up 只创建标准托盘图标，不修改用户的系统托盘排列设置。

## 2. 基础行为

正常启动和开机自启只显示桌面海报及托盘，不自动显示主页。主页、设置和 Agent 的完整角色见 [`RUNTIME_SURFACE_MODEL_V0.1.md`](RUNTIME_SURFACE_MODEL_V0.1.md)。

| 操作 | 默认行为 |
| --- | --- |
| 单击托盘图标 | 无动作，不改变海报或主页可见性 |
| 双击托盘图标 | 打开/关闭 Desktop-Up 主页 |
| 右键托盘图标 | 打开原生快捷菜单；“显示海报宿主”控制海报显隐 |
| 关闭主页窗口 | 隐藏到托盘，不退出运行时 |
| 菜单“退出 Desktop-Up” | 保存状态、结束 Agent 请求并退出 |

海报是桌面常驻程序，默认不允许通过单击托盘隐藏；隐藏海报只能通过右键菜单的“显示海报宿主”显式操作。

首次关闭主页窗口时显示一次“Desktop-Up 仍在通知区域运行”的系统提示，之后不重复打扰。

## 3. 右键菜单

建议结构：

```text
Desktop-Up
├─ 打开主页
├─ 设置…
├─ 显示全部海报                 [✓]
├─ 编辑布局                     [ ]
├─ 锁定全部海报                 [✓]
├─ 暂停动态效果                 [ ]
├─ 快速主题                     >
│  ├─ 深夜行动                  [✓]
│  ├─ 余烬档案
│  ├─ 玻璃陈列
│  ├─ 黑白线描
│  └─ 管理主题…
├─ AI 助手… / 配置 AI…
├─ 开机自启                     [ ]
├─ 重新连接桌面
└─ 退出 Desktop-Up
```

规则：

- “快速主题”默认作用于当前选中海报；无选中项时作用于默认海报，并在菜单文案中说明；
- Key 未配置时显示“配置 AI…”，不启动 Agent；已配置时显示“AI 助手…”；
- 编辑、暂停、海报可见性和开机自启使用带勾选状态的原生菜单项；
- “锁定全部海报”只固定海报模块的位置、尺寸和锚点，不妨碍展开、收起与启动游戏；
- 单张海报的锁定状态允许不同；全局锁定命令批量写入每张海报的持久状态；
- 设置与主页必须复用单实例窗口，不创建重复控制中心；
- “重新连接桌面”仅在桌面挂载降级或失败时突出显示。

## 4. 图标和提示

托盘图标至少提供三种可区分状态：

- 正常：标准品牌图标；
- 已暂停：提示文本增加“动态效果已暂停”；
- 需要处理：挂载失败或托管快捷方式恢复异常，提示文本增加简短原因。

不建议用高频闪烁表达状态。托盘 Tooltip 保持简短，例如：

```text
Desktop-Up · 2 张海报 · 已暂停
```

## 5. 生命周期

- 未开启开机自启：只有用户启动 Desktop-Up 后才出现托盘图标；
- 开启开机自启：登录后先创建轻量托盘与静态海报，控制中心按需加载；
- 普通启动：显示已启用海报并保持控制中心隐藏；只有首次引导的显式用户选择可以例外；
- Explorer 重启：检测 `TaskbarCreated` 后重建托盘图标和菜单；
- 多实例启动：第二实例通知现有实例打开主页，然后退出；
- 正常退出：先取消 Agent 请求、保存布局、移除托盘图标，再结束进程；
- 卸载：停止运行时并清除自启、托盘相关登记和凭据。

## 6. 性能边界

托盘由 Rust 原生层拥有，右键菜单使用缓存的海报/主题摘要，不因打开菜单而唤醒完整主题编辑器。主题列表变化后更新菜单快照。

关闭控制中心后：

- 不保留它的动态预览循环；
- 不因托盘存在而轮询前台窗口；
- 不启动 AI Provider；
- 只保留桌面宿主、事件监听和托盘消息循环。

## 7. 可用性与容错

- 菜单操作必须在键盘导航和高 DPI 下可用；
- 菜单命令失败时显示短通知并保留原状态；
- 主页被移到已断开的显示器时，从托盘打开应迁回主显示器可见区域；
- Explorer 重启后连续恢复失败时停止重试，菜单提供手动重连；
- 用户可在 Windows 设置中决定托盘图标是否常显，应用不强制修改。

## 8. 验收标准

- 图标可以出现在 Windows 11 通知区域/折叠栏；
- 单击、双击、右键行为与契约一致；
- 右键菜单可打开主页、设置和快速切换主题；
- 单张海报锁按钮与托盘全局锁定状态一致，锁定后拖动和缩放均不生效；
- 主页关闭后进程和托盘仍存在，显式退出后全部结束；
- 第二实例不产生第二个托盘图标；
- Explorer 重启 10 次后均可恢复或进入明确回退；
- 100%、125%、150%、200% DPI 下菜单与图标清晰可用；
- 未配置 API Key 时，托盘不会启动 AI，只提供配置入口。
