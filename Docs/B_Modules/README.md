各模块目录结构:

```text
B_Modules/<ModuleName>/
├─ 00_Catalog/C_WORKSTREAM_INDEX.md
├─ 10_Plan/MODULE_PLAN.md
├─ 20_Log/MODULE_LOG.md
└─ 30_Sync/COLD_START.md, CURRENT_HANDOFF.md
```
