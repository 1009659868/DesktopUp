# Theme Authoring 工作流索引

| C 工作流 | 责任 | 依赖 | 状态 |
| --- | --- | --- | --- |
| Schema Parameter Authoring (`C-SPA`) | schema 参数面板、预设和撤销 | C-THP | `PLANNED` |
| Asset Sanitization (`C-ASN`) | 图片/SVG/字体净化和槽位 | C-TPS | `PLANNED` |
| Restricted Overrides (`C-ROC`) | Shadow Root 内 CSS/HTML 覆盖与信任 | C-SPA, C-ASN | `PLANNED` |
| Theme Import Export (`C-TIE`) | 参数包、素材包、完整模板包闭环 | C-ROC | `PLANNED` |

在线主题市场和无限权限脚本不属于 V1。
