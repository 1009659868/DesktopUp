## 1. 责任

## 2. 契约范围

- **状态模型**:单一状态权威(core),状态变更=命令+修订号,拒绝无 base revision 的盲写(防回弹);
- **命令**:统一命令/回复/事件/错误 schema;命令执行后读回验证(穿透位/几何等);
- **生命周期**:单实例互斥体、二次启动归并、看门狗有限重建、托盘退出路径;
- **诊断**:结构化 JSON lines 循环日志,携带会话/修订/事件序列号,支持故障回放;
- **安全**:未来主题脚本/AI 工具的权限声明与拒绝契约挂在此模块。
