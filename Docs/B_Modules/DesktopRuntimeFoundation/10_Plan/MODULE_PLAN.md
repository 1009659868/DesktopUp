# Desktop Runtime Foundation 模块计划

最后检查：2026-08-04

状态：`SUPERSEDED`

> 本模块计划冻结于 2026-08-04。当前计划为 [`MODULE_PLAN_V1.md`](MODULE_PLAN_V1.md)。旧计划中的 C-DHF-04..08 等未完成事项已原样迁移，冻结不代表取消或完成。

## 1. 模块责任

本模块拥有：

- 桌面收纳层、控制中心和通知区域的独立显隐与生命周期边界；
- 桌面宿主窗口的创建、挂载、命中测试和恢复；
- 单实例、系统托盘、显示/隐藏和安全退出；
- 托盘主页/设置、编辑、暂停、快速主题和开机自启原生菜单；
- 前台窗口、会话、电源和显示器状态的事件归一化；
- 动画暂停、停止和恢复策略；
- 开机自启注册与移除；
- Explorer 重启、虚拟桌面、多屏和 DPI 变化的生命周期处理。

本模块不拥有：

- 快捷方式收纳与恢复账本；
- 海报具体排版算法；
- 主题包格式与脚本安全；
- Steam/Epic/Xbox 数据来源；
- 安装器和卸载器的最终实现。

## 2. 对外契约

### DesktopSurface

- 创建/销毁单全局透明桌面宿主；
- 设置海报交互区域；
- 切换编辑、使用、穿透和暂停状态；
- 宿主覆盖全局桌面坐标空间，海报模块在其中维护显示器归属、锚点和位置；
- 新海报默认位于主显示器右侧、`top-right` 锚定、解锁并展开；
- 未锁定时，USING 和 EDITING 均允许从模板内自制 DOM 标题栏空白区移动海报；按钮与其他交互控件排除拖动；
- 持久保存单海报锁定状态，并拒绝手动、自动化或 Agent 对锁定海报的移动与缩放；
- 报告挂载模式、显示器和恢复状态；
- 作为普通启动后的唯一默认可见表面工作，不依赖控制中心窗口存在。

### ControlCenterLifecycle

- 普通启动和开机自启保持隐藏；
- 托盘、开始菜单、快捷方式或第二实例的显式动作才创建/显示；
- 关闭时释放预览资源但不改变海报可见性；
- 控制中心预览和桌面宿主通过统一状态命令同步，不互相嵌套。

### RuntimeVisibilityPolicy

- 输入：前台窗口、窗口覆盖、会话、电源、显示器和用户覆盖规则；
- 输出：`ActiveStatic`、`ActiveAnimated`、`Paused` 或 `Stopped`；
- 相同事件快照必须产生确定性结果。

### RuntimeLifecycle

- 单实例协调；
- 托盘图标、单击/双击/右键命令与 `TaskbarCreated` 恢复；
- 自启开关；
- Explorer/显示器变化后的受限重试与回退。

### TrayQuickAccess

- 单击不改变海报，避免误隐藏桌面常驻程序；
- 双击切换单实例主页显示/隐藏；
- 右键菜单打开主页、设置并切换当前海报主题；
- 右键菜单“显示海报宿主”控制全部海报显示/隐藏；
- 批量锁定或解锁全部海报，并与单海报锁按钮同步状态；
- 未配置 API Key 时只显示“配置 AI”，不得启动 Agent；
- 关闭主页隐藏到托盘，显式退出才结束进程。

## 4. 依赖

- Windows 11 x64 测试环境；
- WebView2 Evergreen Runtime；
- Tauri 2 和 Rust stable；
- 用于 Explorer 重启、多屏/DPI 和全屏应用的测试夹具。

## 5. 风险与回退

| 风险 | 约束 | 回退 |
| --- | --- | --- |
| WorkerW 等桌面内部结构发生变化 | 仅限 Windows 适配层，不进入业务接口 | 普通 bottom-most 工具窗口 |
| 全屏检测误判 | 事件快照加显示器覆盖判断 | 用户按应用覆盖规则 |
| 单全局透明宿主截获鼠标 | 明确交互区域并做原生命中测试 | 安全禁用桌面宿主并回退到可观察的普通工具窗口，不重新引入未验证拓扑 |
| 控制中心被误当成产品主体 | 运行表面模型作为验收契约，启动后枚举可见窗口 | 阻止发布并回退到控制中心默认隐藏 |
| WebView2 空闲仍有资源占用 | 静态按需绘制并冻结主题 | 原生静态合成或释放宿主 |
| Explorer 重启重试风暴 | 指数退避、次数上限和状态报告 | 手动“重新连接桌面” |
| 托盘图标被系统折叠 | 不篡改 Windows 通知区域偏好 | 在首次引导中说明由用户决定是否常显 |

## 6. 验收范围

- Windows 11 x64；
- 100%、125%、150%、200% DPI；
- 单屏、双屏、主屏切换和热插拔；
- Win+D、Explorer 重启、锁屏、显示器关闭、远程桌面；
- 窗口化、最大化、无边框全屏和独占全屏应用；
- 静态、30 FPS 动态和停止释放三种主题状态。
