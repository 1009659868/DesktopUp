# C-PSI 现状审计与交互矩阵 V1

日期：2026-08-14

状态：`FROZEN — C-PSI-01`

## 1. 裁决原则

1. SQLite `poster_state_v1` 继续是海报业务状态的唯一正式来源；`RuntimeSnapshot` 只拥有编辑态、性能/生命周期、显隐和宿主诊断。
2. 控制中心是正式状态的投影与命令入口，不拥有第二份海报几何；真实桌面海报和控制中心均通过同一 expected-revision/CAS 路径提交。
3. 已经由 Release 人工验证的顶部不移动、桌面空白穿透、卡片命中、锁定、收起/展开和普通程序层级直接吸收，不重新实现。
4. “暂停动态效果”只停止动态绘制，保持已经验收的锁定、收起/展开和恢复入口可用；系统不可见、会话锁定、显示器关闭、退出或宿主未就绪才禁止海报表面输入。实现层必须区分渲染暂停与输入不可用，不能再只用一个 `paused` 布尔值推断两者。
5. C-PSI 只提供稳定承载 Item 的状态与命中边界。真实 Item 仓库、启动、排序语义和 Item 菜单内容分别交给 C-CIM、C-LCH、C-LAR；C-PSI 不用演示卡片冒充正式 Item。

附加规则：

- 标题栏按钮、链接、输入控件和 Item 必须排除出标题栏拖动起点；指针移动达到 `5px` 后才判定为拖动。
- COLLAPSED 时标题文字单击可展开，任何缩放手柄均不得进入 DOM 或命中区。
- 透明空白在 USING 中继续穿透至 Windows 桌面；EDITING 的控制中心预览可在非 Item 内容区移动海报，但真实桌面空白命中不改变。
- 海报宽高最小均为 `240px`；最大宽为当前工作区宽度的 `45%`；最大展开高度为工作区高度减去上下各 `24px` 安全边距；右下角缩放不得移动左上角。

## 4. 剩余实施切片

任务数量保持不变，不为制造进度重复实现 PASS：

1. `C-PSI-02`：接入权限派生、拆分效果暂停/输入暂停，并为正式字段增加 pending mutation 保留。
2. `C-PSI-03`：统一移动/缩放入口和动态工作区约束，非法组合 fail closed。
3. `C-PSI-04`：补标题文字展开、`5px` 拖动判定和海报级右键入口；Item 命令只留版本化接口，不实现内容主线。
4. `C-PSI-05`：运行自动化与主屏 Release 回归，冻结 C-CIM 所需 Item 投影接口后立即交接 C-CIM。

## 5. C-PSI-01 结论

C-PSI-01 只形成审计与裁决文档，没有修改生产代码。现有能力中 7 组直接吸收，确认 7 个真实缺口；后续不得以 C-PSI 名义重写 SQLite 仓库、桌面宿主、透明大幅面或生命周期快捷入口。
