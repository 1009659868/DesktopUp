# Poster State and Interaction 工作流计划

日期：2026-08-14

状态：`ACTIVE — C-PSI-03 GEOMETRY`

## 1. 目的

在不重做 C-DRP/C-PCB/C-PSS 已通过能力的前提下，审计并收敛海报 `USING/EDITING × EXPANDED/COLLAPSED × locked/unlocked` 的唯一状态与权限矩阵，使海报成为可安全承载正式 Item 的稳定交互表面。

## 2. 范围

本工作流负责：

- USING/EDITING、展开/收起、锁定、暂停与显隐状态权威；
- 自制标题栏拖动、按钮排除、卡片命中和透明空白穿透；
- 仅在 `EDITING + EXPANDED + unlocked` 时允许移动/缩放编辑；
- 海报框宽高拉伸、240px 最小宽/高、45% 最大宽和工作区最大高；
- 控制中心编辑投影与真实桌面矩形之间的单向提交、CAS 和失败保留；
- Release 交互回归及 C-CIM 输入门。

本工作流不负责 Item 仓库、真实启动、模板参数权威、多海报或多显示器认证。

## 3. 提前冻结的边界

1. 先做现状审计；已通过项直接登记证据，不为“任务完整”重复实现。
2. SQLite 正式状态继续是业务状态唯一权威；控制中心编辑画布只是投影和命令入口。
3. 原生宿主继续拥有窗口几何、桌面层级和命中应用；前端不得建立第二套窗口 authority。
4. 收起/展开保持顶部位置；锁定不禁止解锁、收起/展开或 Item 启动。
5. C-PSI 退出时只要求稳定承载 Item，不要求 Item 已经存在。

## 4. 预定任务

| 任务 | 可验证结果 | 状态 |
| --- | --- | --- |
| C-PSI-01 现状审计与矩阵冻结 | 将既有实现映射到状态/权限矩阵，只列真实缺口 | `COMPLETE` |
| C-PSI-02 状态权威与失败保留 | USING/EDITING、锁定、收起和暂停由正式快照/运行时快照统一，CAS 失败不回弹 | `COMPLETE` |
| C-PSI-03 移动、缩放与尺寸边界 | 编辑权限、原生几何、控制中心投影和显式 min/max 约束一致 | `IN PROGRESS` |
| C-PSI-04 命中、标题栏与运行时同步 | 空白、标题栏、控件、Item 区域以及 pause/visibility 状态无冲突 | `PLANNED` |
| C-PSI-05 Release 交互门与 C-CIM 交接 | 自动化和主屏人工矩阵通过，形成正式 Item 投影输入 | `PLANNED` |

C-PSI-01 已冻结 [`C_PSI_AUDIT_MATRIX_V1.md`](C_PSI_AUDIT_MATRIX_V1.md)：7 组能力直接吸收，7 个真实缺口分别归 C-PSI-02..04；正式 Item 数据与命令继续留给 C-CIM/C-LCH/C-LAR。

## 5. 完成门

- 状态/权限矩阵在 JS、Rust 与实际 UI 中一致；
- 收起、展开、锁定、编辑、拖动、缩放和暂停无回弹；
- 非法状态组合不能触发移动或缩放；
- 控制中心关闭/重开不改变真实海报；
- 透明空白、卡片、原生桌面图标和普通程序层级无回退；
- C-CIM 可以只通过版本化接口提供 Item 快照，不访问原生宿主内部实现。
