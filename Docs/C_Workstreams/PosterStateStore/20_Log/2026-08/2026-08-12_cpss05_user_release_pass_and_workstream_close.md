## 2. 不随关闭掩盖的已知缺陷

用户同时确认控制中心“视觉参数”的强调色、透明度或密度调整存在回弹，当前不能正常连续调整。用户决定本轮不修复，后续处理。

该问题不记为通过，原因与边界如下：

- C-PSS 冻结输入明确规定 `theme/accent/opacity/density` 不是状态仓库自身 schema；
- 当前正式风格选择通过 `templateKey` 保存，用户已确认风格和其他正式状态的退出重启恢复；
- 旧控制中心仍直接修改 runtime `accent/opacity/density`，正式状态刷新会重新投影已接受的正式字段，因此出现回弹；
- 缺陷归入后继 Template Platform 的 schema 参数面板/模板参数权威收敛，不通过扩张 C-PSS schema 临时修补；进入相关工作流时必须先复现并建立自动测试。
