# Large Surface and Transparency 工作流计划

日期：2026-08-14

状态：`COMPLETE — ABSORBED AND AUDITED`

## 1. 目的

确认主屏单海报的大幅面默认几何、透明合成、无原生非客户区、收起包络和位置恢复已经形成可重复的生产基线。现有 C-DRP、C-PCB、C-PSS 与 C-RLC 证据优先复用；只有审计证明存在明确缺口时才允许新增实现。

## 2. 范围

本工作流负责：

- 主显示器 `top-right` 默认锚点、22% 默认宽度、近满高与安全边距；
- 240px 最小宽/展开高度、45% 工作区最大宽和工作区最大高度契约；
- 展开与收起共用顶部/左右位置，收起只改变高度包络；
- Tauri 透明窗口、WebView 背景、CSS 背景与 Windows 非客户区不变量；
- 位置、宽高、锁定与收起状态经正式 SQLite 状态恢复；
- 主屏单海报 Release 人工证据和自动化回归。

本工作流不负责：多显示器认证、完整 USING/EDITING 交互、Item 数据、真实启动、模板平台、视觉参数权威或文件移动。

## 3. 冻结决策

1. C-LST 是“证据审计优先”的收敛工作流，不以重新修改窗口代码作为完成条件。
2. 当前发布认证继续限制为主屏单海报；混合 DPI、负坐标副屏、主屏切换、跨屏重启和热插拔不计入本次完成门。
3. 几何常量继续以 `poster-geometry-v1` 的 JS/Rust 同构实现为权威，不复制第三套常量。
4. 透明背景必须同时保持窗口配置、WebView 合成背景、DOM/CSS 与 Windows 非客户区不变量；任一层回退都视为失败。
5. C-LST 不接管 C-PSI 的编辑权限、拖动/缩放状态机，也不接管 C-CIM 的 Item 仓库。

## 5. 完成门

- 默认几何与主屏右上锚点由 JS/Rust 同构测试冻结；
- 展开和收起保持顶部/左右位置，宽度不跳变；
- 冷启动、拖动、收起/展开后无顶部白条或裁切；
- 透明空白与桌面交互不因大幅面而回退；
- 改变位置、宽高、锁定或收起状态后退出重启能够恢复；
- 普通程序不会被海报覆盖，Shell 恢复不使用通用 TOPMOST；
- 多显示器未认证项明确保留。

## 6. 后继边界

C-LST 关闭后进入 C-PSI 的剩余项审计和收敛。C-PSI 通过后立即进入 C-CIM，让硬编码演示卡片退出正式运行路径。
