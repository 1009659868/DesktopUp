# C-V2P5 主题平台 工作流计划 V1

状态:`PLANNING — 待闸口 A-F1 解锁(计划提前准备)`

日期:2026-08-19

设计输入:`A_Project/10_Plan/THEME_PLATFORM_AND_AI_V1.md`(模板角色、四级定制、隔离、热切换、包格式、导入安全链、原子安装)

## 1. 目的

把渲染端从"单一 NIGHT OPS 构图 + 两个参数"升级为正式主题平台:三模板 + minimal-fallback、结构化参数 schema、素材槽、热切换 <200ms、包导入导出。交付闸口 F1。

## 2. 架构要点

- **模板角色**(合同 §4):night-ops / neon-hud / cinema-lightbox 三正常模板 + minimal-fallback(错误回退,物理/逻辑独立,不参与正常选择);
- **四级定制**(合同 §5):D0 预设开关 → D1 结构化参数 → D2 素材替换 → D3 受限覆盖;本阶段先落地 D0+D1 全量,D2 素材槽骨架,D3 留 P7;
- **受保护结构契约**(合同 §6):标题栏/卡片/健康标记结构不可被主题移除(自检依赖品红标记——与呈现自检耦合);
- **隔离**(合同 §7):模板目录隔离、参数白名单、素材路径白名单;fallback 独立;
- **参数权威与防回弹**(合同 §8):沿用核心状态权威 + base_rev;主题参数纳入同一状态机;
- **热切换**(合同 §9):set_params 路径已实测 0-1ms;完整模板切换目标 <200ms,切换期间旧帧有效、失败回滚;
- **包格式**(合同 §10):`.params.json` / `.theme.zip`(素材)/ `.full.zip`(模板);
- **导入安全链**(合同 §12):解压前校验(大小/条目数/总解压大小)→ 目录安全(无路径穿越)→ 内容安全(声明清单 vs 实际);不执行任何包内代码;
- **原子安装/卸载**(合同 §13):stage → 校验 → 原子替换;卸载迁移到默认/fallback。

## 4. 闸口 F1 证据清单(摘自合同 §24 主题部分)

1. 三个正常模板与 fallback 角色分离;fallback 永不参与正常选择;
2. 参数非法值拒绝,冲突不覆盖,回弹可复现可撤销;
3. 热切换 <200ms 且切换失败回滚到旧模板;
4. 导入安全链攻击用例全拒(路径穿越/超限/缺声明);
5. 卸载后默认模板接管,default 缺失进 fallback;
6. 包导出 → 导入往返一致。
