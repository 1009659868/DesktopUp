# C-V2P6 布局与活跃度 工作流计划 V1

状态:`PLANNING — 待闸口 A-F2 解锁(计划提前准备)`

日期:2026-08-19

设计输入:`A_Project/10_Plan/CONTENT_ITEM_ACTIVITY_LAYOUT_V1.md`(排名 §7-9、动态缩放 §10、基础布局 §11、行式弹性流 §12、三层人工控制 §13、拖拽提升 §14)

## 1. 目的

把海报布局从固定 3×2 升级为数据驱动的动态排版:排名、缩放、弹性流、锚定、跳变,全部可解释、确定、可撤销。交付闸口 F2。

## 2. 架构要点

- **排名模型**(合同 §7-9):MVP 先用 added_at 稳定序(P3 已采集统计字段);P6 接入 `rank_score = 0.40×recency_norm + 0.35×frequency_norm + 0.25×diversity_norm`(合同公式,衰减校正按 §8.3 的矛盾修正执行——以合同 §8 有效启动语义为准);
- **确定性**:同一状态必产生同一布局(种子固定、平局按 id 序);
- **动态缩放**(合同 §10):基础对数映射 + 用户参数(最小/最大尺寸、缩放强度);超界裁剪;
- **行式弹性流**(合同 §12):主流 + 子列填充,几何性质(间隙一致、换行确定);
- **三层人工控制**(合同 §13):全自动(默认)/ 锚定+自动 / 全手动;锁定只冻结外部几何与人工重排,不影响内部自动逻辑(需求确认轮裁决);
- **拖拽临时活跃提升**(合同 §14):拖拽触发 burst,目标提升、衰减与真实启动衔接;
- **撤销链**:所有自动调整共用统一撤销栈(与收纳/主题/AI 同一纪律)。

## 4. 闸口 F2 证据清单(摘自合同 §18 相关项)

1. 排序可解释(排名理由可查:各分项分值)且确定(同状态重放一致);
2. 所有自动调整可撤销;锚定冲突按"后固定稳定偏移"规则;
3. 锁定只冻结外部几何与人工重排,内部自动逻辑不受影响;
4. 极端夹具:0 Item(空状态)、1 Item、满溢出 Item 的布局不崩溃;
5. 拖拽提升后排名变化可解释,衰减后回归稳定。
