# C-V2P1 桌面宿主重建 工作流计划 V1

状态:`PLANNING — 待闸口 A 解锁(计划提前准备,原则 2)`

日期:2026-08-18

## 1. 目的

在 C-QTP 原型证据基础上,把 Qt 渲染侧车生产化、把核心桩扩为真核心(单实例、状态权威、命令、修订、生命周期、诊断),交付主屏单海报交互门(闸口 B)。本计划不依赖闸口 A 的具体结论——若 C-QTP 未通过,本计划由 C-D2D 保底工作流替换渲染器部分,核心/契约部分不变。

## 2. 原型教训(直接输入)

| 教训 | 本阶段落实 |
| --- | --- |
| 命名管道 PIPE_NOWAIT + 一次性 ConnectNamedPipe → 断管死锁 | 管道服务器用阻塞 ConnectNamedPipe 循环 + 每客户端独立读线程;stdio 父子通道保留(已实证稳定) |
| frameSwapped 内 grabWindow → 0xC0000374/0xC0000005 | 自检抓取只在事件循环干净上下文(QTimer 延迟),写入渲染器自检契约 |
| 隐藏态 grabWindow 返回陈旧缓冲 | 自检抓取前检查 isVisible,未呈现即报失败 |
| 原子状态与窗口实际样式位不一致 | 状态权威以命令执行为准,穿透位变更后读回验证(写入命令执行器) |
| 路径/参数硬编码(渲染器 1700,200 等) | 配置注入:core 下发几何与参数,渲染器无自主默认值 |
| 沙箱 UIPI 阻断 SendInput(测试环境边界) | 自动化验证用直接样式位读回;交互验证留用户实机 |

## 3. 目标架构

```text
┌─────────────────── desktopup-core(Rust, 单实例) ───────────────────┐
│ 状态权威(唯一)/ 命令执行器 / 修订号 / 生命周期 / 结构化诊断          │
│ 看门狗(有限重建)│ 单实例互斥体 │ 托盘(最小 Shell_NotifyIconW)        │
└───────┬──────────────────────┬─────────────────────────────────────┘
        │ stdio 帧协议 v1       │ 命名管道服务器(阻塞多实例,P2 接入预留)
┌───────▼──────────────┐       └──────────(控制中心 P2 起接入)
│ poster-renderer      │
│ (C++/Qt, 无状态投影) │
└──────────────────────┘
```

- **状态权威**:core 唯一;renderer 只投影,不持状态;
- **修订号**:每次状态变更单调递增,命令携带 base revision,冲突即拒绝(防回弹,为 P2 控制中心一致性铺路);
- **层级决策**:海报 = `Qt::Tool + WindowDoesNotAcceptFocus` + 空白 `WS_EX_TRANSPARENT`(C-QTP 已证),桌面图标之上、普通窗口之下、永不抢焦点;
- **单透明机制**:继续只用 WS_EX_TRANSPARENT,禁止叠加 layered/blur(单一机制原则)。

### 闸口 A 期间的解锁说明(2026-08-18 增补)

闸口串联原则(原则 2)的例外登记:以下任务**不依赖渲染技术结论**,即使 C-QTP 被淘汰转 C-D2D 也原样保留,故允许在闸口 A 裁决前启动:

- **C-V2P1-01**(协议 schema 与命名管道服务器)——纯契约与核心侧传输;
- **C-V2P1-02 中与渲染无关的部分**(单实例互斥体、状态机骨架、修订号、结构化诊断)。

C-V2P1-03(渲染器生产化)及之后任务仍严格等待闸口 A。

## 5. 边界与非目标

- 控制中心、Item、主题、AI、安装器不在本阶段(对应 P2+);
- 不做多层透明机制;不做 Progman/WorkerW 注入(桌面层挂载留决策记录,本阶段 Tool 窗口方案已满足主屏单海报);
- V1 代码不迁移。

## 6. 闸口 B 证据清单(用户实机)

1. 冷启动:海报出现且自检 PASS(品红标记 256px);
2. 拖动 20 轮:零白条/灰框/裁切;
3. 穿透:空白区点到桌面图标;标题栏命中可拖动(5px 阈值);
4. 层级:海报在桌面图标之上、普通窗口之下;不抢焦点;
5. Win+D 期间海报持续可见(桌面内容层语义),验收(2026-08-19 用户冻结):点击桌面空白后等待任意时间再按 Win+D——海报持续可见;WS_VISIBLE 始终 true;非最小化;DWM Cloak=0;Z 序恒满足 普通程序 > 海报 > Progman/图标/壁纸;不得先掉到 Progman 后方再恢复;不得 TOPMOST;覆盖键盘 Win+D、任务栏"显示桌面"按钮与触控板手势全部入口(不依赖 Shell 前台边沿事件);
6. Explorer 重启后海报仍在;
7. 托盘退出/重启海报;
8. 复测 0-FPS、CPU ≤ 预算、工作集记录(生产化后)。

## 7. 完成门

8 项全过 → 冻结宿主架构,进入 V2-P2(控制中心);任一失败 → 修复回归或按计划转 C-D2D 替换渲染层。
