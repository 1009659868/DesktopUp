# 设计资源库

CanvasWorkspace 实现 ICanvasWorkspace。位置为当前配置根下 canvas/；图片 SHA256 寻址，作品为有界 JSON，组合为带摘要的不可变装饰快照。拒绝重解析路径、未知图片格式、超额／超像素和篡改依赖；临时写入完成后原子替换自身元数据，不操作用户源图片或收纳文件。

单图 8 MB／2400 万像素／最长边8192，单作品最多8份不同图片；库128图片、256 MB。WinUI 解码最长边2048且不放大，缩略图最长边96。无需逐帧磁盘读取。已导入资源保守保留，避免破坏已应用版本、草稿、组合与撤销；跨配置导出资源包和依赖垃圾回收不是本批已实现能力。

Samples 是普通样例声明与已认可设计使用的雨窗图像。图像由项目设计阶段生成，来源记录见 Docs/A_Project/40_Implementation/V3-07/CANVAS_J1_CREATION_REDESIGN.md。不包含样例名称分支或第三方执行代码。
